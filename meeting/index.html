3 회의 내용에 질문하기

정리된 회의 기록을 근거로 답합니다.

협의회 정리 도우미 · Deepgram·Groq 무료 API 기반 · 전사(Deepgram)와 정리(Groq)는 내 브라우저에서 각 서버로 직접 전송됩니다 (중계 서버 · 저장 없음)
연결됨 Deepgram + Llama 3.3

💡 사용법 · 팁

간단 사용법 — 딸각 세 번

  • ① 최초 1회만: 무료 API 키 2개 연결 (발급 방법은 연결 창에 단계별 안내 · 카드 등록 없음)
  • ② 파일 올리기 또는 바로 녹음: 녹음 파일(mp3·m4a·wav·ogg)·텍스트 파일(txt·md)을 끌어다 놓거나, 🔴 브라우저에서 바로 녹음 버튼으로 회의 현장에서 직접 녹음
  • ③ 정리 시작: 결과 유형·문체를 고르고 버튼 클릭 — 완료되면 회의 내용에 질문도 할 수 있어요

이 도구의 장점

  • 자동 화자 분리: 녹음만 올리면 "화자1 · 화자2 …"로 발언자를 자동 구분해 전사합니다. 누가 어떤 발언·결정을 했는지 정리에도 반영돼요. (실측: 5인 협의회 20분 녹음에서 화자 5명 구분 확인)
  • 빠른 처리: 녹음을 조각내지 않고 통째로 전송해 서버에서 한 번에 처리합니다. (실측: 20분 녹음 전사 약 10초)
  • 앱 → 변환 → 재업로드 과정이 없음: 클로바노트처럼 앱에서 변환한 텍스트를 내보내 다시 올릴 필요 없이, 브라우저에 녹음 파일 하나만 올리면 전사부터 정리까지 한 번에 끝납니다.
  • 원하는 형태로 정리: 안건별 · 시간순 · 핵심만 / 개조식 · 회의록 격식체 · 서술형을 골라 바로 공문·회의록에 쓸 수 있는 형태로 나옵니다.
  • 저장 없음: 회의 내용은 어디에도 저장되지 않으며, API 키는 내 브라우저에만 보관됩니다.

클로바노트 앱과 뭐가 다른가요?

  • 현장에서 바로 끝: 이 도구는 브라우저 하나에서 녹음 → 전사 → 정리 → 질문까지 한 번에 됩니다. 클로바노트는 앱에서 녹음·변환한 뒤 텍스트를 내보내 다른 도구로 옮겨야 정리가 가능해요.
  • 무료 한도가 훨씬 큼: 클로바노트 무료 플랜은 매월 전사 시간 한도(약 300분 수준)가 있지만, 이 도구는 Deepgram $200 크레딧으로 약 700시간(20분 회의 약 2,000회) — 주 1회 사용 기준 수년치이고, AI 정리는 매일 리셋되는 Groq 무료 한도로 사실상 제한 없이 씁니다.
  • 정리 성능·자유도: 클로바노트의 AI 요약은 형식이 고정돼 있고 무료 횟수 제한이 있지만, 여기서는 안건별·시간순·핵심만 × 개조식·격식체·서술형을 골라 공문·회의록에 바로 쓰는 형태로 나오고, 화자 구분이 정리에까지 반영되며(누가 결정했는지), 회의 내용에 추가 질문도 할 수 있어요.
  • 저장 정책: 클로바노트는 녹음·전사가 네이버 서버 계정에 보관되지만, 이 도구는 회의 내용을 어디에도 저장하지 않습니다.

🔴 브라우저에서 바로 녹음하기 — 설정 방법

  • 시작: 파일 카드의 브라우저에서 바로 녹음 버튼 클릭 → 브라우저가 묻는 마이크 권한에서 허용 클릭 (최초 1회만)
  • 권한을 실수로 차단했다면 (인터넷 주소로 연 경우): 주소창 왼쪽 자물쇠(사이트 정보) 아이콘 → 마이크 → 허용으로 바꾼 뒤 새로고침
  • 내 컴퓨터의 파일로 직접 연 경우 (주소가 file:// · 자물쇠 없음): 녹음 버튼을 누른 직후 주소창 오른쪽 끝의 마이크(차단) 아이콘 클릭 → 허용 · 안 보이면 브라우저 설정의 쿠키 및 사이트 권한 → 마이크 차단 목록에서 삭제 후 새로고침
  • 소리가 잘 담기는지 확인: 녹음 중 초록 입력 레벨 막대가 말소리에 맞춰 움직여야 정상 · 녹음 완료 후 🎧 미리 듣기로 재생 확인
  • 막대가 안 움직이면 (노트북 설정 문제): 윈도우 설정 → 시스템 → 소리 → 입력에서 사용할 마이크가 선택돼 있고 볼륨이 0이 아닌지, 설정 → 개인 정보 및 보안 → 마이크에서 브라우저 접근이 켜져 있는지 확인
  • 긴 회의 팁: 녹음 중에는 화면 꺼짐을 자동으로 막아 주지만, 노트북은 전원을 연결하고 이 탭을 켜 둔 채로 두세요
  • 일시정지·완료: 쉬는 시간엔 일시정지했다가 이어서 녹음 가능 — 녹음 완료를 누르면 파일이 자동으로 올라가고 바로 정리 시작을 누르면 됩니다
  • 주의: 녹음 완료 전에 창을 닫으면 녹음이 사라집니다 (닫으려 하면 경고가 뜸) · 녹음은 어디에도 저장되지 않고 완료 즉시 내 브라우저 안에서 파일로만 준비됩니다

결과를 회의록답게 다듬기

  • 회의 정보 입력: 옵션 카드에 회의명·일시·장소·참석자를 적어두면 회의록 머리말과 다운로드 파일명에 자동으로 들어갑니다
  • 화자 이름 바꾸기: 결과 화면 상단에서 "화자1 → 김OO"처럼 입력하고 이름 일괄 적용을 누르면 정리본·전사 원문에 한 번에 반영됩니다
  • 전사 원문 검색: 전사 원문 카드를 펼치면 검색창이 있어요 — 키워드를 입력하고 ▲▼로 이동하며 특정 발언을 빠르게 찾을 수 있습니다
  • 실수 방지: 정리 진행 중이거나 녹음 중일 때 창을 닫으려 하면 경고를 띄워 결과를 잃지 않게 지켜줍니다

무료로 어디까지 쓸 수 있나요?

  • 전사 (Deepgram): 가입 시 $200 크레딧 지급 (카드 등록 없음) — 20분 회의 약 2,000회, 1시간 회의 약 700회 분량입니다. 주 1회 사용 기준 수년 이상.
  • 정리·질문 (Groq): 매일 리셋되는 무료 한도 — 하루 2~3시간 분량 회의 정리도 여유 있습니다. 한도에 걸리면 도구가 자동으로 대기했다가 이어서 진행하니 창만 닫지 마세요.
  • 파일 크기: 녹음 파일 1개당 2GB까지 — 수 시간짜리 회의도 통째로 올릴 수 있어요.

API 연결

무료 API 키 2개로 모든 기능이 작동합니다 — Deepgram(전사·화자 구분) + Groq(정리·질문).
키는 이 브라우저에만 저장되며 외부로 새지 않습니다.

① Deepgram 키 녹음 전사 · 화자 구분 담당
발급 방법 보기 (약 3분 · 카드 등록 없이 $200 무료 크레딧)
  1. console.deepgram.com/signup 접속 → 구글 계정으로 무료 가입 (카드 등록 없음 · $200 크레딧 자동 지급 — 20분 회의 약 2,000회 분량)
  2. 왼쪽 메뉴 API Keys → Create a New API Key 클릭
  3. 이름은 아무거나(예: 협의회) → 만료(Expiration)는 Never, 권한(Role)은 Default 그대로 → Create Key
  4. 딱 한 번만 표시되는 40자 키를 복사해 위 칸에 붙여넣기
녹음 파일 없이 텍스트 파일만 정리할 거라면 비워두어도 됩니다.
② Groq 키 AI 정리 · 질문 담당 · 필수
발급 방법 보기 (약 2분 · 무료)
  1. console.groq.com 접속 → 구글 계정으로 무료 로그인
  2. 왼쪽 메뉴 API Keys → Create API Key 클릭
  3. 이름은 아무거나(예: 협의회) → gsk_ 로 시작하는 키 복사 (한 번만 표시되니 꼭 저장)
  4. 복사한 키를 위 칸에 붙여넣기
