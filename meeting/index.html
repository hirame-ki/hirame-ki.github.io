⚠️ 회의 녹음은 참석자 동의 하에 사용하세요. 오디오는 브라우저에서 분할된 뒤 STT API(Groq)로 전송됩니다. 완전 로컬 처리가 아닙니다.
🔑 API 연결 (최초 1회)

① Groq 키 발급 — 전사(음성→텍스트)용 · Whisper Large v3 (Groq 최고 정확도 모델) 자동 사용

  1. console.groq.com 접속 → 구글 계정으로 로그인
  2. 왼쪽 메뉴 API Keys → Create API Key 클릭
  3. 이름은 아무거나 입력(예: 협의회) → 생성된 gsk_... 키를 복사 (이 화면을 닫으면 다시 못 봅니다)
  4. 아래 칸에 붙여넣고 검증

② NVIDIA 키 발급 — AI 정리·질문용

  1. build.nvidia.com 접속 → 오른쪽 위 로그인(이메일 인증)
  2. 아무 모델이나 클릭 → 오른쪽 코드 영역의 Get API Key 버튼 클릭
  3. 생성된 nvapi-... 키를 복사해 아래 칸에 붙여넣고 검증
