💡 사용법 · 팁

사용법 — 딸각 세 번

  • ① 모드 선택: 상단에서 회의 · 상담 · 수업 중 하나
  • ② 파일 올리기 또는 바로 녹음: mp3·m4a·wav·ogg·mp4·txt·md를 끌어다 놓거나 음성 / 미디어 / 음성+미디어 녹음 버튼
  • ③ 정리 시작: 옵션 고르고 클릭 — 결과에 질문도 가능
  • 최초 1회만 무료 API 키 2개 연결이 필요합니다 (연결 창에 발급 안내 · 카드 등록 없음)

모드별로 뭐가 달라지나요?

  • 📋 회의: 개요 · 안건별 논의 · 결정사항 · 후속조치 (협의회·부장회의 등)
  • 💬 상담: 개요 · 경위 · 진행 내용 · 상담자 소견/조치 · 추수 지도 (평가·낙인 표현을 피하고 사실 위주로 기록)
  • 📚 수업: 학습목표 · 수업 전개 · 판서/핵심 정리 · 학생 질문 · 과제/다음 차시
  • 모드를 바꾸면 정리 형식 · 정보 입력칸 · 질문 예시 · 파일명이 함께 바뀝니다

이 도구의 장점

  • 🗨️ 결과에 AI 챗으로 질문 — 이 도구만의 기능: 정리 끝난 결과를 근거로 "결정사항만 다시 알려줘"처럼 대화하듯 추가 질문·재가공 요청 가능 (클로바노트에는 없는 기능)
  • 자동 화자 분리: "화자1 · 화자2 …"로 발언자를 구분해 전사하고 정리에도 반영 (실측: 20분 녹음에서 5명 구분)
  • 빠른 처리: 통째로 전송해 한 번에 처리 (실측: 20분 녹음 약 10초)
  • 원하는 형태로: 모드별 구조 · 시간순 · 핵심만 × 개조식 · 격식체 · 서술형
  • 내 기기에만: 녹음·내용은 서버에 저장되지 않고, 정리 결과·질문 기록만 내 브라우저 보관함에 저장(삭제 가능) · API 키도 내 브라우저에만

클로바노트와 뭐가 다른가요?

  • 🗨️ AI 챗 질문 — 이 도구만의 기능: 클로바노트는 정리된 내용을 대화하듯 다시 질문할 방법이 없지만, 이 도구는 결과를 근거로 계속 물어보고 재가공을 요청할 수 있음
  • 한 곳에서 끝: 브라우저에서 녹음 → 전사 → 정리 → 질문까지 (앱↔도구 이동 없음)
  • 무료 한도(분 기준): 클로바노트는 월 300분(음성 데이터를 네이버 AI 학습에 활용하는 데 동의하면 600분) · AI요약 월 15회 제한 / 이 도구는 약 42,000분 — 월 한도·횟수 제한 없음
  • 자유도: 고정 요약이 아니라 모드·형식·문체를 골라 문서에 바로 쓰는 형태로
  • 저장 정책: 네이버 서버 계정 보관 vs 내 브라우저에만 (서버 저장 없음)

🔴 바로 녹음하기 — 3가지 방식

  • 🎙️ 음성 녹음: 마이크만 — 일반 회의·상담·수업
  • 🔊 미디어 소리만: 컴퓨터에서 나는 소리만 — 영상 자료·온라인 강의 (PC 크롬·엣지 전용)
  • 🎙️+🔊 음성 + 미디어: 내 목소리와 미디어 소리를 한 파일로 — 영상을 틀며 설명하는 수업 (소리 겹침 방지를 위해 이어폰 권장)
  • ⚠️ 미디어 녹음 시 필수: 화면 공유 창에서 "시스템 오디오 공유"(전체 화면) 또는 "탭 오디오 공유"(크롬 탭)를 반드시 체크 — 안 하면 소리가 안 담깁니다 · 창(window) 공유는 소리 캡처 불가 · 맥은 탭 공유만 가능
  • 휴대폰·태블릿: 미디어 소리 녹음은 브라우저가 지원하지 않아요 — 기기의 화면 녹화로 녹화한 뒤 그 영상 파일(mp4·mov)을 올리면 됩니다
  • 시작: 녹음 버튼 클릭 → 마이크 권한 허용 (최초 1회)
  • 확인: 녹음 중 초록 막대가 움직여야 정상 · 완료 후 🎧 미리 듣기로 재생 확인
  • 막대가 안 움직이면: 윈도우 설정 → 시스템 → 소리 → 입력에서 마이크·볼륨 확인, 개인 정보 및 보안 → 마이크에서 브라우저 접근 허용
  • 권한이 차단됐다면: 주소창 자물쇠 → 마이크 → 허용 · file://로 열었다면 주소창 오른쪽 마이크(차단) 아이콘 클릭
  • 일시정지·완료: 쉬는 시간엔 일시정지 후 이어서 · 녹음 완료를 누르면 파일이 자동으로 올라감
  • 다른 창·앱 작업: PC는 다른 창에서 일해도 녹음 유지 · 휴대폰·태블릿은 화면을 끄거나 앱을 바꾸면 끊길 수 있어요(특히 아이폰) — 이럴 땐 기본 녹음 앱으로 녹음 후 파일 올리기 추천
  • 끊김 자동 감지: 녹음 중 마이크가 끊기면 즉시 알리고, 그때까지의 녹음은 파일로 살려줍니다
  • 주의: 완료 전 창을 닫으면 녹음이 사라집니다 · 긴 녹음은 전원 연결 권장

결과 다듬기 · 보관함

  • 정보 입력: 옵션 카드의 이름·일시·장소·참석자가 머리말과 파일명에 자동 반영
  • 화자 이름: "화자1 → 김OO" 입력 후 일괄 적용 — 정리본·원문에 한 번에
  • 원문 검색: 전사 원문 카드를 펼쳐 키워드 검색 · ▲▼로 이동
  • 🗂️ 보관함: 정리가 끝나면 결과·질문 기록이 자동 저장 — 화면 왼쪽 아래 보관함에서 불러오기·삭제 (녹음 파일은 저장되지 않음)

API 연결

무료 API 키 2개로 모든 기능이 작동합니다 — Deepgram(전사·화자 구분) + Groq(정리·질문).
키는 이 브라우저에만 저장되며 외부로 새지 않습니다.

① Deepgram 키 녹음 전사 · 화자 구분 담당
발급 방법 보기 (약 3분 · 카드 등록 없이 $200 무료 크레딧)
  1. console.deepgram.com/signup 접속 → 구글 계정으로 무료 가입 (카드 등록 없음 · $200 크레딧 자동 지급 — 20분 녹음 약 2,000회 분량)
  2. 왼쪽 메뉴 API Keys → Create a New API Key 클릭
  3. 이름은 아무거나(예: 협의회) → 만료(Expiration)는 Never, 권한(Role)은 Default 그대로 → Create Key
  4. 딱 한 번만 표시되는 40자 키를 복사해 위 칸에 붙여넣기
녹음 파일 없이 텍스트 파일만 정리할 거라면 비워두어도 됩니다.
② Groq 키 AI 정리 · 질문 담당 · 필수
발급 방법 보기 (약 2분 · 무료)
  1. console.groq.com 접속 → 구글 계정으로 무료 로그인
  2. 왼쪽 메뉴 API Keys → Create API Key 클릭
  3. 이름은 아무거나(예: 협의회) → gsk_ 로 시작하는 키 복사 (한 번만 표시되니 꼭 저장)
  4. 복사한 키를 위 칸에 붙여넣기
