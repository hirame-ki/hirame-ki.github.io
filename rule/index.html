API 연결

엔비디아 무료 API 키를 연결하면 시작합니다. 키는 이 브라우저에만 저장되며, NVIDIA 호출 시 중계 서버를 거쳐 전달됩니다(서버에 저장·기록되지 않음).

  1. build.nvidia.com 접속 후 무료 가입 (신용카드 불필요)
  2. build.nvidia.com/models 에서 아무 모델이나 클릭해 열기
  3. 모델 상세 페이지 우측의 Get API Key 클릭
  4. nvapi- 로 시작하는 키 복사 (한 번만 표시되니 꼭 저장)
  5. 위 칸에 붙여넣고 연결

규정나침반 사용법

이 서비스의 문서 분석과 답변 생성은 세계적 AI 기업 엔비디아(NVIDIA)의 공식 AI 서버(NIM)에서 이뤄집니다. 별도 프로그램 설치 없이, 엔비디아가 무료로 개방한 최신 AI 모델을 그대로 사용합니다. API 키와 문서는 이 브라우저에만 저장되며, 중계 서버에 기록되지 않습니다.

🧭 3단계로 끝나는 사용법

  • API 연결 — 처음 한 번, 엔비디아 무료 키(nvapi-)를 발급받아 연결합니다. 신용카드가 필요 없고, 키는 자동 저장되어 다음 방문부터는 바로 시작됩니다.
  • 문서 등록 — 왼쪽에 내 규정·지침 파일(PDF · DOCX · HWPX · TXT)을 끌어다 놓습니다. 처음 한 번만 분석하며 이후엔 저장됩니다.
  • 질의 — 상황이나 질문을 적고 [질의]를 누르면, 오른쪽에 근거 조항과 함께 답변이 나타납니다. 답변 아래 채팅창에서 이어서 질문할 수 있습니다.

💡 더 잘 쓰는 팁

  • 질문은 구체적으로 — "연차 규정 알려줘"보다 "연차는 며칠 전까지 누구에게 신청해야 하나요?"처럼 물으면 정확한 조항을 찾습니다. 조항 번호("제15조")로 바로 물어도 됩니다.
  • 근거 조항 수 — 핵심만 빠르게 보려면 3개, 여러 조항을 두루 검토하려면 8개를 선택하세요.
  • 문서 체크박스 — 등록된 문서 중 체크한 문서에서만 답을 찾습니다. 질문과 관련된 규정집만 켜두면 더 정확해집니다.
  • 질의 기록 — 모든 질의는 자동 저장됩니다. 왼쪽 기록을 클릭하면 답변·근거·채팅까지 복원되고, [내보내기]로 마크다운 파일로 받을 수 있습니다.
  • 다시 생성 — 답변이 아쉬우면 답변 아래 [다시 생성]으로 같은 근거에서 다시 작성합니다.
  • 첫 답변이 느릴 때 — 무료 개방 서버라 혼잡 시간엔 첫 문장까지 30초~1분 걸릴 수 있습니다. 멈춘 게 아니니 잠시 기다려 주세요.

⚠ 꼭 알아두세요

  • 올린 문서 내용과 질문은 답변 생성을 위해 엔비디아 서버로 전송됩니다. 개인정보·기밀 문서는 올리지 마세요.
  • 답변은 근거를 정리한 참고 자료입니다. 최종 판단·처분은 반드시 원문과 담당 기구의 검토를 거치세요.
  • 스캔(이미지) PDF와 구형 HWP는 지원하지 않습니다. HWP는 한글에서 PDF·HWPX로 저장 후 올려주세요.
