1 API 연결

엔비디아 무료 API 키를 연결하세요. 키는 이 브라우저에만 저장되며, NVIDIA 호출 시 중계 서버를 거쳐 전달됩니다(서버에 저장·기록되지 않음). 공용 PC에서는 사용 후 해제를 눌러 주세요.

  1. build.nvidia.com 접속 후 무료 가입 (신용카드 불필요)
  2. 아무 모델이나 열고 우측 Get API Key 클릭
  3. nvapi- 로 시작하는 키 복사 (한 번만 표시되니 꼭 저장)
  4. 위 칸에 붙여넣고 연결 — 이 안내는 자동으로 닫힙니다
