# PRD — 상담 일지 (Counsel Log)

| 항목 | 내용 |
|---|---|
| 제품명 | 상담 일지 — 학생별 상담 기록 타임라인 |
| 형태 | 단일 HTML 파일 웹앱 (`index.html`), 외부 리소스·서버 없음 |
| 제작 | @hirame.ki |
| 문서 버전 | v1.0 (2026-09-17) |

## 1. 배경 및 문제
- 담임·상담 교사의 상담 기록이 수첩, 한글 파일, 메신저 메모 등으로 흩어져 있어 **학생별 누적 흐름을 한눈에 보기 어렵다.**
- 학부모 상담 직전에 과거 기록을 뒤져 요약·발문을 준비하는 데 시간이 많이 든다.
- 학생 개인정보가 포함되어 있어 **클라우드 서비스·회원가입형 도구 사용이 부담**스럽다.

## 2. 목표
1. 설치·로그인 없이 파일 하나로 열어 바로 쓰는 상담 기록 도구
2. 학생별 상담 내역을 시간순 타임라인으로 정리
3. 누적 기록을 바탕으로 학부모 상담 준비용 AI 프롬프트를 자동 생성
4. 모든 데이터는 사용자 브라우저(localStorage)에만 저장

### 비목표 (Non-goals)
- 서버 동기화, 다중 사용자 협업, 계정 시스템
- 앱 내부에서 AI API 직접 호출 (프롬프트 생성까지만 제공)

## 3. 대상 사용자
| 페르소나 | 니즈 |
|---|---|
| 담임 교사 | 반 전체 학생의 상담 이력 관리, 학부모 상담 주간 대비 |
| 상담·진로 교사 | 학업/생활/진로 유형별 기록 누적 |
| 학원·교습소 강사 | 간단한 학생 관리와 보호자 상담 준비 |

## 4. 핵심 기능 (현재 구현 기준)
### 4.1 반·학생 관리
- 반 생성/삭제 (반 관리 모달), 헤더 드롭다운으로 반 전환
- 학생 일괄 등록: 한 줄에 `번호 이름` (공백·쉼표·점 구분), 번호 생략 시 자동 부여
- 좌측 학생 목록 + 학생 검색

### 4.2 상담 기록
- 날짜, 유형(학업 / 생활 / 진로 / 기타), 내용 입력
- 학생별 타임라인 표시, 기록 수정·삭제

### 4.3 학부모 상담 프롬프트 생성
- 입력: 상담 예정일(선택), 방식(대면/전화/화상/서면), 기록 기간(전체/3·6개월/1년), 다룰 내용(선택)
- **개인정보 보호 옵션**: 학생 이름 → ○○, 반 이름 제외
- 출력: 기록 정리·발문·예상 답변을 요청하는 프롬프트 → 복사 / 파일 저장

### 4.4 데이터 관리
- 엑셀(CSV) 내보내기
- JSON 백업 파일 저장 / 복원, 저장 현황 표시
- 브라우저 데이터 삭제 시 유실 경고 안내

### 4.5 디자인 설정
- 포인트 컬러(네이비/인디고/슬레이트), 배경 톤(아이보리/쿨 그레이), 정보 밀도(넉넉/조밀), 다크 모드
- 설정은 localStorage에 유지

## 5. 비기능 요구사항
| 구분 | 요구사항 |
|---|---|
| 프라이버시 | 네트워크 전송 없음, 외부 CDN·폰트·아이콘 미사용(인라인 SVG) |
| 이식성 | 최신 Chrome/Edge/Safari/Firefox, 오프라인 동작 |
| 성능 | 파일 1개 약 80KB, 즉시 로드 |
| 접근성 | 키보드 조작 가능한 모달·버튼, 대비 확보한 색 토큰, 다크 모드 |
| 공유 | OG/Twitter 메타태그, 1200×630 썸네일(`images/og-thumbnail.png`) |

## 6. 사용자 흐름
1. 반 관리 → 반 생성 → 학생 일괄 등록
2. 학생 선택 → 상담 추가 → 저장 → 타임라인 누적
3. 학부모 상담 전: 프롬프트 생성 → 개인정보 보호 체크 → 복사 → AI에 붙여넣기
4. 학기 말: 백업 파일 저장 / CSV 내보내기

## 7. 성공 지표
- 첫 방문 후 5분 내 첫 상담 기록 저장 비율
- 학생 1인당 평균 기록 수, 프롬프트 생성 횟수
- 백업 파일 저장 실행 비율(데이터 유실 방지)
- 공유 링크 유입 수 (블로그·SNS)

## 8. 리스크 & 대응
| 리스크 | 대응 |
|---|---|
| 브라우저 데이터 삭제로 기록 유실 | 백업 안내 강화, 마지막 백업 경과일 알림(로드맵) |
| 외부 AI에 개인정보 유출 | 익명화 옵션 기본 권장, 안내 문구 |
