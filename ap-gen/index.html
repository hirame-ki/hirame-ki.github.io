사용 가이드
1
기본 정보 입력 필수
과목명·학년을 입력합니다.
단원은 선택사항이지만 입력하면 더 구체적인 채점기준이 생성됩니다.
단원이 여러 개일 경우 줄바꿈(Enter)으로 구분하세요.
입력한 단원은 각 회차 배점 설계에서 선택 가능합니다.
2
평가 비율 설정 필수
정기고사·수행평가 반영비율 합계가 100%가 되도록 설정합니다.
정기고사·수행평가 횟수도 함께 입력하세요. 막대그래프로 비율을 확인할 수 있습니다.
3
수행평가 배점 설계 필수
회차별로 만점·기본점수·급간·합산비율을 입력합니다.
영역이 여러 개이면 영역 추가 버튼으로 추가하세요. 같은 회차의 영역은 하나의 수행평가로 처리됩니다.
단원을 입력했다면 각 회차의 평가 단원 드롭다운에서 단원을 지정할 수 있습니다. 미선택 시 AI가 자동으로 정합니다.
4
논술형·요청사항 선택
논술형 평가를 포함할 경우 해당 영역의 논술 체크박스를 선택하세요. 합산비율이 자동 계산됩니다.
원하는 수행평가 방향이나 특이사항이 있으면 요청사항란에 자유롭게 입력하세요.
5
프롬프트 생성 → AI에 붙여넣기
생성 버튼을 누르면 Claude·ChatGPT 등에 바로 쓸 수 있는 프롬프트가 만들어집니다.
① 복사 버튼으로 복사 → AI에 붙여넣기
② AI가 수행평가 목록을 추천하면 원하는 번호를 회차 순서대로 입력하세요.
예) 수행평가 3회차 → 5, 2, 7 입력 시 1회차=5번, 2회차=2번, 3회차=7번 적용
③ AI가 채점기준표·운영가이드가 포함된 파일을 생성합니다.
안내
입력 정보는 이 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
