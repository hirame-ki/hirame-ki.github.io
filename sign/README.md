# 연수 전자서명 시스템 v5

구글 시트를 데이터 저장소로 사용하는 연수(교육) 전자서명 시스템입니다.
학교뿐 아니라 교육청·연수원 등 **어떤 기관이든** 자신의 구글 시트만 준비하면 사용할 수 있습니다.

## v5 구조 — 재배포가 필요 없는 이유

```
[GitHub Pages]                     [각 기관의 구글 시트]
 index.html (공통 웹페이지)  ←fetch→  code.gs (JSON API, 최초 1회 배포)
 · 디자인/기능 업데이트는             · 연수설정 / 구성원명단 / 서명현황
   저장소 관리자가 반영               · 서명 PNG는 기관 드라이브에 저장
 · 모든 기관에 자동 적용             · 이후 수정·재배포 불필요
```

- **웹페이지(이 저장소)**: 관리자가 업데이트하면 모든 기관에 자동 반영
- **code.gs(기관별)**: 최초 1회만 붙여넣고 배포하면 끝. 다시는 손댈 일 없음
- 연결고리: 웹페이지 접속 시 각 기관의 **웹앱 배포 URL**을 입력(최초 1회)

## 기관 관리자 설치 방법 (약 10분, 최초 1회)

> 기관 관리자는 **코드와 시트 구조가 모두 갖춰진 깨끗한 시트 사본**을 공유받는 것을 전제로 합니다.
> (사본에는 Apps Script 코드가 이미 포함되어 있어 코드를 붙여넣을 필요가 없습니다)

1. 공유받은 시트에서 메뉴 [확장 프로그램] → [Apps Script] 열기
2. [배포] → [새 배포] → 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 반드시!
   - 최초 1회 권한 승인 창이 뜨면 계정 선택 후 허용
   - [배포] 후 **웹 앱 URL** 복사
3. **[⚙️ 연수설정]** 시트에 기관명(B2)·연수 목록 입력,
   **[👥 구성원명단]** 시트에 부서·성명 입력
4. 서명 웹페이지(GitHub Pages 주소)에 접속 → 복사한 URL 붙여넣기 → [연결하기]
5. 연결 완료 후 표시되는 **공유 링크와 QR**을 구성원에게 안내

<details>
<summary>빈 시트에서 처음부터 만드는 경우 (배포자용)</summary>

1. 구글 시트 새로 만들기 → [확장 프로그램] → [Apps Script]
2. 기본 코드를 지우고 `code.gs` 내용 전체 붙여넣기 → 저장
3. 시트로 돌아와 새로고침 → 메뉴 [🎓 연수서명관리] → [초기설정 실행]
4. 샘플 데이터(연수·명단)를 지워 깨끗하게 만든 뒤, 이 시트의 **사본**을 각 기관에 배포

</details>

> ⚠️ 배포는 **딱 1회**면 충분합니다. 이후 화면이 업데이트되어도 재배포할 필요가 없습니다.

## 주요 기능

- 📝 3단계 서명: 연수 선택 → 부서/성명 선택 → 캔버스 서명
- 🔒 중복 방지: 서버(시트) 차단 + 기기(브라우저) 잠금 이중 안전망
- 🖼️ 서명 이미지: 기관 드라이브에 PNG 저장 + 시트 셀 안에 자동 표시
- 🖨️ **서명등록부 출력**: 웹페이지 [서명결과 출력] → 2인 1행 표(부서·성명·서명 이미지) + 서명률 → 브라우저 인쇄/PDF 저장
- 📊 미서명 현황 집계: 시트 메뉴에서 연수별 서명/미서명 집계
- 📱 공유 링크 + QR: 연결 완료 시 자동 생성 (헤더의 🔗 버튼으로 언제든 다시 열기)
  - 링크는 배포 ID만 담은 압축형(`?s=...`)으로 만들어지고, 무료 단축 서비스(da.gd → clck.ru 순 시도)로 **단축 주소**가 자동 생성되면 QR도 그 짧은 주소로 만들어져 인식이 잘 됩니다 (단축 실패 시 압축형으로 자동 대체)

## 추가 설정 (선택사항 — [⚙️ 연수설정] 시트, 비워두면 기본 동작)

| 셀 | 설정 | 효과 |
|----|------|------|
| B18 | 🔐 출력 비밀번호 | 입력 시 [서명결과 출력]에 비밀번호 잠금 — 구성원 명단·서명 이미지 노출 방지 |
| B19 | 📢 안내문 | 입력 시 웹페이지 상단에 공지 배너 표시 |
| B20 | 🎨 대표 색상 | 셀 클릭 → 툴바 **채우기 색(페인트통)** → 원하는 색 선택 시 웹페이지 전체가 그 색으로 자동 변경 (색상코드 입력 불필요) |

시트에서 값을 바꾸면 웹페이지에 즉시 반영됩니다(새로고침 시). 코드 수정·재배포는 필요 없습니다.

## 웹페이지 배포 (저장소 관리자용)

1. 이 저장소를 GitHub에 올리고 Settings → Pages → Branch: `main` 활성화
2. 발급된 `https://<계정>.github.io/<저장소>/` 주소를 각 기관에 안내
3. `index.html` 수정 후 push하면 모든 기관에 자동 반영

로컬 미리보기: `index.html?demo=1` 로 열면 가짜 데이터로 화면을 확인할 수 있습니다.
