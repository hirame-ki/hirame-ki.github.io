## 1. 배경과 문제

쌤보드의 수업 도구 위젯은 교실에서 자주 쓰는 도구(뽑기, 타이머, 점수판 등)를 한 창에 모았지만 다음 한계가 있었다.

1. **앱을 설치해야만 쓸 수 있다.** 학교 PC, 전자칠판, 출장 수업 등 설치가 어려운 환경에서는 쓸 수 없다.
2. **한 번에 도구 하나만 보인다.** "점수판을 띄운 채로 타이머를 돌리는" 것처럼 실제 수업에서 흔한 동시 사용이 불가능하다.
3. **탭 11개가 평평하게 나열돼 있다.** 비슷한 도구끼리 묶여 있지 않아 찾는 데 시간이 걸린다.
4. **화면이 작고 딱딱하다.** 위젯 크기에 맞춘 작은 글씨, 기본 파란색, 이모지 아이콘 위주라 교실 TV로 띄웠을 때 멀리서 잘 보이지 않고 완성도가 낮아 보인다.

## 2. 목표 / 비목표

### 목표
- G1. 쌤보드 수업 도구 11종을 **독립 웹페이지**로 옮기고, 도구를 12종으로 정리한다(스톱워치와 알림 종 분리).
- G2. 도구를 **다섯 칸(서랍)** 으로 묶어 3초 안에 원하는 도구를 찾게 한다.
- G3. **2~4개 도구를 한 화면에 나란히** 띄워 함께 쓸 수 있게 한다.
- G4. 밝고 부드러우면서도 "잘 만들어졌다·고급스럽다·믿을 만하다·완성되어 있다"는 인상을 주는 시각 품질.
- G5. 교실 TV·전자칠판 거리(3~6m)에서도 핵심 숫자와 이름이 읽힌다.

### 비목표 (v1)
- 계정, 서버 저장, 여러 기기 동기화
- 학생 개인 기기와의 실시간 연동
- 성적·생활기록 등 민감 정보 처리
- 앱 스토어 배포

## 3. 사용자

| 구분 | 설명 |
|---|---|
| 주 사용자 | 담임·교과 교사. 수업 중 한 손으로 빠르게 조작하며, 화면은 교실 TV나 전자칠판에 띄운다. |
| 보는 사람 | 학생. 멀리서 화면을 보며 결과(이름, 점수, 남은 시간)를 확인한다. |
| 사용 환경 | 학교 윈도우 PC + 크롬/웨일/엣지, 1920×1080 TV 또는 전자칠판, 가끔 태블릿 |

### 대표 시나리오
1. **모둠 퀴즈 시간** — 모둠 편성 → "점수판으로" 버튼으로 모둠을 점수판에 바로 옮김 → 타이머와 나란히 띄워 문제마다 3분씩 진행.
2. **발표 순서 정하기** — 한 명 뽑기(뽑힌 친구 제외 켜짐)와 타이머를 나란히. 발표자 뽑고 1분 발표.
3. **조용한 개별 활동** — 소음 측정 + 집중 소리 + 타이머를 세 칸으로.
4. **설문·패들렛 안내** — QR 코드를 크게 띄우고 옆에 타이머.

수업의 흐름(시간 관리 → 정하기 → 함께하기 → 분위기 → 나누기) 순서로 배치했다. 칸마다 고유 색이 있고, 도구 카드·패널 머리·아이콘이 모두 이 색을 따른다.

| 칸 | 이름 | 색 | 도구 | 원래 위젯과의 관계 |
|---|---|---|---|---|
| 01 | 시간 | 코랄 `#FF8A65` | 타이머 · 스톱워치 · 알림 종 | 스톱워치/종을 둘로 분리 |
| 02 | 뽑기 | 라벤더 `#8B7CF6` | 한 명 뽑기 · 여러 명 뽑기 · 룰렛 · 사다리 타기 | 1명/N명 뽑기 이름 정리 |
| 03 | 모둠·점수 | 민트 `#2FBF9B` | 모둠 편성 · 점수판 | — |
| 04 | 교실 분위기 | 스카이 `#4A9EF5` | 소음 측정 · 집중 소리 | 백색소음 → 집중 소리 |

## 5. 기능 요구사항

### 5.1 공통
| ID | 요구사항 | 우선순위 |
|---|---|---|
| C-1 | 상단 바: 로고(처음 화면으로), **우리 반 명단** 버튼(반 이름·인원 표시), 전체 화면 버튼 | P0 |
| C-2 | 명단 관리: 여러 반 저장, 반 이름 수정, 한 줄에 한 명 입력(엑셀 붙여넣기 가능), "1번부터 N명 채우기", 반 삭제 | P0 |
| C-3 | 첫 실행 시 기본 명단 「우리 반 · 1번~24번」으로 바로 사용 가능 | P0 |
| C-4 | 명단·점수·타이머 마지막 값·레이아웃은 브라우저(localStorage)에만 저장, 외부 전송 없음 | P0 |
| C-5 | 모든 소리는 파일 없이 Web Audio로 합성(차임, 틱, 노이즈) | P1 |
| C-6 | 명단이 비었을 때 각 도구가 안내 문구를 보여줌 | P1 |

### 5.2 도구별
| 도구 | 핵심 요구사항 |
|---|---|
| 타이머 | 원형 진행 링 + 큰 숫자, 1/3/5/10/15/20분 프리셋, 분·초 스텝퍼, 마지막 10초 빨간색 깜박임과 5초 틱, 종료 차임. **브라우저가 다른 창 뒤에 있어도 정시에 종료음**(setInterval 기반) |
| 스톱워치 | 0.1초 단위, 시작/멈춤/계속, 구간 기록(구간 시간 + 누적 시간) |
| 알림 종 | 딩 / 딩동댕 / 모두 주목 / 정리 시간. 「모두 주목」「정리 시간」은 패널을 덮는 큰 글씨 안내판(6초 후 자동 닫힘, 누르면 닫힘) |
| 한 명 뽑기 | 점점 느려지는 슬롯 연출, 당첨 시 색종이, **한 번 뽑힌 친구 빼기**(남은 인원 표시, 모두 뽑히면 자동으로 처음부터) |
| 여러 명 뽑기 | 인원 스텝퍼, 중복 없이 뽑아 순번 칩으로 차례대로 등장 |
| 룰렛 | 우리 반 명단 / 직접 입력 전환, 파스텔 돌림판, 칸이 지날 때 틱, 감속 후 결과 표시. 직접 입력 목록 저장 |
| 사다리 타기 | 참여자(명단 앞 12명 자동)·결과 입력, 최대 16명, 이름 버튼으로 한 명씩 경로 애니메이션, 모두 공개, 다시 입력 |
| 모둠 편성 | 「모둠 수로」/「모둠 인원으로」 두 방식, 고르게 섞어 카드로 표시, **「점수판으로」** 버튼으로 점수판 팀 자동 생성 |
| 점수판 | 팀 추가·이름 바로 고치기·삭제, 큰 점수 숫자, +/− 버튼, 팀 선택 후 +1/+2/+5/+10 빠른 추가, 1위 왕관, 점수 0으로, 4모둠 만들기. 새로고침해도 유지 |
| 소음 측정 | 마이크 레벨을 표정(좋아요/조금 커요/목소리를 줄여요)과 막대로 표시, 허용 크기 슬라이더, 0.6초 이상 넘을 때만 경고(순간 소음 무시). 소리는 저장·전송하지 않음 |
| 집중 소리 | 화이트/핑크/브라운 노이즈, 부드러운 페이드 인·아웃, 음량 조절, 이음새 없는 반복 |
| QR 코드 | 주소/문장 입력 → 패널 크기에 맞춰 큰 QR, PNG 저장, 마지막 값 기억 |

### 5.3 화면 나누기 (핵심 기능)
| ID | 요구사항 | 우선순위 |
|---|---|---|
| S-1 | 진입 방법 3가지: ① 「여러 개 골라 함께 쓰기」로 카드 2~4개 선택 후 「나란히 열기」 ② 자주 쓰는 조합 버튼 ③ 도구를 연 뒤 「도구 추가」 | P0 |
| S-2 | 최대 4개. 2개: 좌우/위아래, 3개: 크게+작게(왼쪽 큰 칸)/세 칸, 4개: 2×2 | P0 |
| S-3 | 2개일 때 가운데 경계를 끌어 비율 조절(22~78%), 두 번 누르면 반반 | P1 |
| S-4 | 각 패널: 「이 도구만 크게」(포커스) ↔ 「나란히 보기로」, 닫기. Esc로 포커스 해제 | P0 |
| S-5 | 도구를 추가·닫아도 **다른 패널의 진행 상태(타이머 등)는 유지** | P0 |
| S-6 | 모든 도구는 패널 크기에 맞춰 글자·링·돌림판이 커지고 작아짐(CSS 컨테이너 쿼리). 낮고 넓은 패널에서는 타이머·룰렛이 가로 배치로 전환 | P0 |
| S-7 | 주소 뒤에 조합이 기록됨(예: `index.html#scoreboard+timer`). 즐겨찾기하면 그 조합으로 바로 열림 | P1 |
| S-8 | 처음 화면에 「이어서 쓰기」로 마지막 조합 복원 | P1 |
| S-9 | 좁은 화면(860px 이하)에서는 패널을 세로로 쌓아 스크롤 | P2 |

## 6. 디자인 원칙

### 6.1 톤
- **밝고 부드럽게**: 따뜻한 종이색 배경 `#FAF7F2`, 흰 카드, 넓은 여백, 큰 모서리(16~30px), 옅은 갈색 그림자.
- **고급스럽고 믿음직하게**: 원색 대신 채도를 한 단계 낮춘 파스텔 포인트, 잉크 네이비 `#1E2330` 본문, 이모지 대신 한 벌로 그린 라인 아이콘 30여 종.
- **아이들이 멀리서도 읽게**: 숫자는 Outfit, 한글은 Pretendard. 타이머 숫자는 링 지름의 25%, 점수는 최대 96px.

### 6.2 색 토큰
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FAF7F2` | 전체 배경 |
| `--ink` | `#1E2330` | 본문·주 버튼 |
| `--brand` / `--brand-deep` | `#FF7A5C` / `#E85E3F` | 로고 손잡이, 강조 문구, 선택 바 |
| `--time` `--pick` `--team` `--mood` `--share` | 4장 표 참고 | 서랍 칸별 색, 각각 `-soft` 옅은 배경 짝 |

### 6.3 로고
정면에서 본 2단 서랍장. 위 칸은 코랄 그라데이션(꺼낸 서랍), 아래 칸은 크림색. `assets/favicon.svg` 하나로 파비콘·상단 로고·썸네일·앱 아이콘을 모두 만든다.

### 6.4 오프닝 애니메이션 (약 3.3초, 언제든 건너뛰기)
| 시간 | 장면 |
|---|---|
| 0.1s | 서랍장이 아래에서 떠오름 |
| 0.55s | 위 칸 서랍이 앞으로 당겨지며 열림(스프링) |
| 0.95s~ | 도구 아이콘 7개가 서랍에서 튀어올라 부채꼴로 펼쳐지고 둥실 떠 있음 |
| 1.35s | 「CLASS DRAWER / 수업서랍」 워드마크 |
| 1.55s | 「꺼내면 바로, 수업이 됩니다」 |
| 3.3s | 화면이 살짝 커지며 사라지고, 서랍 칸들이 차례로 올라옴 |

- 클릭·아무 키로 즉시 건너뛰기, 오른쪽 아래 「건너뛰기」 버튼.
- 같은 브라우저 창에서는 **한 번만** 재생(sessionStorage). 처음 화면 아래 「오프닝 다시 보기」.
- 운영체제의 "동작 줄이기" 설정을 켠 사용자에게는 재생하지 않음.
- 주소에 조합(`#timer`)이 있으면 오프닝 없이 바로 도구 화면.

## 7. 비기능 요구사항
| 항목 | 기준 |
|---|---|
| 설치 | 폴더째 복사해 `index.html`을 열면 동작. 웹 호스팅(GitHub Pages, Netlify 등)에 그대로 올릴 수 있음 |
| 외부 의존 | 글꼴(Pretendard·Outfit), QR 라이브러리(qrcodejs)만 CDN. 오프라인이면 기본 글꼴로 대체되고 QR만 안내 문구 표시 |
| 브라우저 | 최신 크롬·엣지·웨일·사파리(컨테이너 쿼리 지원 버전) |
| 성능 | 첫 화면 1초 이내, 애니메이션 60fps 목표, 이미지 파일 없이 SVG·CSS로 그림 |
| 접근성 | 키보드 포커스 링, Esc 닫기, 대화상자 aria 속성, 동작 줄이기 대응 |
| 개인정보 | 명단은 브라우저 안에만. 마이크는 소음 측정 중에만 켜지고 녹음·전송 없음 |
