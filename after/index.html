방과후 한눈에 — 설치·업데이트 v1.2.0

Apps Script에는 파일 2개(Loader, appsscript.json)만 넣습니다. 프로그램 본체는 자동으로 받아 시트에 보관하고, 업데이트도 버튼 한 번이면 됩니다.

처음 설치

  1. 구글 시트에서 [확장 프로그램] → [Apps Script]
  2. 편집기의 Code.gs 안을 모두 지우고 아래 Loader 코드를 붙여넣기 (파일 이름은 그대로 둬도 됩니다)
  3. [프로젝트 설정(톱니바퀴)] → "appsscript.json" 매니페스트 파일 표시 켜기 → 편집기의 appsscript.json 내용을 아래 것으로 바꾸기
  4. Ctrl+S 저장 → 시트 새로고침 → [🏫 방과후 관리] → [프로그램 설치·복구] → 권한 허용
  5. "설치했습니다"가 나오면 시트 새로고침 → [① 처음 설정하기]
  6. 웹앱 배포: [배포] → [새 배포] → 웹 앱 (실행: 나 / 액세스: 모든 사용자)

예전 버전(v1.1.x)에서 넘어오기 — 한 번만

  1. Apps Script 왼쪽 파일 목록에서 appsscript.json을 뺀 모든 파일을 삭제 (Code, Logic, Setup, Cycle, Update, Index, Apply, Board, SetupDialog, LinksDialog, Styles, Client)
  2. [＋] → [스크립트]로 Loader 파일을 만들어 붙여넣기 → appsscript.json도 바꾸기 → 저장
  3. 시트 새로고침 → [🏫 방과후 관리] → [프로그램 설치·복구] → 권한 허용
  4. [배포] → [배포 관리] → 연필 → 버전 [새 버전] → [배포] (이번 한 번만, 웹앱 주소는 그대로)

학생·강좌·신청 데이터는 시트에 있으므로 그대로 남습니다.

업데이트 (v1.2부터)

  • 새 버전이 나오면 관리자 화면 위쪽과 시트를 열 때 알림이 뜹니다.
  • [지금 업데이트] 또는 시트 메뉴 [업데이트 확인·설치] 한 번 — 붙여넣기·재배포 필요 없음
  • 문제가 있으면 시트 메뉴 [이전 버전으로 되돌리기]

v1.2.0에서 바뀐 점 (2026-10-16)

  • 불러오기 구조로 바뀌었습니다. Apps Script에는 파일 2개(Loader, appsscript.json)만 넣고, 이후 업데이트는 [업데이트 확인·설치] 버튼 한 번이면 됩니다. 붙여넣기나 다시 배포할 필요가 없습니다.
  • 예전 버전(v1.1.x)은 안내 페이지의 「예전 버전에서 넘어오기」를 한 번만 따라 하면 됩니다. 데이터는 그대로입니다.
  • 시트 메뉴 [이전 버전으로 되돌리기]가 생겼습니다.
  • 구글이 화면 코드 속 "//" 뒤를 지워 관리자 화면이 열리지 않던 문제("줄 1388" 오류)를 고쳤습니다.
  • 더 이상 "스크립트 프로젝트 관리·배포" 권한을 요청하지 않습니다.
