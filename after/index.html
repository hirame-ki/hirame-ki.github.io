방과후 한눈에 — 설치·업데이트 v1.1.1

처음 설치 (코드 붙여넣기)

  1. 구글 시트에서 [확장 프로그램] → [Apps Script]를 엽니다.
  2. 아래 목록 순서대로 편집기에 같은 이름의 파일을 만듭니다. 스크립트는 [＋] → [스크립트], HTML은 [＋] → [HTML]. 확장자는 입력하지 않습니다.
  3. [코드 복사] → 편집기 파일 안을 모두 지우고(Ctrl+A → Delete) Ctrl+V.
  4. 마지막 appsscript까지 넣고 Ctrl+S 저장 → 시트 새로고침 → [🏫 방과후 관리] 메뉴가 나오면 끝.

이미 쓰고 있다면 (업데이트)

  • 시트 메뉴 [🏫 방과후 관리] → [업데이트 확인·설치] 한 번이면 됩니다. 관리자 화면 위쪽 띠의 [지금 업데이트]도 같습니다.
  • 자동 업데이트를 쓸 수 없는 계정이면 왼쪽에서 「이번에 바뀜」 표시가 있는 파일만 붙여넣고, 웹앱은 [배포 관리] → 새 버전으로 바꾸세요.

v1.1.1에서 바뀐 점 (2026-10-16)

  • 학교 망에서 외부 주소(cdnjs·jsdelivr)가 막히거나 느릴 때 관리자·학생 화면이 "불러오는 중…"에서 멈추던 문제를 고쳤습니다. QR 라이브러리를 코드 안에 넣었습니다.
  • 화면이 30초 동안 응답이 없거나 오류가 나면, 멈춰 있지 않고 원인과 해결 방법(새로고침, 시크릿 창)을 보여 줍니다.
