사용 가이드
1
영역 선택 필수
교과세특·행동특성·자율·동아리·봉사·진로활동 중 작성할 영역을 선택합니다. 교과세특은 과목명도 함께 입력하세요.
2
기본 정보 입력 필수
학년(중1~고3), 글자수 목표, 진로 희망 등을 입력합니다. 진로 입력 시 연계 문장이 강화됩니다.
3
학생 사례 입력
교사가 관찰한 수업 장면, 에피소드, 행동을 자유롭게 적으세요. 여러 개 나열해도 됩니다.
4
키워드 선택
분야 버튼을 클릭하면 펼쳐집니다. 여러 분야·키워드 동시 선택 가능합니다.
5
문체·버전 선택 / 스타일·중복 설정 선택
문체와 버전 수를 고르세요. 내 문장 스타일 입력 및 중복 방지 설정은 선택사항입니다.
6
프롬프트 생성 → AI에 붙여넣기
생성 버튼을 누르면 프롬프트가 화면 오른쪽에 표시됩니다. 복사 버튼을 눌러 Claude·ChatGPT 등에 붙여넣으세요.
2026 기재요령 반영
입력 불가 용어(대회·수상·자격증·소논문 등)가 프롬프트에 자동 포함
종결어미 ~임/~함/~됨 통일, 이름·특수기호 금지 지침 자동 반영
중1~고3 학년 선택, 봉사활동 1~2학년/3학년 차이 반영
