# 슬라이드 뚝딱 (수업 슬라이드 스킬·프롬프트 웹앱)

교사가 웹앱에서 옵션을 고르면 **스킬 파일**(SKILL.md·ZIP) 또는 **복사용 프롬프트**를 만들어 주는 웹앱이다.
교사는 그 스킬·프롬프트에 **수업자료 + 디자인 참조(템플릿 이미지 또는 캔바·미리캔버스 링크)**를 넣어
Claude·ChatGPT·Gemini에서 전문 디자이너 수준의 HTML 수업 슬라이드를 받는다.
개인 도구가 아니라 **다른 선생님들과 공유하기 위한 도구**다.

## 작업 원칙 (사용자 선호)

- 설명과 보고는 간단 명료하게.
- 추측으로 결론 내지 않는다. 외부 서비스의 메뉴 이름·요금제·제한은 06_SOURCES.md 기준으로 쓰고, 바뀌었을 수 있으면 공식 문서로 다시 확인한다. 확인 못 한 내용은 지어내지 말고 사용자에게 보고한다.
- 자료 조사는 항상 최신 자료 기준.
- 코드를 고칠 때는 항상 **마지막으로 수정한 파일**을 기준으로 고친다. 이전 출력이나 오래된 사본으로 덮어쓰지 않는다.

## 기술 제약

- 웹앱은 **단일 파일 `index.html`** (HTML·CSS·JS 인라인). 빌드 도구·프레임워크·서버 없음.
- 무료 정적 호스팅: GitHub Pages. 배포 안내는 **GitHub 웹 업로드 방식**으로 한다 (터미널 git 명령으로 안내하지 않는다).
- 외부 라이브러리는 버전을 고정한 CDN만 쓴다: JSZip(ZIP 생성), Pretendard(웹폰트). 그 밖에 추가하면 이유를 남긴다. 버전은 나온 지 2주 이상 지난 안정 버전으로 고정한다.
- 슬라이드 엔진(`engine/slide-engine.css`, `engine/slide-engine.js`)은 웹앱과 별개 파일이다. 생성된 슬라이드가 jsDelivr로 불러 쓴다 (01_SPEC §8).
- 옵션은 JS 객체 하나(`OPTIONS`)로 관리하고 UI·? 설명·미리보기·출력 문구를 모두 여기서 만든다. 02_OPTIONS.md와 1:1로 맞춘다.
- 설정 저장: URL 해시(공유 링크) + localStorage(최근 설정, 반드시 try/catch).
- 개인정보를 수집·전송하지 않는다 (서버·분석 도구 없음).

## 작업 순서

1. 웹앱 뼈대 + 디자인 토큰(05) + 3단계 흐름(① AI 고르기 → ② 옵션 → ③ 받기)
2. 옵션 데이터·UI: 카테고리, 칩, ? 팝오버, 미리보기 모달
3. 슬라이드 엔진 + 레퍼런스 덱 (미리보기 모달도 이 엔진으로 재생)
4. 출력 생성: SKILL.md 조립·검증, AI별 ZIP, AI별 프롬프트, 옵션 한 줄, 오프라인 파일 변환
5. 안내: AI별 설치·커넥터·권한 안내, 처음 쓰는 분 가이드, 발표 단축키, 자주 묻는 질문
6. 검수: 03의 품질 체크리스트, 접근성, 모바일, 3개 AI 실제 업로드·생성 테스트 → docs/TEST_LOG.md

각 단계가 끝나면 한 일과 확인 방법을 3줄 이내로 보고한다.

## 완료 기준

- 처음 온 교사가 설명 없이 3단계로 스킬 또는 프롬프트를 받는다.
- 모든 옵션에 ? 설명이 있고, 눈에 보이는 효과가 있는 옵션은 미리보기 팝업에서 실제로 재생된다.
- 생성된 SKILL.md가 03 §8 검증 규칙을 통과하고, ZIP 구조가 AI별 요구와 맞는다.
- 레퍼런스 덱과 실제 생성 결과가 03 §5 품질 체크리스트를 통과한다.
- 3개 AI에서 실제로 업로드·붙여넣기·생성한 결과를 docs/TEST_LOG.md에 남긴다.
- 360px 모바일 화면과 키보드만으로도 모든 기능을 쓸 수 있다.
