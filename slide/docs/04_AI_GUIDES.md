# 04. AI별 안내 문구 (웹앱 '설치·연결 안내'의 원본)

- 확인일: **2026-11-20**. 근거는 06_SOURCES.
- 메뉴 이름은 영어 화면 기준으로 확인한 것이다. 한국어 화면 표기는 구현할 때 실제 화면으로 확인해 바꾼다 (**확인 필요** 표시).
- 웹앱 표시: AI 탭 → [스킬 설치] [프롬프트 쓰기] [커넥터 연결] [권한 설정] [결과 저장] 카드. 카드마다 "화면이 다르면 알려 주세요" 링크와 확인일을 작게 표시.
- 문구 규칙: 단계는 번호 목록, 한 단계에 행동 하나, 누를 버튼 이름은 굵게.

## 2. Claude

### 2-1. 스킬 설치
1. **설정 → 기능(Capabilities)**에서 **코드 실행 및 파일 생성**을 켭니다. (새 화면에서는 이름이 **Create and edit files**로 보일 수 있어요)
2. 왼쪽 메뉴에서 **사용자 지정**을 누르고 **Skills** 탭을 엽니다. (주소: claude.ai/customize/skills)
3. 오른쪽 위 **추가** → **Skill 업로드**를 누릅니다. (메뉴에는 Skill 업로드 · Skill 만들기 · Claude로 만들기가 있음)
4. 받은 `lesson-slides.zip`을 끌어다 놓거나 골라 넣고, 아래 **업로드**를 누릅니다. (.zip · .skill · .md를 받음, 올리기 전에 이름·설명 미리보기와 보안 스캔이 나옴)
5. **Skill 업로드됨**이 뜨고 스킬이 켜져 있는지 확인합니다.
- 2~5번은 2026-11-20 실제 한국어 화면(Max 계정)으로 확인. 1번의 한국어 메뉴 이름은 **확인 필요**.
- 사용: 새 대화에 수업자료 + 템플릿 이미지 + 옵션 한 줄을 넣고 "슬라이드 만들어줘". Claude가 알아서 스킬을 씁니다.
- 업로드 오류가 나면: 폴더 이름과 스킬 이름이 다르거나, SKILL.md가 없거나, 이름·설명에 쓸 수 없는 문자가 있거나, ZIP이 너무 큰 경우예요. 웹앱에서 다시 받아 주세요. (웹앱이 미리 검사하므로 정상이라면 생기지 않아야 함)

### 2-2. 프롬프트 쓰기
1. 웹앱의 **프롬프트 복사하기**를 누릅니다.
2. Claude 새 대화에 붙여 넣고, 맨 아래 '수업자료'·'디자인 참조' 자리에 자료를 붙여 넣거나 파일을 첨부합니다.
3. 보냅니다.

### 2-3. 캔바 커넥터 연결 (링크 방식·직접 수정을 쓸 때만)
1. 대화창 왼쪽 아래 **+** → **커넥터(Connectors)** → **커넥터 관리(Manage connectors)**를 누릅니다.
2. **+**(커넥터 둘러보기)를 눌러 **Canva**를 검색합니다.
3. **연결(Connect)** → 캔바에 로그인하고 허용합니다.
4. 대화창 **+ → 커넥터**에서 Canva가 켜져 있는지 확인합니다.

### 2-4. 권한 설정 — 모두 '항상 허용'
1. **설정 → 커넥터(Connectors) → Canva → 도구 권한(Tool permissions)**으로 갑니다.
2. 도구들을 모두 **항상 허용(Always allow)**으로 바꿉니다.
3. 대화 중에 승인 창이 뜨면 **항상 허용**을 누릅니다.
- 알아 두기
  - '항상 허용'은 Claude가 매번 묻지 않고 캔바 디자인을 읽고 고칠 수 있다는 뜻이에요. 여러 사람이 함께 쓰는 학교 계정이라면 고치는 도구는 **승인 필요(Needs approval)**로 두는 것도 좋아요.
  - 캔바에 저장하기 직전에는 '항상 허용'이어도 미리보기를 보여 주고 확인을 묻는 게 정상이에요.
  - '항상 허용'으로 해 두었는데 다시 묻는 경우가 보고되어 있어요. 그때는 승인 창에서 다시 **항상 허용**을 눌러 주세요.

### 2-5. 미리캔버스 커넥터 (**확인 필요**)
- 2026-11-20 기준 Claude에서 미리캔버스 커넥터가 연결되어 동작하는 것은 확인했지만, 다른 사람이 연결하는 공개 경로(커넥터 목록 등재 여부·연결 주소)는 확인하지 못했다.
- 구현 전 미리캔버스 공식 안내를 확인해 2-3과 같은 형식으로 채운다. 확인 전까지 웹앱에서는 "미리캔버스 연결 방법은 미리캔버스 안내를 확인해 주세요"로 표시한다.
- 연결된 경우 쓸 수 있는 것: 내 디자인 편집 링크(…/v2/design2/…) 읽기·페이지 미리보기, 페이지 내용 수정·추가·삭제, 브랜드 키트 양식 등록(PDF·PowerPoint)과 선택, 파일 받기(PNG·JPG·PDF·PPTX·MP4·GIF, 커넥터로 만든 디자인만).

### 2-6. 결과 저장
- 대화에 나온 파일 카드의 **다운로드** 버튼으로 저장 → 파일을 더블클릭해 브라우저로 엽니다.
- Claude 오른쪽 미리보기 창에서는 엔진(jsDelivr의 CSS·JS)이 불러와지지 않아 꾸밈 없이 글만 보인다 (2026-11-20 확인, 01 §8-1의 확인 필요 항목). 저장해서 브라우저로 열면 정상이다.

## 3. ChatGPT

### 3-1. 스킬 설치
1. **Skills(스킬)** 페이지로 갑니다.
2. **Create(만들기)** → **Upload from your computer(컴퓨터에서 업로드)**를 누릅니다.
3. 받은 `lesson-slides.zip`을 고릅니다.
- 계정 종류에 따라 스킬 메뉴가 없을 수 있어요. 그럴 땐 프롬프트 방식을 쓰세요.
- **확인 필요**: Skills 페이지로 가는 메뉴 위치, 한국어 표기, ZIP 구조(폴더 한 겹) 인식 여부.

### 3-2. 프롬프트 쓰기와 저장
1. 웹앱의 **프롬프트 복사하기** → ChatGPT에 붙여 넣고 자료를 붙이거나 첨부해 보냅니다.
2. 결과로 나온 HTML 코드 블록에서 **미리보기(Preview)**로 확인합니다.
3. 코드 블록을 **복사** → 메모장에 붙여 넣고 `수업제목.html`로 저장합니다. (파일 형식: 모든 파일, 인코딩: UTF-8)
- 참고: 2026-05-28부터 GPT-5.5 모델에서 캔버스(Canvas)가 빠지고 대화 안 코드 블록으로 바뀌었다는 자료가 있다 (제3자 자료 → OpenAI 공지로 **재확인**). 그래서 '캔버스'로 안내하지 않는다.

### 3-3. 캔바 앱 연결 (링크 방식을 쓸 때만)
1. **설정 → 앱(Apps & connectors)**으로 갑니다. (계정에 따라 **Apps**로만 보여요)
2. **Canva**를 찾아 **연결(Connect)** → 캔바에 로그인하고 허용합니다.
3. 대화에서 "Canva로 …"라고 요청하거나 Canva 앱을 골라 씁니다.
- 캔바 무료·교육용 계정도 연결된다는 안내가 있다 (제3자 확인 → 캔바 공식 안내로 **재확인**).
- **확인 필요**: ChatGPT의 Canva 앱이 공유 링크의 디자인을 읽고 사본을 고칠 수 있는지. 테스트 후 1장 비교표 배지를 갱신한다.

### 3-4. 권한 설정
- 연결할 때 요청하는 권한을 허용하고, 대화 중 확인 창이 뜨면 허용합니다.
- **확인 필요**: '항상 허용' 같은 도구별 설정이 있는지와 위치.

## 4. Gemini

### 4-1. 스킬 설치
1. 웹(gemini.google.com) 또는 Mac 앱에서 **Skills(스킬)** 페이지로 갑니다.
2. **Create(만들기)** → **Upload(업로드)**를 누릅니다.
3. 받은 `SKILL.md` 파일, 또는 `lesson-slides-gemini.zip`을 고르고 **Open(열기)**를 누릅니다.
4. 폴더째 올릴 때는 폴더 이름이 스킬 이름(`lesson-slides`)과 같아야 해요.
- 스킬은 2026-10-13부터 순차 배포 중이에요(11월 중순 완료 예정). 메뉴가 안 보이면 프롬프트 방식을 쓰세요.
- 만든 스킬은 Skills 페이지에서 동료에게 공유할 수 있어요 (2026-11-16 공지).

### 4-2. 프롬프트 쓰기와 저장
1. 입력창 아래 도구에서 **Canvas**를 고릅니다.
2. 웹앱의 **프롬프트 복사하기** → 붙여 넣고 자료를 붙이거나 첨부해 보냅니다.
3. Canvas **미리보기**로 확인합니다.
4. **코드(Code)** 보기에서 코드를 복사해 `수업제목.html`로 저장하거나, **공유 및 내보내기(Share & export) → 공유(Share)**로 링크를 만듭니다.

### 4-3. 캔바 연결된 앱 (**확인 필요**)
1. **설정 → 앱(연결된 앱)**에서 **Canva**를 켭니다.
2. 대화에서 `@Canva`로 부릅니다.
- 2026-05-19부터 영어권 일부 시장부터 순차 배포. 한국어 계정 제공 여부 확인 필요. 안 보이면 이미지 방식을 쓰세요.

### 4-4. 권한 설정
- **확인 필요**.

## 5. 자주 묻는 질문 (웹앱 FAQ 원본)

| 질문 | 답 |
|---|---|
| 템플릿 이미지는 어떻게 받나요? | 캔바에서 템플릿을 열고 **공유 → 다운로드 → PNG**를 고른 뒤, 표지 1장과 본문 2~3장만 골라 받으세요. (메뉴 이름 **확인 필요**) |
| 결과 파일은 어떻게 여나요? | 받은 .html 파일을 더블클릭하면 브라우저(크롬·엣지·웨일)로 열려요. |
| 발표는 어떻게 하나요? | F 키로 전체 화면, → 키나 클리커로 넘겨요. ? 키를 누르면 단축키가 나와요. |
| 인터넷이 안 되는 교실이에요 | 웹앱의 **오프라인 파일로 바꾸기**에 파일을 넣어 다시 받으세요. |
| 사진은 어떻게 넣나요? | 점선 사진 칸을 클릭하거나 사진을 끌어다 놓으세요. 칸에 적힌 검색어로 찾으면 편해요. |
| 글자를 고치고 싶어요 | E 키를 누르면 바로 고칠 수 있고, **저장**을 누르면 고친 파일을 받아요. |
| PDF로 저장하고 싶어요 | Ctrl+P → 대상 **PDF로 저장** → 저장. |
| 템플릿과 똑같지 않아요 | 그림을 복사하지 않고 색·글꼴 느낌·장식을 해석하는 방식이라 그래요. 이미지를 2~3장 더 넣으면 더 가까워져요. |
| AI가 링크를 못 열어요 | 해당 커넥터가 연결됐는지 확인하거나, 이미지 방식을 쓰세요. |
| 학생에게 나눠 줘도 되나요? | 템플릿 그림은 복제하지 않으니 대부분 괜찮지만, 넣은 사진의 출처와 이용 조건은 꼭 확인하세요. |
