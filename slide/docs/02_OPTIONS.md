# 02. 옵션 카탈로그

웹앱의 옵션 UI, ? 칩 설명, 미리보기 팝업, 스킬·프롬프트에 들어가는 문구는 **모두 이 문서에서 나온다**.
코드에서는 `OPTIONS` 객체 하나로 옮기고, 이 문서와 1:1로 맞춘다.

---

## 0. 읽는 법

### 0-1. 옵션 데이터 규격

| 필드 | 뜻 |
|---|---|
| `code` | 짧은 코드 (A1, B3 …). URL 해시에 쓴다 |
| `id` | 의미 있는 영문 ID (`text.amount` 등) |
| 형식 | 하나 고르기 / 여러 개 고르기 / 켜기·끄기 / 숫자 / 글 입력 |
| 범위 | `skill` = 기본 설정(스킬·프롬프트에 들어감) · `lesson` = 이번 수업 옵션(옵션 한 줄) · `both` = 둘 다 |
| 결과물 | `html` · `canva` · `miri` — 이 결과물을 골랐을 때만 활성. 아니면 흐리게 + 이유 |
| 선택지 | **굵은 글씨 = 기본값** |
| ? | ? 칩 팝오버 문구 |
| 미리보기 | 팝업 데모 종류와 내용 (0-2) |
| 반영 | 스킬·프롬프트에 들어갈 문구 또는 엔진 속성 |

### 0-2. 미리보기 종류

| 종류 | 모달에서 보여 주는 것 |
|---|---|
| `motion` | 16:9 미니 무대에서 실제 엔진으로 효과 재생. 선택지 버튼으로 바꿔 보기, [다시 보기] |
| `layout` | 엔진 클래스로 렌더한 샘플 슬라이드 |
| `compare` | 선택지 2~5개를 같은 샘플로 나란히 (정적) |
| `widget` | 실제로 눌러 보는 작동 데모 (퀴즈·타이머 등) |
| `steps` | 따라 하기 그림 3~4컷 |
| `none` | 팝오버 설명만 |

샘플 문구는 중립 주제("물의 순환" 등)로 통일한다. 모든 데모는 `prefers-reduced-motion`이면 정지 화면 + "동작 줄이기 설정이 켜져 있어요" 문구.

### 0-3. ? 설명 쓰는 법

- 존댓말 '~해요'. 2문장 이내.
- 첫 문장은 무엇인지, 둘째 문장은 언제 좋은지 또는 주의할 점.
- 전문 용어를 쓰면 괄호로 쉬운 말을 붙인다.

## 1. 항상 적용되는 규칙 (옵션 아님)

스킬·프롬프트에 언제나 들어간다. 화면에는 "항상 지키는 규칙" 접힘 상자로 보여 준다.

- 한 장에 한 메시지. 넘치면 장을 나눈다 (글자를 줄이지 않는다).
- 가장 작은 글자도 24px 이상 (1920×1080 기준).
- 글자와 배경의 명도 대비 4.5:1 이상 (44px 이상 큰 글자는 3:1).
- 모든 사진·그림에 대체 텍스트.
- 동작 줄이기 설정이 켜져 있으면 움직임을 멈춘다. 1초에 3번 넘게 깜빡이는 효과 금지.
- 한국어는 단어 단위로 줄을 바꾼다 (`word-break: keep-all`).
- 수업자료에 없는 사실·수치·인용을 지어내지 않는다. 보충이 필요하면 노트에 '[확인 필요]'.
- AI 티 나는 요소 금지 (03 §5-9).

## 4. 옵션 상세

### O. 출력 설정

#### O1 · 사용할 AI `out.ai`
- 형식: 여러 개 고르기 · 범위: — · 결과물: 전부
- 선택지: Claude · ChatGPT · Gemini (처음엔 아무것도 고르지 않은 상태)
- ?: 슬라이드를 만들 AI를 골라요. 여러 개 고르면 AI별로 맞춘 파일을 각각 드려요.
- 미리보기: none (카드에 지원 배지 표시: 04 §1)
- 반영: AI별 패키지 구조와 프롬프트 머리말·꼬리말 (03 §2, §6)

#### O2 · 받을 형태 `out.form`
- 형식: 하나 고르기
- 선택지: **스킬** · 프롬프트
- ?: 스킬은 한 번 설치하면 매번 "슬라이드 만들어줘"만 하면 돼요. 프롬프트는 설치 없이 복사해서 붙여 넣는 방식이에요.
- 미리보기: compare — 두 방식의 매 수업 과정 비교 (스킬 2단계 / 프롬프트 4단계)
- 반영: 출력 종류 결정

#### O3 · 결과물 `out.target`
- 형식: 여러 개 고르기 (HTML은 항상 포함)
- 선택지: **HTML 슬라이드** · 캔바에서 직접 수정 · 미리캔버스에서 직접 수정
- ?: HTML 슬라이드는 어느 AI에서나 만들어지고 브라우저로 바로 발표해요. 직접 수정은 해당 커넥터를 연결한 AI에서 템플릿 사본을 고쳐 캔바·미리캔버스에서 이어서 편집할 수 있어요.
- 미리보기: compare — 결과물별 장단점 표 (애니메이션 가능 여부, 필요한 연결, 편집 위치)
- 반영: 캔바·미리캔버스를 고르면 SKILL.md에 직접 수정 절차를 추가하고 K·L 카테고리를 연다

#### O4 · 엔진 불러오기 `out.engine`
- 형식: 하나 고르기
- 선택지: **인터넷에서 불러오기** · 파일에 내장(오프라인)
- ?: 인터넷 방식은 파일이 가볍고 결과가 안정적이에요. 인터넷이 안 되는 교실이면 '파일에 내장'을 고르세요.
- 미리보기: none
- 반영: 인터넷 → 엔진 주소 2줄 사용. 내장 → 받기 화면에 [오프라인 파일로 바꾸기] 안내 강조 (AI에게 엔진 코드를 쓰게 하지 않는다)

#### O5 · 스킬 이름 `out.name`
- 형식: 글 입력 · 기본값 `lesson-slides`
- ?: 스킬을 구분하는 영문 이름이에요. 영어 소문자·숫자·하이픈(-)만 쓸 수 있어요.
- 미리보기: none
- 반영: SKILL.md `name`, 폴더 이름 (03 §8 검증)

#### O6 · 슬라이드 언어 `out.lang`
- 형식: 하나 고르기
- 선택지: **한국어** · 수업자료 언어 그대로
- ?: 화면에 쓸 언어예요. 외국어 수업에서 원문을 살리고 싶으면 '수업자료 언어 그대로'를 고르세요.
- 미리보기: none
- 반영: "슬라이드 글은 {한국어 / 수업자료 언어}로 쓴다."

### A. 수업 흐름

#### A1 · 수업 구성 틀 `flow.frame`
- 형식: 하나 고르기 · 범위: skill · 결과물: html
- 선택지: **자동** · 도입·전개·정리 · 질문·탐구·정리 · 개념·예시·적용 · 토론·발표형
- ?: 수업자료를 어떤 순서로 나눌지 정해요. 잘 모르겠으면 '자동'으로 두면 자료에 맞게 정해요.
- 미리보기: compare — 틀마다 슬라이드 순서를 작은 블록으로 표시
- 반영:
  - 자동 → "수업자료의 흐름을 살려 알맞은 구성을 정한다."
  - 도입·전개·정리 → "도입(동기유발·학습목표) → 전개(개념·활동) → 정리(요약·확인) 순서로 구성한다."
  - 질문·탐구·정리 → "핵심 질문 → 탐구(자료·사례) → 정리(답과 일반화) 순서로 구성한다."
  - 개념·예시·적용 → "개념 설명 → 예시 → 적용 문제 순서를 반복한다."
  - 토론·발표형 → "논제 → 쟁점별 근거 → 의견 나누기 → 정리 순서로 구성한다."

#### A2 · 꼭 넣을 슬라이드 `flow.slides`
- 형식: 여러 개 고르기 · 범위: skill
- 선택지: **표지** · **학습목표** · 오늘의 질문 · 목차 · **섹션 구분** · **핵심 요약** · 형성평가(출구 티켓) · 다음 차시 예고 · 참고자료·출처
- ?: 수업자료와 별개로 꼭 들어갈 슬라이드예요. 형성평가는 수업 끝에 2~3문항으로 이해를 확인해요.
- 미리보기: layout — 종류별 샘플 슬라이드
- 반영: "다음 슬라이드를 반드시 넣는다: {목록}."

#### A3 · 수업 단계 표시 `flow.stage`
- 형식: 켜기·끄기 (끄기)
- ?: 화면 위쪽에 지금이 도입·전개·정리 중 어디인지 작게 보여 줘요. 학생이 수업 흐름을 따라오기 쉬워요.
- 미리보기: layout
- 반영: `data-features`에 `stage` 추가 + "각 장의 `data-stage`에 단계 이름을 적는다."

#### A4 · 슬라이드 수 `flow.count`
- 형식: 하나 고르기 · 범위: lesson
- 선택지: **자동** · 8장 내외 · 12장 내외 · 16장 내외 · 20장 내외
- ?: 자동이면 자료 양에 맞춰 정해요. 한 장에 한 가지 내용이 원칙이라 자료가 많으면 장 수가 늘어요.
- 미리보기: none
- 반영: 옵션 한 줄 `장수=12`

#### A5 · 수업 시간 `flow.time`
- 형식: 하나 고르기 · 범위: lesson
- 선택지: **정하지 않음** · 45분 · 50분 · 블록(90분 이상)
- ?: 수업 시간에 맞춰 분량을 조절하고, 발표자 노트에 장별 예상 시간을 적어요.
- 미리보기: none
- 반영: 옵션 한 줄 `시간=45분` + "수업 시간에 맞춰 분량을 정하고, 노트에 장별 예상 시간을 적는다."

### B. 화면·글

#### B1 · 화면 비율 `screen.ratio`
- 형식: 하나 고르기 · 범위: skill
- 선택지: **16:9** · 4:3
- ?: 요즘 TV와 프로젝터는 대부분 16:9예요. 오래된 프로젝터라면 4:3을 고르세요.
- 미리보기: compare
- 반영: `data-ratio="16:9|4:3"`

#### B2 · 글자 크기 `text.size`
- 형식: 하나 고르기
- 선택지: 보통(본문 32px) · **크게(본문 36px)** · 아주 크게(본문 44px)
- ?: 교실 맨 뒷자리에서도 읽히려면 '크게' 이상을 추천해요. 글자가 커지면 한 장에 들어가는 글은 줄어요.
- 미리보기: compare — 같은 슬라이드 세 크기
- 반영: `data-size="m|l|xl"` + "본문 글자는 {n}px 이상으로 한다."

#### B3 · 글 양 `text.amount`
- 형식: 하나 고르기
- 선택지: 키워드형 · **짧은 문장** · 설명형
- ?: 키워드형은 선생님이 말로 설명할 때, 설명형은 학생이 화면만 보고 이해해야 할 때 좋아요.
- 미리보기: compare — 같은 내용을 세 가지 글 양으로
- 반영:
  - 키워드형 → "본문은 핵심어 위주로, 한 항목 12자 이내, 한 장 3항목 이내."
  - 짧은 문장 → "본문은 한 문장 30자 안팎, 한 장 4항목 이내."
  - 설명형 → "본문은 2~3문장 단락, 한 장 6줄 이내. 넘치면 장을 나눈다."

#### B4 · 문장 스타일 `text.tone`
- 형식: 하나 고르기
- 선택지: **개조식(~함)** · 대화체(~해요) · 질문형 제목
- ?: 화면에 쓰는 말투예요. 질문형 제목은 학생의 생각을 끌어내기 좋아요.
- 미리보기: compare
- 반영:
  - 개조식 → "본문은 '~함·~임' 개조식으로 쓴다."
  - 대화체 → "본문은 '~해요' 대화체로 쓴다."
  - 질문형 제목 → "제목은 '왜 ~일까?'처럼 질문으로 쓰고 본문이 답한다."

#### B5 · 강조 방식 `text.emphasis`
- 형식: 하나 고르기
- 선택지: **형광펜** · 강조색 글자 · 굵게만 · 밑줄
- ?: 핵심어를 눈에 띄게 하는 방법이에요. 한 장에 1~2곳만 강조해야 효과가 커요.
- 미리보기: compare (형광펜은 E6 '형광펜 긋기'와 함께 보여 줌)
- 반영: "핵심어 강조는 `<mark>`(형광펜) / `.em-color` / `<b>` / `.em-underline`만 쓰고, 한 장에 2곳 이내."

#### B6 · 여백 `text.space`
- 형식: 하나 고르기
- 선택지: **넉넉하게** · 보통 · 촘촘하게
- ?: 여백이 넉넉할수록 정돈돼 보이고 읽기 쉬워요. 대신 장 수가 조금 늘 수 있어요.
- 미리보기: compare
- 반영: `data-space="loose|normal|tight"`

#### B7 · 제목 글꼴 느낌 `text.headfont`
- 형식: 하나 고르기
- 선택지: **테마·템플릿 따라가기** · 단정한 고딕 · 부드러운 둥근체 · 진지한 명조 · 힘 있는 굵은 제목
- ?: 제목 글꼴의 느낌이에요. 본문은 읽기 쉬운 고딕(Pretendard)으로 고정돼요. 여기서 글꼴을 고르면 테마 팩의 제목 글꼴 대신 이 글꼴을 써요.

- 반영(캔바 AI로 그리기): "캔바 도구가 연결돼 있으면 사진 칸 가운데 가장 중요한 3곳까지 캔바의 이미지 생성 도구로 그림을 만든다(사진 설명 + '글자 없음', 가로 칸은 16:9). 만든 그림은 HTML에 넣지 않고, 끝난 뒤 '몇 번째 장 – 그림을 여는 링크' 목록과 붙여 넣는 방법을 안내한다."
- 근거: 캔바가 돌려주는 그림 주소는 200px 미리보기뿐이고 약 4시간 뒤 만료된다(06). 그래서 캔바 그림은 파일에 자동으로 넣지 않는다. ChatGPT는 무료 계정에서 그림 1장을 만들어 HTML 안에 넣어 줬다. Gemini는 두 번 시도해 두 번 다 넣지 못한다고 답했다(TEST_LOG 11-20 밤). ChatGPT의 여러 장은 확인 전이다.

캔바 커넥터가 연결된 AI에서만 동작. 근거는 Claude 캔바 커넥터 도구 설명(2026-11-20 확인, 06_SOURCES). 커넥터의 편집 도구에는 애니메이션 기능이 없으므로 E 카테고리는 이 결과물에서 흐리게 처리하고 "애니메이션은 캔바 편집기에서 직접 넣어 주세요"를 표시한다.

#### K1 · 원본 보호 `canva.copy`
- 형식: 켜기·끄기 (**켜기**, 끄기 비추천)
- ?: 템플릿 원본은 그대로 두고 사본을 만들어 고쳐요.
- 미리보기: none
- 반영: "먼저 디자인 사본을 만들고 사본에서만 작업한다."

#### K2 · 사용할 페이지 `canva.pages`
- 형식: 하나 고르기
- 선택지: **필요한 페이지만 골라 사본 만들기** · 전체 페이지 복사
- ?: 템플릿에서 쓸 페이지만 골라 사본을 만들면 정리할 일이 줄어요.
- 반영: "내용에 맞는 템플릿 페이지만 골라 사본을 만든다." / "전체 페이지를 복사한다."

#### K3 · 글 넘침 처리 `canva.overflow`
- 형식: 하나 고르기
- 선택지: **글을 줄여 맞추기** · 글자 크기를 조금 줄이기(최소 24px)
- ?: 템플릿 글 상자보다 내용이 길 때 어떻게 할지 정해요. 글을 줄이는 쪽이 디자인이 덜 깨져요.
- 반영: "글이 상자를 넘치면 {문장을 줄여 맞춘다 / 글자 크기를 24px까지만 줄인다}."

#### K4 · 템플릿 사진 `canva.photos`
- 형식: 하나 고르기
- 선택지: 그대로 두기 · **바꿀 사진 목록 알려 주기**
- ?: 템플릿에 있던 예시 사진을 어떻게 할지 정해요. 목록을 받으면 캔바에서 바로 바꿀 수 있어요.
- 반영: "주제와 맞지 않는 템플릿 사진은 페이지별로 목록을 만들어 알려 준다." / "템플릿 사진은 그대로 둔다."

#### K5 · 발표자 노트 쓰기 `canva.notes`
- 형식: 켜기·끄기 (**켜기**)
- ?: 페이지마다 말할 내용을 캔바 발표자 노트에 적어 둬요.
- 반영: "각 페이지의 발표자 노트에 말할 내용 2~3줄을 적는다."

#### K6 · 내 브랜드 키트 적용 `canva.brandkit`
- 형식: 켜기·끄기 (끄기)
- ?: 캔바에 저장해 둔 브랜드 키트(학교 색 등)가 있으면 그 색·글꼴로 맞춰요.
- 반영: "사용자의 캔바 브랜드 키트 색·글꼴에 맞춘다 (브랜드 키트가 없으면 건너뜀)."

#### K7 · 끝나면 내보내기 `canva.export`
- 형식: 하나 고르기
- 선택지: **안 함** · PDF · PPTX · PNG
- ?: 완성 후 파일로 받을지 정해요. 캔바에서 계속 고칠 거면 '안 함'이 좋아요.
- 반영: "저장이 끝나면 {형식}으로 내보내 다운로드 링크를 준다."

고정 안내 (옵션 아님): "고친 내용을 미리 보여 주고, 확인을 받은 뒤 저장해요." (캔바 편집 도구가 저장 전 사용자 승인을 요구함)

### L. 미리캔버스에서 직접 수정 (O3에서 골랐을 때)

미리캔버스 커넥터가 연결된 AI에서만 동작 (2026-11-20 기준 Claude에서 동작 확인, 공개 연결 방법은 확인 필요: 06_SOURCES). 커넥터 도구에 애니메이션 기능이 없으므로 E 카테고리는 흐리게 처리한다.

#### L1 · 시작 방식 `miri.start`
- 형식: 하나 고르기
- 선택지: **내 디자인 링크 고치기** · 브랜드 키트에 등록한 양식으로 새로 만들기
- ?: 이미 열어 둔 내 디자인(편집 링크)을 고칠지, 브랜드 키트에 등록한 양식으로 새로 만들지 정해요. 등록한 양식은 매번 목록에서 직접 골라요.
- 반영:
  - 내 디자인 → "편집 링크(…/v2/design2/{디자인ID})의 디자인 정보·미리보기를 먼저 확인하고 페이지 내용을 고친다."
  - 브랜드 키트 양식 → "브랜드 키트 템플릿 목록을 보여 주고 사용자가 고른 양식으로 만든다 (임의로 고르지 않는다)."

#### L2 · 페이지 추가·삭제 허용 `miri.pages`
- 형식: 켜기·끄기 (**켜기**)
- ?: 내용 양에 맞춰 페이지를 더하거나 뺄 수 있게 해요.
- 반영: "내용에 맞춰 템플릿 기반으로 페이지를 더하거나 뺀다."

#### L3 · 끝나면 받기 `miri.download`
- 형식: 하나 고르기
- 선택지: **안 함** · PDF · PPTX · PNG · MP4 · GIF
- ?: 완성 후 파일로 받을지 정해요. 커넥터로 만든 디자인만 내려받을 수 있어요.
- 반영: "완성 후 {형식} 파일 링크를 준다. 커넥터로 만든 디자인이 아니면 미리캔버스에서 직접 내려받도록 안내한다."
