# 05. 웹앱 디자인 시스템

생성되는 슬라이드가 아니라 **웹앱 자체**의 디자인이다. (슬라이드 디자인은 03 문서)

## 1. 방향

- 흰 바탕의 깔끔한 화면.
- 글씨체와 색감은 **Wise(wise.com)의 아이덴티티를 참고**한다: 밝은 라임 그린 + 짙은 포레스트 그린, 크고 굵은 제목, Inter 계열 본문, 알약 모양 버튼, 또렷한 포커스 테두리.
- Wise의 로고·이름·Wise Sans 글꼴·일러스트·깃발 모양 아이콘은 쓰지 않는다. **느낌만** 가져온다.
- 키워드: 분명함, 친근함, 자신감 있는 큰 글자, 넉넉한 여백.

## 2. 색

```css
:root {
  --c-bg: #FFFFFF;          /* 페이지 배경 */
  --c-ink: #0E0F0C;         /* 제목·본문 */
  --c-ink-2: #454745;       /* 보조 글자 (초안, 대비 검증) */
  --c-forest: #163300;      /* 선택 상태, 링크, 포커스, 진한 면 */
  --c-lime: #9FE870;        /* 주 버튼 바탕 (글자는 반드시 forest) */
  --c-lime-soft: #E2F6D5;   /* 선택된 카드 바탕, 강조 면 */
  --c-surface: #F2F4EF;     /* 패널·미리보기 무대 바탕 (초안) */
  --c-line: #D9DDD5;        /* 테두리 (초안) */
  --c-danger: #D03238;      /* 오류 */
  --c-warn-bg: #FFF4C2;     /* 경고 바탕 (초안) */
  --c-success: #054D28;     /* 완료 */
}
```

| 토큰 | 근거 |
|---|---|
| `--c-forest` #163300, `--c-lime` #9FE870 | Wise 핵심 색 (06_SOURCES) |
| `--c-ink` #0E0F0C, `--c-lime-soft` #E2F6D5, 보조 색 | Wise를 분석한 제3자 자료의 참고값 → 대비 검증 후 확정 |
| `--c-surface`, `--c-line`, `--c-warn-bg` | 초안. 화면에 맞춰 조정 |

- 라임 위 글자는 **포레스트 그린만** 쓴다 (계산상 약 9:1). 흰 바탕에 라임 글자는 대비가 부족하므로 쓰지 않는다.
- 색은 넓게 칠하지 않는다. 화면 대부분은 흰색과 글자색, 라임은 주 버튼·선택 표시에만.

## 3. 글꼴

- **Pretendard Variable 하나**로 통일한다 (라틴 글자가 Inter 기반이라 Wise 본문 느낌과 맞는다). jsDelivr 고정 버전.
- 제목은 굵기 800~900, 자간 -0.03em. 줄 간격은 1.05~1.15 (Wise 영문 제목처럼 0.85로 좁히면 한글이 겹친다).
- `font-feature-settings: "calt"`, 숫자는 `font-variant-numeric: tabular-nums`.

| 쓰임 | 데스크톱 | 모바일 | 굵기 |
|---|---|---|---|
| 히어로 제목 | 56px | 36px | 900 |
| 화면 제목 | 40px | 28px | 800 |
| 섹션 제목 | 28px | 22px | 800 |
| 카드 제목 | 20px | 18px | 700 |
| 본문 | 17px | 16px | 500 |
| 보조 | 14px | 14px | 500 |
| 캡션 | 13px | 13px | 500 |

## 4. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 주 버튼 | 알약(radius 9999), 높이 48 (작게 40, 크게 56), 좌우 24px, 라임 바탕 + 포레스트 글자 700. 누르면 살짝 진해짐 |
| 보조 버튼 | 흰 바탕 + 포레스트 1.5px 테두리 + 포레스트 글자 |
| 글자 버튼 | 포레스트 글자 + 밑줄 |
| 카드 | radius 24, 흰 바탕, 1px `--c-line`, 그림자 없음. 선택되면 포레스트 2px 테두리 + `--c-lime-soft` 바탕 + 체크 표시 |
| 옵션 칩 | 알약, 높이 40, 흰 바탕 + `--c-line` 테두리. 선택되면 포레스트 바탕 + 흰 글자 + 체크 아이콘 (색만으로 구분하지 않음) |
| 레이아웃 칩 (C1) | 작은 썸네일(16:9) + 이름. 선택 표시는 옵션 칩과 같음 |
| 스위치 | 켜짐 = 포레스트, 꺼짐 = `--c-line`. 라벨을 눌러도 바뀜 |
| ? 칩 | 지름 22px 원, `--c-line` 테두리, '?' 13px 700. 마우스를 올리거나 포커스하면 `--c-lime-soft` 바탕. 터치 영역은 44px 확보 |
| 팝오버 | radius 16, 흰 바탕, 그림자 `0 8px 24px rgba(14,15,12,.12)`, 최대 폭 320px. 내용 = 설명 + [미리보기] 글자 버튼. 바깥 클릭·Esc로 닫힘. 모바일은 아래에서 올라오는 시트 |
| 미리보기 모달 | 최대 폭 960px, radius 24. 위: 옵션 이름 + 닫기. 가운데: 16:9 무대(radius 16, `--c-surface` 바탕, 엔진으로 렌더). 아래: 선택지 칩 + [다시 보기] + [이걸로 선택](주 버튼). 배경 `rgba(14,15,12,.48)` |
| 단계 표시 | 원 1·2·3 + 이름. 현재 = 포레스트 채움, 완료 = 라임 채움 + 체크 |
| 입력 칸 | 높이 48, radius 12, `--c-line` 테두리. 오류면 `--c-danger` 테두리 + 아래 한 줄 설명 |
| 코드 보기 | SKILL.md·프롬프트 미리보기. 고정폭 13px, `--c-surface` 바탕, radius 16, 최대 높이 360px 스크롤, 오른쪽 위 [복사] |
| 토스트 | 화면 아래 가운데, 포레스트 바탕 + 흰 글자, 2.5초 |
| 배지 | 알약 높이 24. '됨' = `--c-lime-soft` 바탕 + 포레스트 글자, '확인 필요' = `--c-surface` 바탕 + `--c-ink-2` 글자 |

## 5. 배치

- 최대 폭 1200px, 좌우 여백 24px (모바일 16px).
- 데스크톱: 본문 8칸 + 요약 패널 4칸(스크롤해도 따라옴).
- 모바일: 요약은 화면 아래 바("고른 옵션 12개 · 만들기"), 누르면 시트로 펼침.
- 간격: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96. 섹션 사이 64px, 카드 안쪽 24px.
- 첫 화면: 큰 제목 + 한 줄 설명 + [시작하기] + 결과 예시 슬라이드 한 장(레퍼런스 덱 캡처). 장식은 라임 원형 도형 1~2개 정도.

## 6. 움직임

- 곡선 `cubic-bezier(0.2, 0, 0, 1)`, 150~250ms.
- 칩 선택: 바탕색 120ms. 팝오버: 페이드 + 4px 이동 150ms. 모달: 페이드 + 0.98→1 확대 200ms.
- `prefers-reduced-motion`이면 전환 없이 바로 바뀐다.

## 7. 접근성

- 포커스: 모든 조작 요소에 포레스트 3px 테두리(바깥 2px 띄움). 브라우저 기본 포커스에 기대지 않는다.
- 대비 4.5:1 이상.
- 키보드: 화면 순서대로 Tab, 칩 묶음 안에서는 화살표 키, 모달은 포커스를 가두고 Esc로 닫기.
- aria: 칩 묶음은 `radiogroup`/`group` + 칩마다 `radio`/`checkbox`, ? 칩은 `button` + `aria-expanded`·`aria-controls`, 모달은 `dialog` + `aria-modal`.
- 터치 영역 44×44px 이상. 글자 200% 확대에도 깨지지 않게.

## 8. 문구 톤
