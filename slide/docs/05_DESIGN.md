# 05. 웹앱 디자인 시스템

생성되는 슬라이드가 아니라 **웹앱 자체**의 디자인이다. (슬라이드 디자인은 03 문서)

## 1. 방향

- **세 가지 색으로만 만든다: 크림 · 남색 · 코랄.** 넓은 면은 옅은 크림, 글자와 진한 면은 남색, 눈에 띄어야 하는 곳만 코랄.
- 정한 과정(2026-11-21): 처음엔 Wise를 참고한 라임·포레스트 그린 → 사용자가 준 참고 화면의 오키드 핑크·가지 보라·시그널 오렌지로 바꿈 → "눈에 띄지만 피로할 것 같다"는 의견에 후보 셋(같은 3색을 옅게 / 크림·남색·코랄 / 세이지·초록·살구)을 실제 화면에 입혀 비교 → **사용자가 크림·남색·코랄을 고름.**
- 피로를 줄이는 원칙: 진하고 쨍한 색을 넓게 칠하지 않는다. 넓은 면은 옅게, 진한 색은 글자와 작은 면에, 강조색은 버튼·번호에만.
- 색마다 **밝은 단계와 그늘 단계**를 두고, 솟아 있는 것(버튼·카드·예시 슬라이드) 아래에는 **자기 색의 그늘**을 깐다. 이 그늘이 화면에 생동감을 준다.
- 색을 칠하는 자리: 첫 화면 = 크림 면, 요약 패널·바닥글·모바일 아래 바 = 남색 면, 주 버튼·번호·강조 = 코랄. 일하는 곳(옵션·받기)은 흰 바탕.

## 2. 색

```css
:root {
  --c-bg: #FFFFFF;            /* 페이지 배경 */
  --c-ink: #151B2E;           /* 본문 (남색을 더 짙게) */
  --c-ink-2: #515972;         /* 보조 글자 */
  /* 남색: 제목, 선택 상태, 링크, 포커스, 진한 면 */
  --c-navy: #1E2A4A;  --c-navy-2: #2E3D66;  --c-navy-3: #131B33;
  /* 코랄: 주 버튼, 번호, 강조 (글자색으로는 쓰지 않는다) */
  --c-coral: #F0643C;  --c-coral-2: #F58462;  --c-coral-3: #C2482A;  --c-coral-soft: #FDE8DF;
  /* 크림: 첫 화면 면, 선택된 카드 바탕, 그늘 */
  --c-cream: #F3EADB;  --c-cream-2: #FBF7EF;  --c-cream-3: #E6D8C0;  --c-cream-soft: #FAF5EC;
  --c-surface: #F7F4EE;       /* 안내 상자·코드 보기 바탕 */
  --c-line: #E6DFD2;          /* 테두리, 흰 카드의 그늘 */
  --c-danger: #C4262E;        /* 오류 */
  --c-warn-bg: var(--c-coral-soft);   /* 경고 바탕 */
}
```

| 단계 | 쓰임 |
|---|---|
| 기본 (`-navy` `-coral` `-cream`) | 세 색의 기준 |
| `-2` 밝은 단계 | 면 위쪽의 밝은 쪽 (버튼·남색 면·크림 면의 위에서 아래로 가는 음영) |
| `-3` 그늘 단계 | 아래에 까는 그늘 (버튼 아래 3px, 선택된 칩 아래 2px, 면의 어두운 쪽) |
| `-soft` | 넓게 깔아도 글자가 잘 읽히는 아주 옅은 바탕 |

대비 (계산값):

| 조합 | 대비 | 쓰는 곳 |
|---|---|---|
| 흰 바탕 + 남색 | 약 14:1 | 제목·링크·선택 표시 |
| 코랄 바탕 + 짙은 남색(`--c-navy-3`) | 약 5.4:1 | 주 버튼 글자 |
| 크림 바탕 + 남색 | 약 12:1 | 첫 화면 제목 |
| 크림 바탕 + `--c-ink-2` | 약 5.8:1 | 첫 화면의 작은 글자 |
| 흰 바탕 + 코랄 | 약 3.2:1 | **글자로 쓰지 않는다** (도형·버튼 바탕만) |

- 같은 색 안에서만 음영을 준다(코랄→진한 코랄). 색과 색을 섞는 그라데이션은 쓰지 않는다.
- 경고·주의도 코랄 옅은 바탕으로 표현한다(노랑을 따로 쓰지 않는다). 오류만 붉은색.
- 미리보기·영상 속 **슬라이드**는 슬라이드 테마의 색을 그대로 보여 준다(웹앱 색으로 칠하지 않는다). 첫 화면의 예시 슬라이드만 이 3색을 입혔다(`HERO_CSS`, 템플릿 색을 따를 때와 같은 방식).

## 3. 글꼴

- **Pretendard Variable 하나**로 통일한다 (라틴 글자가 Inter 기반이라 Wise 본문 느낌과 맞는다). jsDelivr 고정 버전.
- 제목은 굵기 800~900, 자간 -0.03em. 줄 간격은 1.05~1.15 (Wise 영문 제목처럼 0.85로 좁히면 한글이 겹친다).
- `font-feature-settings: "calt"`, 숫자는 `font-variant-numeric: tabular-nums`.

| 쓰임 | 데스크톱 | 모바일 | 굵기 |
|---|---|---|---|
| 히어로 제목 | 56px | 36px | 900 |
| 화면 제목 | 40px | 28px | 800 |
| 섹션 제목 | 28px | 22px | 800 |
| 카드 제목 | 20px | 18px | 700 |
| 본문 | 17px | 16px | 500 |
| 보조 | 14px | 14px | 500 |
| 캡션 | 13px | 13px | 500 |

## 4. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 주 버튼 | 알약(radius 9999), 높이 48 (작게 40, 크게 56). 코랄 바탕(위가 조금 밝음) + 짙은 남색 글자 800 + **아래에 진한 코랄 그늘 3px**(작게 2, 크게 4). 올리면 1px 뜨고, 누르면 그늘만큼 내려앉는다 |
| 보조 버튼 | 흰 바탕 + 남색 1.5px 테두리 + 남색 글자 + 아래에 남색 그늘 |
| 글자 버튼 | 남색 글자 + 밑줄 |
| 카드 | radius 24, 흰 바탕, 1.5px `--c-line` + 아래 그늘 3px. 올리면 2px 뜨고 그늘이 크림로. 선택되면 남색 2px 테두리 + 옅은 크림 바탕 + 크림 그늘 5px + 체크 표시 |
| 옵션 칩 | 알약, 높이 40. 선택되면 남색 바탕 + 흰 글자 + 체크 아이콘 + 아래 그늘 2px (색만으로 구분하지 않음) |
| 레이아웃 칩 (C1) | 작은 썸네일(16:9, 남색·코랄·크림로 그림) + 이름 |
| 스위치 | 켜짐 = 남색, 꺼짐 = `--c-line` |
| ? 칩 | 지름 22px 원. 올리거나 포커스하면 옅은 크림 바탕. 터치 영역 44px |
| 팝오버 | radius 16, 흰 바탕, 남색 기운의 그림자, 최대 폭 320px. 모바일은 아래에서 올라오는 시트 |
| 미리보기 모달 | 최대 폭 960px, radius 24. 배경 `rgba(19,27,51,.48)` |
| 단계 표시 | 원 1·2·3 + 이름. 현재 = 남색, 완료 = 코랄 + 체크 |
| 받기 화면의 큰 번호 | 코랄 원 + 짙은 남색 숫자 + 아래 그늘 |
| 요약 패널 | 남색 면(위 `--c-navy-2` → 아래 `--c-navy-3`), 흰 글자, 작은 제목은 크림, 버튼은 코랄. 모바일 아래 바도 남색 |
| 꼭 알아 두세요 | 옅은 코랄 바탕 + 코랄 점 |
| 입력 칸 | 높이 48, radius 12, `--c-line` 테두리. 오류면 `--c-danger` 테두리 + 아래 한 줄 설명 |
| 코드 보기 | 고정폭 13px, `--c-surface` 바탕, radius 16, 최대 높이 360px 스크롤, 오른쪽 위 [복사] |
| 토스트 | 화면 아래 가운데, 남색 바탕 + 흰 글자, 2.5초 |
| 배지 | 알약 높이 24. '됨' = 옅은 크림 + 남색, '확인 필요' = `--c-surface` + `--c-ink-2` |
| 바닥글 | 짙은 남색 면 + 옅은 크림 글자 |

## 5. 배치

- 최대 폭 1200px, 좌우 여백 24px (모바일 16px).
- 데스크톱: 본문 8칸 + 요약 패널 4칸(스크롤해도 따라옴).
- 모바일: 요약은 화면 아래 바("고른 옵션 12개 · 만들기"), 누르면 시트로 펼침.
- 간격: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96. 섹션 사이 64px, 카드 안쪽 24px.
- 첫 화면: 화면 폭 전체를 크림로 칠하고(왼쪽 위가 조금 밝고 오른쪽 아래가 조금 짙음), 작은 꼬리표 + 큰 제목(강조 낱말은 코랄 조각) + 설명 + 버튼 3개 + 예시 슬라이드. 예시 슬라이드는 남색 테두리와 12px 그늘, 뒤에 코랄 공 하나.
- 다른 탭(갤러리·연결 안내·단축키·질문)은 제목 뒤에만 옅은 크림가 위에서 아래로 사라진다.

## 6. 움직임

- 곡선 `cubic-bezier(0.2, 0, 0, 1)`, 150~250ms.
- 칩 선택: 바탕색 120ms. 팝오버: 페이드 + 4px 이동 150ms. 모달: 페이드 + 0.98→1 확대 200ms.
- `prefers-reduced-motion`이면 전환 없이 바로 바뀐다.

## 7. 접근성

- 포커스: 모든 조작 요소에 남색 3px 테두리(바깥 2px 띄움). 남색 면 위에서는 코랄 테두리. 브라우저 기본 포커스에 기대지 않는다.
- 대비 4.5:1 이상.
- 키보드: 화면 순서대로 Tab, 칩 묶음 안에서는 화살표 키, 모달은 포커스를 가두고 Esc로 닫기.
- aria: 칩 묶음은 `radiogroup`/`group` + 칩마다 `radio`/`checkbox`, ? 칩은 `button` + `aria-expanded`·`aria-controls`, 모달은 `dialog` + `aria-modal`.
- 터치 영역 44×44px 이상. 글자 200% 확대에도 깨지지 않게.

## 8. 문구 톤

- 존댓말 '~해요', 짧게. 버튼은 동사형 (만들기, 복사하기, 받기).
- 전문 용어는 쉬운 말로: MCP → 커넥터(AI와 앱을 잇는 연결), SKILL.md → 스킬 파일, HTML → 웹 슬라이드 파일.
- 완료 메시지에는 다음에 할 일을 넣는다. 예: "복사했어요. 이제 Claude 새 대화에 붙여 넣으세요."

## 9. 하지 말 것

- 세 색 밖의 색을 웹앱 화면에 더하기 (슬라이드 미리보기 안의 테마 색은 예외)
- 색과 색을 섞는 그라데이션, 흐린 빛 번짐, 이모지
- 흰 바탕에 코랄 글자
- AI 회사 공식 로고 (텍스트 이름 + 중립 아이콘으로)
