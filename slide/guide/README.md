# 사용법 영상 · 내레이션

웹앱의 [사용법 영상]은 영상 파일이 아니다. `index.html`의 `UV_CH`(장면 12개)를 시각에 따라 그리는 방식이고,
생기부돋보기(`mirror`)·우리반 창체 비서(`moa`)의 사용법 영상과 같은 틀이다.

| 무엇 | 어디 |
|---|---|
| 대본 (자막 · 읽을 말) | `index.html`의 `UV_SAY` (`/*SAY*/ … /*SAY-END*/`) |
| 줄마다 소리 자리·길이 | `index.html`의 `UV_VO` (`/*VO*/ … /*VO-END*/`) — 아래 스크립트가 고쳐 쓴다. 손으로 고치지 않는다 |
| 장면 | `index.html`의 `UV_CH` — 장마다 `say`(읽을 줄), `raw`/`pane`(화면), `cur`(커서 길), `clk`(누르는 순간), `run`(시각 → 화면) |
| 내레이션 소리 | `guide/narration.m4a` (웹앱과 함께 올린다. 영상을 처음 틀 때만 받는다) |
| 목소리 원본 | `guide/voice-cache/` (올리지 않는다) |

## 내레이션 다시 만들기

```
cd C:\Users\User\Desktop\코딩\hirameki\slide\guide
node make-voice.mjs
```

- 필요한 것: VoiceStudio(목소리 「멋남 · 릴스 TTS 1」), ffmpeg.
- 바뀐 줄·빠진 줄만 새로 읽힌다. 한 줄에 2~5분 걸린다 (다른 작업이 VoiceStudio를 같이 쓰면 더 느리다).
- 발음이 이상한 줄만 다시: `node make-voice.mjs --redo c5a,c8a` · 씨앗을 바꾸려면 `--seed 9`.
- 읽을 말은 한글로 적는다 (AI → 에이아이, ZIP → 집, F → 에프).
- 장의 길이와 자막 시각은 소리 길이에서 나오므로, 대본을 고쳐 소리를 다시 만들면 장면도 저절로 맞는다.
  장면 안의 움직임은 `T.s[k]`(k번째 줄이 시작하는 시각)에 맞춰 적어 두었다.

## 장면을 고칠 때

- 장면 속 버튼 이름·문구는 실제 화면과 같게 둔다. 웹앱 문구를 바꾸면 `UV_CH`도 고친다.
- 5~7장의 Claude 화면은 2026-11-20에 실제로 조작하며 확인한 메뉴 이름·순서다
  (사용자 지정 → Skills → 추가 → Skill 업로드 → 업로드). Claude 화면이 바뀌면 고친다.
- 작은 슬라이드의 테마·제목·장 수는 `UV_SL`에 있다. 2026-11-20 Claude가 실제로 만든 결과를 본떴다.
- 자막은 화면 아래쪽에 얹힌다. 꼭 보여야 할 것은 640×360 기준 y 290 위쪽에 둔다.
- 확인: 영상을 연 뒤 콘솔에서 `uvSeekTo(uvStarts[4] + 3)`처럼 원하는 시각으로 옮겨 본다.
