1
성적 파일 업로드 필수
① 학교급 선택 — 고등학교 / 중학교를 먼저 선택하세요.
② 파일 종류 선택 후 나이스(NEIS)에서 내려받은 .xlsx 파일을 업로드합니다.

🏫 교과학습발달상황
나이스 → 학급담임 → 학교생활기록부 → 학생부 항목별 조회 → 교과학습발달상황(전체학생)
· 고등학교: 석차등급(1~2학년 5등급 / 3학년 9등급) 그대로 분석
· 중학교: NEIS 기재 성취도(A~E) 그대로 분석 · 1학기 P(이수)는 자동 제외

📋 전과목 성적 일람표
나이스 → 학급담임 → 성적조회/통계 → 학기말성적조회 → 성적일람표 전과목
(산출기준: 1차 정기시험 · 받은점수기준 선택 후 엑셀 다운로드)
· 고등학교: 원점수 + 석차 기반 가상등급 자동 산출, 등급 상승 필요 인원 표시
· 중학교: 성취도·석차 컬럼 없음 → 원점수 기준 성취도 추정값 표시 (실제와 다를 수 있음)
  정확한 분석은 교과학습발달상황 파일을 권장합니다.
2
학생 선택 필수
파일 업로드 후 드롭다운에서 상담할 학생을 선택합니다. 학급 전체 학생이 자동으로 목록에 표시됩니다.
3
분석 과목 선택
해당 학생이 이수한 과목이 자동으로 표시됩니다. 체크박스로 그래프에 포함할 과목을 선택하세요. 과목은 국어·수학·영어·사회·과학·기타 계열로 자동 분류되어 그래프에 표시됩니다.
4
진로 희망 입력 (선택)
학생의 진로 희망을 입력하면 상담 프롬프트에 진로 연계 분석이 강화됩니다. 담임 메모도 함께 입력할 수 있습니다.
5
✨ 분석 & 프롬프트 생성 → AI 붙여넣기
생성 버튼을 누르면 성적표·그래프·상담 프롬프트가 한번에 생성됩니다. 프롬프트를 복사해 Claude·ChatGPT 등에 붙여넣으면 상담 자료가 완성됩니다.
📌 차트 보는 법
✅ Y축: 위로 올라갈수록 높은 등급 / 좋은 성취도입니다
✅ 계열 탭을 클릭하면 해당 계열 과목끼리 묶어서 추이를 확인할 수 있습니다
✅ 한 학기만 수강한 과목은 점 하나로 표시됩니다
✅ 엑셀 다운로드로 성적 분석 자료를 저장할 수 있습니다

💡 고등학교 교과학습발달상황: 석차등급 기반 분석
▸ 1~2학년 (공통과목): 5등급제 · 1등급 10% · 2등급 24% · 3등급 32% · 4등급 24% · 5등급 10%
▸ 3학년 (선택과목): 9등급제 · 1등급 4% · 2등급 7% · 3등급 12% … 자동 감지하여 적용
💡 중학교 교과학습발달상황 분석 안내

▸ 원점수/과목평균도 함께 표시됩니다.
💡 전과목 성적 일람표 (고등학교) 파일은 원점수와 석차를 기반으로 가상등급을 자동 산출합니다.
수강자수는 파일에서 자동으로 읽고, 학년에 따라 5등급·9등급 자동 감지하여 적용합니다.
▸ 5등급 (고1~2 공통과목): 1등급 10% · 2등급 24% · 3등급 32% · 4등급 24% · 5등급 10%
▸ 9등급 (고3 선택과목): 1등급 4% · 2등급 7% · 3등급 12% · 4등급 17% · 5등급 20% · …
⚠️ 석차등급(1~9등급)이 이미 기재된 교과학습발달상황 파일은 위의 「교과학습발달상황」 칩을 사용하세요.
💡 전과목 성적 일람표 (중학교) 분석 안내
▸ 이 파일에는 성취도·석차 컬럼이 없어 원점수를 기준으로 성취도를 추정합니다.
   90점 이상 → A / 80점 이상 → B / 70점 이상 → C / 60점 이상 → D / 미만 → E
▸ 실제 성취도는 과목 평균 대비 비율로 결정되므로 이 추정값과 다를 수 있습니다.
▸ 정확한 성취도 분석은 「교과학습발달상황」 파일을 사용하세요.
