📖 사용 가이드
1
성적 파일 업로드 필수
나이스(NEIS)에서 내려받은 .xlsx 파일을 업로드합니다. 학급 전체 파일 한 번에 지원됩니다. 5등급제·9등급제 자동 감지로 학년에 관계없이 모든 파일을 지원합니다.
나이스 → 학급담임 → 학교생활기록부 → 학생부 항목별 조회 → 교과학습발달상황(전체학생)
2
학생 선택 필수
파일 업로드 후 드롭다운에서 상담할 학생을 선택합니다. 학급 전체 학생이 자동으로 목록에 표시됩니다.
3
분석 과목 선택
해당 학생이 이수한 과목이 자동으로 표시됩니다. 체크박스로 그래프에 포함할 과목을 선택하세요. 과목은 국어·수학·영어·사회·과학·기타 계열로 자동 분류되어 그래프에 표시됩니다.
4
진로 희망 입력 (선택)
학생의 진로 희망을 입력하면 상담 프롬프트에 진로 연계 분석이 강화됩니다. 담임 메모도 함께 입력할 수 있습니다.
5
✨ 분석 & 프롬프트 생성 → AI 붙여넣기
생성 버튼을 누르면 성적표·그래프·상담 프롬프트가 한번에 생성됩니다. 프롬프트를 복사해 Claude·ChatGPT 등에 붙여넣으면 상담 자료가 완성됩니다.

✅ 계열 탭을 클릭하면 해당 계열 과목끼리 묶어서 추이를 확인할 수 있습니다
✅ 고교학점제 특성상 한 학기만 수강한 과목은 점 하나로 표시됩니다
✅ 엑셀 다운로드로 성적 분석 자료를 저장할 수 있습니다
