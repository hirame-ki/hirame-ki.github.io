# 손펜 (Sonpen) — 손글씨 연습장 만들기

문구를 입력하면 십자 격자 안에 반투명 글씨를 깔아주는 손글씨 연습장 생성기입니다.
태블릿에서는 화면에 바로 쓸 수 있고, A4로 인쇄하면 딱딱한 문서가 아니라
꾸며진 연습장이 나옵니다.

## 실행

빌드 도구·서버·설치 없이 순수 HTML/CSS/JS입니다.

- `index.html`을 브라우저로 열면 바로 동작합니다.
- 인쇄를 자주 쓴다면 로컬 서버로 여는 편이 폰트 로딩이 안정적입니다.

```bash
python -m http.server 8777
```

그 다음 브라우저에서 `http://localhost:8777` 로 접속합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 · 설정 패널 |
| `styles.css` | 디자인, 격자, A4 인쇄 규칙(`@page`) |
| `app.js` | 상태 관리, 격자/페이지 렌더링, 필기 캔버스 |
| `fonts.js` | 폰트 목록 · 기본 테마 · 장식 문양 |
| `phrases.js` | 추천 문구 103편 (갈래 10종) |
| `corrector.js` | 맞춤법 / 띄어쓰기 자동 교정 규칙 |

## 기능

### 문구
- 여러 줄 입력, 줄마다 1~10회 반복
- 첫 줄은 진하게(견본), 나머지는 흐리게 / 반복할수록 점점 흐려지기
- 따라쓰기 진하기 5~70% 조절
- 맞춤법·띄어쓰기 자동 교정 (아래 설명 참고)
- 추천 문구 **103편** — 갈래 10종에서 골라 누르면 바로 들어갑니다
  (감성 / 시 / 목민심서 / 성찰 일지 / 고전 명언 / 계절과 자연 / 기초 연습 / English / 日本語 / 中文)
- **페이지를 열 때마다 다른 문구**가 놓입니다. `🎲 아무거나 하나`로 언제든 다시 뽑습니다.
  단, 직접 저장해 둔 문구가 있으면 그것이 우선입니다.

### 머리말과 꼬리말
- 제목(머리말) · 아래쪽 응원 문구(꼬리말)를 각각
  **글씨체 · 크기(pt) · 굵기 · 자간 · 간격 · 정렬 · 진하기**로 조절
- 글씨체는 본문과 따로 고를 수 있습니다 (기본은 "본문 글씨체와 같게")
- 이름 / 날짜 칸 넣기
- 제목 크기와 간격을 바꾸면 본문에 남는 높이가 다시 계산되어 페이지 수가 자동으로 맞춰집니다

### 격자 (언어 자동 감지)
입력한 글자를 보고 격자 양식을 자동으로 고릅니다. 수동 지정도 가능합니다.

| 언어 | 양식 |
|---|---|
| 한글 | 네모칸 격자 (한 글자 한 칸) |
| 일본어 | 원고지 칸 |
| 중국어 | 전자격(田) / 미자격(米) |
| 알파벳 | 4선 노트 (윗선·중간 점선·기준선·아랫선) |

격자 종류: **십자 격자 / 점선 십자 / 미자 격자(米) / 네모칸만 / 밑줄만 / 격자 없이**
칸 수(4~20), 칸 간격, 4선 노트 줄 높이를 조절합니다. 격자 색·글씨 색은 `꾸미기` 단계에 있습니다.

### 글씨체
Google Fonts의 무료 폰트 29종을 실었습니다. **흘림체는 넣지 않았고**, 연습에 적합한
정자 계열(고딕·명조·둥근고딕·교육용)만 골랐습니다.

- 한글 14종 (본고딕, 본명조, 나눔고딕, 나눔명조, 고운돋움, 고운바탕, IBM Plex Sans KR, 함렛, 송명, 주아, 도현, 개구, 감자꽃, 검은고딕)
- 일본어 5종 (Noto Sans/Serif JP, Zen Maru Gothic, Zen Kaku Gothic New, BIZ UDPMincho)
- 중국어 3종 (Noto Sans/Serif SC, Noto Sans TC)
- 알파벳 6종 (Andika, Atkinson Hyperlegible, Nunito, Quicksand, Poppins, Lora)

언어를 바꾸면 그 언어에 맞는 기본 글씨체로 자동 전환됩니다.
목록에서 직접 고르면 그 뒤로는 자동 전환하지 않습니다.

### 꾸미기
테마를 고르면 **종이 바탕색 · 격자 색 · 글씨 색 · 테두리 모양 · 테두리 색 · 장식 문양**이
한 번에 바뀝니다. 그 아래 `고른 분위기 다듬기`에서 마음에 안 드는 값만 손보면 됩니다.
(테마를 고를 때마다 이 값들은 테마 색으로 다시 채워지므로, **테마를 먼저 고르고 손보세요.**)
- 기본 테마 10종 (크림 노트, 민트 산책, 복숭아빛, 맑은 하늘, 크라프트, 라벤더, 풀잎 노트, 담백한 흰색, 밤하늘, 벚꽃)
- 종이 바탕색 · 격자 색 · 글씨 색 자유 지정
- 용지 테두리 9종: 없음 / 얇은 실선 / 이중선 / 둥근 모서리 / 점선 / 동글동글 점무늬 / 물결무늬 / 리본 프레임 / 모서리 장식
- 이모티콘 24종 + 직접 입력, 배치 5종(네 모서리 / 위쪽 띠 / 아래쪽 띠 / 흩뿌리기 / 양옆), 크기 조절
- 이미지 업로드 후 배치 6종(모서리 4곳 / 가운데 워터마크 / 머리말 배너), 크기·투명도 조절

### 용지 · 인쇄
- A4 세로 / 가로
- 여백 5~30mm, 미리보기 배율 40~160%
- `인쇄 / PDF 저장` 버튼 → 브라우저 인쇄 대화상자
  (대상을 **PDF로 저장**으로 바꾸면 PDF 파일이 됩니다)
- 배경색·격자가 그대로 인쇄되도록 `print-color-adjust: exact`를 켜 두었습니다.
  브라우저 인쇄 설정에서 **"배경 그래픽"** 옵션이 켜져 있는지 확인하세요.

### 쓰기 모드 (태블릿)
`✍️ 쓰기 모드`를 켜면 종이 위에 그대로 필기할 수 있습니다.
Pointer Events 기반이라 손가락·마우스·스타일러스 모두 됩니다.
펜 색, 굵기 1~12, 지우개, 되돌리기, 전체 지우기를 지원합니다.

### 설정 저장
`용지` 탭의 `현재 설정 저장`을 누르면 브라우저(localStorage)에 저장되어
다음에 열 때 그대로 복원됩니다. `초기화`로 되돌립니다.

## 자동 교정에 대해

`corrector.js`는 **외부 API 없이 브라우저 안에서만 도는 규칙 기반 교정기**입니다.
완전한 맞춤법 검사기가 아니라, 확실한 경우에만 고치는 보수적인 방식입니다.

고치는 것:
- 공백 정리(중복 공백, 줄 끝 공백), 문장부호 앞뒤 간격 (반각·전각 모두)
- 자주 틀리는 한국어 단어 약 60개 (며칠, 오랜만에, 역할, 설렘, 웬일, 할게, 하려고, 일일이 …)
- 의존명사 띄어쓰기 (`할수있다` → `할 수 있다`, `것같다` → `것 같다`, `때문에`, `-지 않다` 등)
- 옛 표기 `-읍니다` → `-습니다`
- 영어 철자 오류 약 35개, `i` → `I`, 문장 첫 글자 대문자

일부러 **건드리지 않는 것** (문맥을 봐야 해서 오교정 위험이 큼):
- 되/돼 전반, 바램/바람, 든지/던지, 낫다/낳다, 예기/얘기 등

정확도가 더 필요하면 `corrector.js`의 `KO_WORDS` / `KO_REGEX` 배열에
직접 항목을 추가하면 됩니다. 형식은 파일 안 주석에 있습니다.

## 추천 문구의 저작권

`phrases.js`에 실린 인용문은 **저작권 보호기간이 끝난 것만** 골랐습니다.

- 시 — 윤동주, 김소월, 한용운, 이육사, 정지용, 김영랑, 황진이, 윤선도
  (모두 사후 70년이 지나 만료)
- 고전 — 목민심서·다산 정약용, 논어, 명심보감, 채근담, 노자, 맹자, 속담
- 영어 — Thoreau, Marcus Aurelius, Emerson, Frost, Dickinson
- 그 밖의 감성·성찰·계절 문장은 이 프로젝트에서 직접 쓴 것입니다.

생존 작가의 글, 저작권이 남아 있는 현대 시, 노래 가사는 **넣지 않았습니다.**
문구를 추가할 때도 같은 기준을 지켜 주세요.

한문 고전의 우리말 옮김은 판본마다 표현이 다릅니다. 실린 것은 널리 쓰이는 형태를
다듬은 것이며, 학술적으로 특정 번역본을 따른 것은 아닙니다.

## 모바일 · 태블릿

폭 900px 아래에서는 설정 패널이 옆이 아니라 **위쪽에 쌓여** 설정 → 미리보기 순서로 놓입니다.

- 단계 레일은 좌우로 밀어서 넘깁니다
- `이전 / 다음` 버튼은 화면 아래에 붙어 따라다닙니다
- 미리보기는 **화면 폭에 맞춰 자동으로 축소**됩니다 (가로 스크롤이 생기지 않습니다).
  화면을 돌리거나 창 크기를 바꾸면 다시 맞춰집니다.
- 상단 버튼은 좁은 화면에서 아이콘 위주로 줄어듭니다

## 브라우저

Chrome, Edge, Safari, Firefox 최신 버전. 인쇄 결과는 Chrome/Edge가 가장 정확합니다.
아이패드 Safari에서도 쓰기 모드가 동작합니다.

## 알려진 제약

- 폰트를 Google Fonts CDN에서 받으므로 **첫 실행에는 인터넷 연결이 필요**합니다.
  오프라인으로 쓰려면 폰트 파일을 내려받아 `@font-face`로 바꿔 넣으세요.
- 쓰기 모드에서 그린 필기는 설정을 바꿔 다시 그리면 페이지 수가 달라질 수 있어
  위치가 어긋날 수 있습니다. 필기는 설정을 다 정한 뒤에 시작하는 것이 좋습니다.
- 한 줄이 칸 수를 넘으면 다음 줄로 넘어가며, 반복은 넘어간 줄마다 따로 적용됩니다.
