쌤보드 SsamBoard

바탕화면 자체가 교무실 책상이 되는 교사 전용 위젯

지금이 몇 교시인지, 이 시간이 몇 분 남았는지가 바탕화면 위에 늘 떠 있습니다. 시간표·급식·학사일정은 NEIS에서 자동으로 불러오고, 수업 도구와 업무 도구도 바로 꺼내 씁니다.

처음 설치할 때 파란색 Windows 보안 창이 뜨면 [추가 정보] → [실행]을 누르세요. 설치 파일은 SsamBoard.Setup.x.x.x.exe 하나만 받으면 됩니다.
  • 위젯 21종 — 시간표, 교시 타이머, 급식, 날씨, 학사일정, 할 일, D-DAY, 명렬표 등
  • 수업 도구 — 무작위 추첨, 타이머, 사다리, 룰렛, QR코드, 소음측정기
  • 업무 도구 12종 — 상담 일지, 진도 체크, 성적 분석, 공문서 도우미, 생기부 초안
  • 휴대폰 연동 — 구글 계정 한 번 연결로 PC의 기록을 휴대폰에서 이어서 확인·입력
  • 학사일정 내보내기 — 학교 일정을 구글 캘린더·엑셀로 한 번에

이지테스트 EzTest

교과서·기출만 올리면 시험 원안지를 만들어 주는 교사용 프로그램

양식을 따로 준비하실 필요가 없습니다. 학교 로고와 학교 정보가 양식에 저절로 들어가고, 만든 문항은 스스로 검산합니다. 새 버전이 나오면 프로그램이 알려 드려요.

시작 전 확인 — 한글(HWP)이 설치되어 있어야 하고, 안내 페이지에 따라 API 키를 받아 넣어야 합니다. 압축을 풀기 전에 파일 속성에서 ‘차단 해제’를 먼저 해 주세요.

기본 2
기본 제공시트 사본

냈니? 냈어요! 과제관리 시스템

종이로 걷던 과제를 웹으로 받는 제출·피드백 시스템

학생은 회원가입이나 구글 로그인 없이 여섯 자리 코드만으로 과제를 냅니다. 선생님은 현황판 한 화면에서 누가 냈는지 확인하고, 칸을 눌러 바로 피드백을 남깁니다.

  • 제출 현황판 — 학생 × 과제 제출 상태를 한눈에
  • 피드백 · 반려 · 칭찬 스티커 — 칸을 눌러 바로 남기기
  • 내 드라이브에 저장 — 제출 파일은 선생님 본인의 구글 드라이브로
  • 생기부 기초 자료 — 쌓인 제출·피드백 기록을 학기말에 그대로
내 드라이브에 사본 만들기

처음 설정과 학생 코드 배부 방법은 사본 안의 사용설명서를 참고하세요.

기본 제공시트 사본+ 서명 웹페이지

연수 전자서명 QR 찍고 서명하면 끝

휴대폰 화면에 서명하면 연수 서명등록부가 완성됩니다

종이 서명부를 돌리는 대신 QR로 접속해 서명합니다. 서명 이미지가 들어간 등록부를 A4로 인쇄하거나 PDF로 저장할 수 있고, 서명 가능 시간 제한·매일 바뀌는 QR·중복 서명 차단으로 대리 서명을 막습니다.

이 자료는 시트 사본과 서명 웹페이지, 두 가지를 함께 씁니다. 처음 한 번만 연결하면 이후 명단·연수·설정은 모두 웹 화면에서 관리합니다.
① 시트 사본 만들기 ② 서명 페이지 열기
  1. 시트 사본 만들기① 버튼을 눌러 서명 시스템 시트를 내 드라이브에 복사합니다.
  2. 웹 앱으로 배포하고 주소 복사사본의 Apps Script를 웹 앱으로 배포한 뒤, https://script.google.com/macros/s/…/exec 형태의 배포 URL을 복사합니다.
  3. 서명 페이지에 붙여 넣기② 서명 페이지의 ‘웹앱 배포 URL’ 칸에 붙여 넣고 [연결하기]를 누릅니다.
  4. 명단·연수 등록 후 QR 공유관리자 화면에서 구성원과 연수를 등록하고, 공유 링크나 QR을 안내하면 끝입니다.
