1설치 파일 받기

아래 버튼을 누르면 구글 드라이브가 새 탭으로 열려요. 쌤패스-설치-버전.exe 파일을 받아 주세요.

구글 드라이브에서 받기
드라이브 화면에서 파일을 누른 뒤 오른쪽 위 다운로드(↓) 버튼을 누르면 이름 그대로 받아져요. "바이러스 검사를 할 수 없다"는 안내가 나오면 [무시하고 다운로드]를 누르세요. 크기가 작은 설치 파일이라 나오는 일반 안내예요.
↓

브라우저가 "일반적으로 다운로드되지 않습니다"라고 할 때

받기를 눌렀는데 파일이 바로 저장되지 않고 경고가 뜰 수 있어요. 이때 그냥 두면 다운로드 폴더에 확인되지 않음 123456.crdownload처럼 이상한 이름으로 남고, 실행되지 않아요.

  1. 엣지: 오른쪽 위 다운로드 창에서 파일 옆 ① …(추가 작업) → ② [유지]
  2. "신뢰할 수 있는지 확인합니다" 창이 뜨면 검은 [삭제] 버튼은 누르지 말고, 그 오른쪽의 ③ 작은 화살표(∨)를 눌러요 → ④ [그래도 계속]
  3. 크롬: 다운로드 창의 경고에서 [계속](또는 [유지])을 누르면 돼요.
  4. 그러면 쌤패스-설치-버전.exe 이름으로 저장돼요. 이미 이상한 이름으로 남은 파일은 이름을 고치지 말고 지운 뒤 다시 받아 주세요.
안전한가요?이 경고는 바이러스를 찾았다는 뜻이 아니에요. "게시자: 알 수 없음"은 유료 코드 서명 인증서를 쓰지 않은 개인 제작 파일이라 나오는 표시이고, "일반적으로 다운로드되지 않음"은 아직 받은 사람이 많지 않다는 뜻이에요. 쌤패스 설치 파일은 관리자 권한 없이 확장 파일을 내 사용자 폴더(%LOCALAPPDATA%\NeisHelper)에만 넣어요. [이 앱을 안전한 것으로 보고]는 누르지 않아도 돼요.
다만 이 페이지의 [구글 드라이브에서 받기]로 연 공식 폴더에서 받은 파일일 때만 [그래도 계속]을 누르세요. 다른 곳에서 받았거나 출처가 헷갈리면 [삭제]하세요.

2설치 파일 실행 · 경고창이 뜨면

받은 파일을 두 번 클릭해요. 관리자 권한은 필요 없어요. 끝나면 이 페이지가 다시 열리고 폴더 경로가 복사돼요.

Win

"Windows의 PC 보호" 파란 창

  1. 처음에는 [실행 안 함] 버튼만 보여요. 누르지 말고, 창 안의 ① 추가 정보 글자를 눌러요.
  2. 오른쪽 아래에 ② [실행] 버튼이 생겨요. 옆의 [실행 안 함]이 아니라 왼쪽 [실행]을 눌러 주세요.
V3

안랩 V3 "프로그램 실행 알림" (주황색 창)

설치 파일을 실행할 때 뜰 수 있어요. 기본 선택이 [한 번만 차단]이라 그대로 [확인]을 누르면 설치되지 않아요.

  1. "파일 처리 방법을 선택하십시오" 목록을 열고 [한 번만 실행]을 고른 뒤 [확인].
  2. 설치가 끝나면 다시 뜨지 않아요. 쌤패스는 브라우저 안에서만 돌아가고, 따로 실행되는 프로그램이 없어요(0.15.0부터).
  3. 목록이 회색이라 고를 수 없으면 학교에서 V3를 한꺼번에 관리하는 경우예요. 정보(전산) 담당 선생님께 설치 파일 실행을 부탁하세요.
왜 뜨나요? 회사 인증서로 서명하지 않은 개인 제작 설치 파일이라, V3가 처음 보는 파일로 판단해 조심스럽게 묻는 거예요. 반드시 이 페이지(공식 배포처)에서 받은 파일일 때만 실행하세요.

3브라우저에 확장 등록 처음 한 번만

쓰는 브라우저를 골라 주세요. 두 브라우저 모두 쓰면 각각 한 번씩 해요.

3-1확장 관리 화면 열기

주소창에 edge://extensions 를 붙여 넣고 Enter

3-2왼쪽 아래 '개발자 모드' 켜기

화면 왼쪽 메뉴의 맨 아래에 있는 개발자 모드 스위치를 켜요.

3-3위쪽에 생긴 '압축 풀린 … 로드' 버튼 누르기

개발자 모드를 켜면 오른쪽 위에 버튼 세 개가 생겨요. 그중 첫 번째 버튼(압축 풀린 … 로드)을 눌러요.

3-1확장 관리 화면 열기

주소창에 chrome://extensions 를 붙여 넣고 Enter

3-2오른쪽 위 '개발자 모드' 켜기 → 3-3 '압축해제된 확장 프로그램 로드'

① 화면 오른쪽 위의 개발자 모드 스위치를 켜면 ② 왼쪽 위에 [압축해제된 확장 프로그램 로드] 버튼이 생겨요. 이 버튼을 눌러요.

3-4폴더 고르는 창: 이 폴더로 들어가서 [폴더 선택]

"폴더를 선택하세요" 창이 열리면 위쪽 주소칸을 한 번 누르고 아래 경로를 붙여 넣은 뒤 Enter 를 눌러요. (설치 직후라면 경로가 이미 복사돼 있어 Ctrl+V만 하면 돼요.)

%LOCALAPPDATA%\NeisHelper\app\extension
안에 icons·img 폴더가 보이면 제대로 들어온 거예요. 그 폴더들을 누르지 말고, 아래 '폴더:' 칸도 비워 둔 채 바로 [폴더 선택]을 누르세요. 확장 목록에 쌤패스 카드가 생기면 성공!
"매니페스트 파일이 없습니다" 오류가 나면 한 단계 위(app)나 아래(icons) 폴더를 고른 거예요. 주소칸 끝이 …\NeisHelper\app\extension인지 다시 확인하세요.

4툴바에 고정하고 처음 설정

주소창 오른쪽의 확장 아이콘을 누르면 설치된 확장 목록이 나와요. 쌤패스 옆의 핀 아이콘을 누르면 툴바에 늘 보여요. 확장 아이콘은 브라우저마다 모양이 달라요.

엣지즐겨찾기(☆) 아이콘 바로 왼쪽, 꽃잎처럼 둥근 조각 모양 ①
크롬주소창 오른쪽 끝 근처의 퍼즐 조각
고정하면 이 아이콘누르면 쌤패스 실행 화면

4-2비밀번호 · PIN 저장

  1. 쌤패스 아이콘 → 오른쪽 위 [설정] → 비밀번호·잠금
  2. 인증서 비밀번호를 두 번, PIN(숫자 6~12자리)을 두 번 넣고 [저장]
  3. 툴바 아이콘에서 PIN으로 잠금을 풀면 준비 끝!
경기도가 아니면 설정 › 로그인에서 업무포털 주소(○○.eduptl.kr)를 바꿔 주세요.

?안 될 때

받은 파일 이름이 "확인되지 않음 123456.crdownload"처럼 이상해요

브라우저가 경고를 띄우고 저장을 멈춘 상태예요. 그 파일은 지우고 다시 받은 뒤, 다운로드 창에서 … → [유지] → 확인 창의 [삭제] 오른쪽 작은 화살표(∨) → [그래도 계속]을 누르세요. (1단계 안내)

새 버전을 설치했는데 그대로예요

1분쯤 기다리거나, 확장 관리 화면에서 쌤패스 카드의 새로고침(↻)을 누르세요. 다른 폴더에서 불러온 쌤패스가 하나 더 있으면 먼저 [제거]하세요.

PIN 화면 대신 "처음 설정이 필요합니다"가 나와요

0.15.0부터 비밀번호를 쌤패스 안에 보관해요. 0.14 이하에서 올라왔다면 인증서 비밀번호와 PIN을 한 번만 다시 저장해 주세요.

"개발자 모드 확장 사용 안 함" 안내가 떠요

웹스토어 밖 프로그램이라 나오는 안내예요. [닫기]나 ×를 누르면 돼요. (끄면 쌤패스가 꺼져요)

개발자 모드 스위치가 회색이라 켜지지 않아요

학교에서 브라우저를 관리하는 PC일 수 있어요. 정보(전산) 담당 선생님께 문의해 주세요.

지우고 싶어요

Win+R → %LOCALAPPDATA%\NeisHelper\NeisHelperSetup.exe /uninstall → Enter, 그다음 확장 관리 화면에서 쌤패스 [제거]. 저장한 비밀번호도 함께 지워져요.
