01 · 기능

매일 하던 클릭,
쌤패스가 먼저 해 둘게요

모두 선생님 브라우저 안에서, 선생님이 보는 앞에서 동작해요. 아래 화면은 실제 프로그램 화면입니다. (이름·내용은 예시)

1바로 열기

PIN 한 번 풀고,
필요한 화면은 버튼 하나로

인증서 비밀번호는 이 PC에만 암호화해 두고, 아침에 PIN으로 잠금을 풀면 팝업 맨 위 바로 열기에서 [업무포털] · [K-에듀파인] · [나이스] · [과세특 입력]을 눌러요. 인증서 로그인부터 그 화면까지 이어서 열어 줘요.

  • 업무포털 창이 없으면 주소부터 열고, 이미 로그인돼 있으면 그 단계는 건너뛰어요
  • "업무포털을 열면 자동 로그인"을 켜면 열기만 해도 로그인
  • 비밀번호가 틀리면 다시 시도하지 않고 멈춰요 (인증서 잠김 방지)
2복무 신청 루틴

로그인부터 결재선까지,
복무 신청도 버튼 하나로

시각·사유·개인결재선을 버튼에 저장해 두면, 누를 때 업무포털 로그인 → 나이스 열기 → 신청 창 → 결재선 지정까지 이어서 해요. 내용을 보고 [상신]은 직접 눌러요.

  • 시간외근무 · 연가 · 조퇴 · 외출 · 지각 · 병조퇴 · 출장
  • 이미 로그인돼 있거나 나이스가 열려 있으면 그 단계는 건너뛰어요
  • 날짜 · 그날만 다른 시각 · 끝나는 날(연가 · 출장)은 팝업에서 바로 바꾸기
  • Alt+Shift+1처럼 단축키로도 실행
3NEW · 과세특

쓰던 엑셀 그대로,
과세특 칸에 옮겨 적어요

엑셀 양식이 달라도 학년·반·번호·이름·내용 열을 스스로 찾아요. 나이스에서 강의실을 조회하면 명단을 맞추고, 맞는 학생만 넣어요.

  • 반 · 번호 · 이름이 모두 맞아야 입력 (한 줄 밀림 방지)
  • 학생별 남은 바이트 · 이모지 · 이미 쓴 내용 미리 검사
  • 누르면 로그인 → 나이스 → 과세특 화면(OTP 창)까지 자동
  • OTP와 [저장]은 직접, 저장되면 다음 강의실로 이어서
4안전

편한 만큼,
잠금은 꼼꼼하게

비밀번호는 PIN으로 암호화해 이 브라우저 안에만 둬요. 잠금 방식은 직접 고를 수 있어요.

  • 기본: 자리를 비운 시간·최대 유지 시간이 지나면 잠금
  • 선택: PC 화면을 잠글 때(Win+L)만 잠금 — 동의 후 켜기
  • PIN 5번 틀리면 잠시 입력 차단
자동 업데이트새 버전은 스토어(엣지·크롬)가 알아서 설치해요. 따로 받을 필요가 없어요.
엑셀 열 배치 기억한 번 고친 양식은 다음부터 자동으로 맞춰요.
2차 인증 남은 시간과세특 입력 중 OTP가 곧 끝나면 미리 알려 줘요.
어디서나 단축키업무포털 · 복무 신청 루틴 · K-에듀파인 · 나이스를 키보드로.
다른 시도교육청업무포털 주소만 바꾸면 돼요. (기본: 경기)
화면 테마 6종스카이 · 베이지 · 라임 · 민트 · 라벤더 · 피치 중에서 골라요. 눌러서 이 페이지에 미리 입혀 보세요.
02 · 사용 설명서

사용 설명서

툴바의 쌤패스 아이콘(또는 Alt+Shift+N) → 오른쪽 위 [설정]을 누르면 설정 화면이 열려요. 화면 사진이 더 많은 전체 사용 설명서(노션) ↗도 있어요. 처음이라면 실제 화면으로 따라 보는 사용법 영상부터 보세요.

처음 설정: 비밀번호와 PIN

  1. 설정 › 비밀번호·잠금에서 인증서 비밀번호를 두 번 넣어요.
  2. 잠금을 풀 때 쓸 PIN(숫자 6~12자리)을 정해요.
  3. [저장]하고 툴바 아이콘에서 PIN으로 잠금을 풀면 준비 끝.
  4. "언제 잠글까요?"에서 잠금 방식을 고를 수 있어요.
비밀번호는 PIN으로 암호화(AES-256)해 이 브라우저 안에만 보관해요. PIN을 5번 틀리면 잠시 잠겨요.

바로 열기

  1. 팝업 맨 위 바로 열기의 [업무포털]을 누르면 업무포털을 열고 인증서 로그인까지 해요.
  2. [K-에듀파인] · [나이스]는 업무포털 로그인부터 그 화면까지, [과세특 입력]은 과세특 메뉴(OTP 창)까지 이어서 열어요. 이미 된 단계는 건너뛰어요.
  3. 설정 › 로그인의 스위치를 켜면 업무포털을 열기만 해도 로그인해요.
  4. 다른 시도교육청은 업무포털 주소를 바꿔 주세요.
로그아웃한 뒤 돌아온 로그인 화면에서는 다시 로그인하지 않아요.

복무 신청 루틴

  1. 나이스 ⚙개인설정 › 업무승인자관리 › 개인결재선관리에서 결재선을 먼저 만들어요. (설정의 [등록 방법]에 순서 사진이 있어요)
  2. 설정 › 복무 신청 루틴 › [+ 버튼 추가]: 종류(시간외근무 · 연가 · 조퇴 등 · 출장) · 시각 · 사유 · 결재선 이름
  3. 팝업의 버튼을 누르면 업무포털 로그인 → 나이스 열기 → 결재선 지정까지 이어서 해요. 이미 된 단계는 건너뛰어요.
  4. 날짜 · 시각 · 끝나는 날(연가 · 출장)은 팝업의 "바꾸기"에서 그날만 바꿔요.
  5. 나이스 화면에서 확인하고 [상신]은 직접.
시간외근무는 수당과 직결돼요. 실제 근무와 다른 날짜·시각이 올라가지 않도록 꼭 확인하세요.

과세특 엑셀 입력

  1. 팝업 › 바로 열기 › [과세특 입력] — 업무포털 로그인 → 나이스 → 과세특 메뉴까지 알아서 열려요(된 단계는 건너뜀)
  2. 나이스에서 OTP 입력 → 쌤패스 과세특 탭으로 돌아와 엑셀 파일 불러오기
  3. "이렇게 이해했어요"에서 열이 맞는지 확인 (틀리면 바꾸기)
  4. 나이스에서 학기·과목·강의실을 고르고 [조회]
  5. 맞추기 표를 보고 [입력 시작] — 이미 내용이 있는 학생은 체크해야 바꿔요
  6. 나이스에서 확인 후 [저장] → 다음 강의실을 조회하면 이어서
엑셀은 화면 안에서만 읽고 저장·전송하지 않아요. 나이스 양식(엑셀내려받기)으로 쓴 파일도 그대로 넣을 수 있어요.

자동 상신 (선택)

  1. 기본은 꺼짐 — 결재선까지 넣고 멈춰요.
  2. 켜려면 수당·책임 안내를 읽고 동의해야 해요.
  3. 켜면 복무 신청 루틴 버튼 · 단축키 모두 [상신]과 그 뒤 나이스 확인 창까지 눌러요.

단축키

  1. Alt+Shift+N 팝업 열기
  2. Alt+Shift+L 업무포털 로그인
  3. Alt+Shift+1~2 복무 신청 루틴 1·2번 (오늘 날짜, 로그인부터)
  4. [단축키 바꾸기]에서 3~6번 · K-에듀파인 · 나이스도 지정할 수 있어요.

화면 테마

  1. 설정 › 화면에서 6가지 색 중 하나를 골라요: 스카이(기본) · 베이지 · 라임 · 민트 · 라벤더 · 피치.
  2. 고르는 즉시 팝업 · 설정 · 과세특 화면에 함께 바뀌어요. 열려 있는 창도 바로 따라 바뀌어요.
  3. 고른 테마는 이 브라우저에만 저장돼요.

정보 · 업데이트

  1. 새 버전은 스토어가 자동으로 설치해요. 선생님이 할 일은 없어요.
  2. 새 버전은 엣지 확장 스토어·크롬 웹 스토어의 심사를 거친 뒤에 배포돼요.
  3. 설정 › 정보에서 지금 쓰는 버전을 볼 수 있어요. 바뀐 점은 이 페이지의 업데이트 기록에 있어요.
쌤패스는 브라우저 안에서만 돌아가요. 따로 설치되는 프로그램이 없어서 백신 확인 창도 뜨지 않아요.
03 · 시작하기

3단계면 바로 시작

엣지는 엣지 확장 스토어, 크롬은 크롬 웹 스토어에서 받아요. 관리자 권한도, 설치 파일도 필요 없어요.

스토어에서 받기

아래 버튼이 지금 브라우저에 맞는 스토어를 열어요. 엣지는 [받기], 크롬은 [Chrome에 추가] → [확장 추가]를 눌러요.

엣지 스토어에서 받기

다른 브라우저용 엣지 확장 스토어크롬 웹 스토어

툴바에 고정

주소창 오른쪽, 즐겨찾기(☆) 왼쪽의 확장 아이콘을 눌러요. 목록의 쌤패스 줄 오른쪽 핀(압정) 아이콘을 누르면 툴바에 쌤패스 아이콘이 생겨요. 이제 툴바에서 바로 열 수 있어요.

처음 받으면 설정의 시작 안내가 저절로 열려요. 그 순서대로 따라 해도 돼요.

04 · 안전

선생님 정보는
선생님 PC에만

PIN 암호화 금고인증서 비밀번호는 PIN으로 암호화(AES-256)해 이 브라우저 안에만 둬요. 5번 틀리면 잠겨요.
외부 전송 없음비밀번호 · 학생 정보를 어디에도 보내지 않아요. 바깥으로 나가는 연결이 하나도 없어요. 업데이트는 스토어가 맡아요.
마지막은 사람이기본은 [상신] · [저장]을 선생님이 확인하고 눌러요. [상신]은 설정 › 자동 상신에서 안내에 동의하고 켜면 자동으로도 할 수 있어요. 과세특 [저장]과 OTP는 늘 직접 해요.
스토어 심사를 거친 버전만새 버전마다 엣지 확장 스토어·크롬 웹 스토어의 심사를 거쳐 배포돼요. 따로 설치되는 프로그램도 없어요.
직접 확인

말로만 말고,
쌤패스 안에서 확인하세요

설정 › 안전 확인은 쌤패스 구성 파일(manifest.json)을 그 자리에서 읽어 보여 줘요. 권한이 하나라도 바뀌면 그대로 드러나요. 팝업 맨 아래 초록 표시를 눌러도 열려요.

  • 인증서 파일 읽기 · PC 프로그램 실행: 권한 없음
  • 동작하는 사이트: 업무포털(○○.eduptl.kr) · 나이스(○○.neis.go.kr)만
  • 인증서 비밀번호는 업무포털 인증서 창의 비밀번호 칸에만 넣어요. 직접 타이핑하는 것과 같은 자리예요.
  • 쌤패스의 코드는 압축·난독화하지 않은 원본 그대로라 누구나 열어 볼 수 있어요.
알아 두실 한계
  • 잠금이 풀린 동안 자리를 비우면 다른 사람이 쓸 수 있어요. 자리를 비울 땐 Win+L.
  • PIN 5번 오류 잠금은 쌤패스 화면에서만 걸려요. 누가 브라우저 프로필 폴더를 통째로 복사해 가면 짧은 PIN은 대입해서 풀 수 있어요. PIN은 길게(최대 12자리) 정하세요.
  • PC에 이미 악성 프로그램이 있다면 쌤패스도, 직접 입력하는 비밀번호도 지킬 수 없어요.

자주 묻는 질문

교육청에서 만든 공식 프로그램인가요?
아니요. 현직 교사가 개인적으로 만든 비공식 도구예요. 나이스·업무포털 화면이 바뀌면 일부 기능이 잠시 동작하지 않을 수 있어요. 학교·교육청의 정보보안 지침을 먼저 확인하고 사용해 주세요.
인증서 비밀번호를 저장해도 안전한가요?
PIN으로 암호화(AES-256)해 이 브라우저 안에만 보관하고, 어디로도 보내지 않아요. 쌤패스에는 PC의 파일(인증서 파일 포함)을 읽는 권한도 없어요. PIN을 5번 틀리면 잠시 잠겨요. 설정 › 안전 확인에서 권한을 직접 볼 수 있어요. 여러 사람이 같이 쓰는 PC에서는 쓰지 마세요. 또 잠금이 풀린 채 자리를 비우면 다른 사람이 쓸 수 있으니, 자리를 비울 땐 Win+L로 PC를 잠가 주세요.
[상신]까지 자동으로 할 수는 없나요?
기본은 결재선 지정까지 하고 멈춰요. 시간외근무는 수당과 직결되기 때문이에요. 설정 › 자동 상신에서 안내에 동의하면 켤 수 있지만 책임은 사용자에게 있어요. 켜면 [상신]과 그 뒤 나이스 확인 창까지 눌러요.
스토어에서 받는 게 안전한가요?
엣지 확장 스토어는 마이크로소프트가, 크롬 웹 스토어는 구글이 운영하는 공식 확장 스토어예요. 쌤패스는 두 스토어의 심사를 모두 통과했고, 새 버전도 매번 심사를 거쳐 배포돼요. 설치 파일을 따로 실행하지 않으니 Windows나 백신 경고 창도 뜨지 않아요. 쌤패스가 받은 권한은 설정 › 안전 확인에서 직접 볼 수 있어요.
크롬에서도 되나요?
네. 크롬은 크롬 웹 스토어에서 받아요. 받기 버튼이 지금 브라우저에 맞는 스토어를 열어 줘요. 엣지 스토어의 확장은 크롬에 설치할 수 없으니, 브라우저마다 맞는 스토어에서 받아 주세요. 학교 PC와 집 PC 브라우저가 다르면 각각 받으면 돼요(비밀번호·PIN도 각각 저장).
다른 시도교육청에서도 되나요?
업무포털 주소가 ○○.eduptl.kr 형태라면 설정 › 로그인에서 주소만 바꾸면 돼요. 처음 만든 곳은 경기도라, 다른 지역은 화면이 조금 달라 일부 기능이 다를 수 있어요.
엑셀 양식이 사람마다 다른데 괜찮나요?
머리글과 값 모양으로 학년·반·번호·이름·내용 열을 스스로 찾아요. 병합된 칸, 시트별 반, "2/17" 같은 반/번호, 학번, 이동반도 알아봐요. 틀리게 알아보면 확인 화면에서 고치면 되고, 고친 배치는 기억해요.
업데이트는 어떻게 하나요?
할 일이 없어요. 새 버전이 나오면 스토어가 알아서 설치해요. 새 버전은 스토어 심사를 거친 뒤에 배포돼서, 나온 뒤 며칠 걸릴 수 있어요. 바뀐 점은 이 페이지의 업데이트 기록에서 볼 수 있어요.
맥(Mac)이나 휴대폰에서도 쓸 수 있나요?
지금은 Windows 10·11의 엣지·크롬만 지원해요. 업무포털 인증서 프로그램이 Windows용이기 때문이에요.
지우고 싶어요.
툴바의 쌤패스 아이콘을 마우스 오른쪽 버튼으로 눌러 [Microsoft Edge에서 제거](크롬은 [Chrome에서 삭제])를 누르세요. (또는 주소창에 edge://extensions·chrome://extensions → 쌤패스 [제거]) 저장한 비밀번호와 설정도 함께 지워져요.
정말 무료인가요?
네, 완전 무료예요. 광고도, 회원 가입도 없어요.
