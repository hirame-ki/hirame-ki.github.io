01 · 기능

매일 하던 클릭,
쌤패스가 먼저 해 둘게요

모두 선생님 브라우저 안에서, 선생님이 보는 앞에서 동작해요. 아래 화면은 실제 프로그램 화면입니다. (이름·내용은 예시)

1아침 1초

PIN 한 번이면
업무포털 로그인 끝

인증서 비밀번호는 이 PC에만 암호화해 두고, 아침에 PIN으로 잠금을 풀면 [업무포털 로그인] 한 번으로 인증서 로그인까지 해요.

  • 업무포털 창이 없으면 주소부터 열어 줘요
  • "업무포털을 열면 자동 로그인"을 켜면 열기만 해도 로그인
  • 비밀번호가 틀리면 다시 시도하지 않고 멈춰요 (인증서 잠김 방지)
2루틴

"로그인 → 나이스 → 조퇴"
순서를 묶어 버튼 하나로

자주 하는 순서를 루틴으로 저장해 두면 팝업 맨 위 버튼 하나로 이어서 실행해요.

  • 순서: 로그인만 / → K-에듀파인 / → 나이스 / → 나이스 → 복무 신청
  • 이미 로그인돼 있거나 나이스가 열려 있으면 그 단계는 건너뛰어요
  • 복무 신청이 들어간 루틴도 [상신] 앞에서 멈춰요
3복무

시간외근무 · 조퇴,
결재선까지 채워 둘게요

시각·사유·개인결재선을 버튼에 저장해 두면 날짜만 골라 나이스 신청 창과 결재선 지정까지 채워요. 내용을 보고 [상신]은 직접 눌러요.

  • 시간외근무 · 조퇴 · 외출 · 지각 · 병조퇴 등
  • 그날만 다른 시각은 팝업에서 바로 바꾸기
  • Alt+Shift+1처럼 단축키로도 실행
4NEW · 과세특

쓰던 엑셀 그대로,
과세특 칸에 옮겨 적어요

엑셀 양식이 달라도 학년·반·번호·이름·내용 열을 스스로 찾아요. 나이스에서 강의실을 조회하면 명단을 맞추고, 맞는 학생만 넣어요.

  • 반 · 번호 · 이름이 모두 맞아야 입력 (한 줄 밀림 방지)
  • 학생별 남은 바이트 · 이모지 · 이미 쓴 내용 미리 검사
  • 누르면 로그인 → 나이스 → 과세특 화면(OTP 창)까지 자동
  • OTP와 [저장]은 직접, 저장되면 다음 강의실로 이어서
5안전

편한 만큼,
잠금은 꼼꼼하게

비밀번호는 PIN으로 암호화해 이 브라우저 안에만 둬요. 잠금 방식은 직접 고를 수 있어요.

  • 기본: 자리를 비운 시간·최대 유지 시간이 지나면 잠금
  • 선택: PC 화면을 잠글 때(Win+L)만 잠금 — 동의 후 켜기
  • PIN 5번 틀리면 잠시 입력 차단
새 버전 알림새 버전이 나오면 아이콘에 NEW. 받아서 실행하면 끝.
엑셀 열 배치 기억한 번 고친 양식은 다음부터 자동으로 맞춰요.
2차 인증 남은 시간과세특 입력 중 OTP가 곧 끝나면 미리 알려 줘요.
어디서나 단축키로그인 · 복무 신청 · K-에듀파인을 키보드로.
다른 시도교육청업무포털 주소만 바꾸면 돼요. (기본: 경기)
화면 테마 6종스카이 · 베이지 · 라임 · 민트 · 라벤더 · 피치 중에서 골라요. 눌러서 이 페이지에 미리 입혀 보세요.
02 · 사용 설명서

사용 설명서

툴바의 쌤패스 아이콘(또는 Alt+Shift+N) → 오른쪽 위 [설정]을 누르면 설정 화면이 열려요.

처음 설정: 비밀번호와 PIN

  1. 설정 › 비밀번호·잠금에서 인증서 비밀번호를 두 번 넣어요.
  2. 잠금을 풀 때 쓸 PIN(숫자 6~12자리)을 정해요.
  3. [저장]하고 툴바 아이콘에서 PIN으로 잠금을 풀면 준비 끝.
  4. "언제 잠글까요?"에서 잠금 방식을 고를 수 있어요.
비밀번호는 PIN으로 암호화(AES-256)해 이 브라우저 안에만 보관해요. PIN을 5번 틀리면 잠시 잠겨요.

업무포털 로그인

  1. 팝업의 [업무포털 로그인]을 누르면 업무포털을 열고 인증서 로그인까지 해요.
  2. 설정 › 로그인의 스위치를 켜면 업무포털을 열기만 해도 로그인해요.
  3. 다른 시도교육청은 업무포털 주소를 바꿔 주세요.
로그아웃한 뒤 돌아온 로그인 화면에서는 다시 로그인하지 않아요.

루틴 만들기

  1. 설정 › 루틴 › [+ 루틴 추가]
  2. 이름(예: 출근)과 순서를 고르고 [저장]
  3. 팝업 맨 위에 버튼이 생겨요.

복무 신청 버튼

  1. 나이스 ⚙개인설정 › 업무승인자관리 › 개인결재선관리에서 결재선을 먼저 만들어요.
  2. 설정 › 복무 신청 › [+ 버튼 추가]: 종류 · 시각 · 사유 · 결재선 이름
  3. 나이스를 연 상태에서 팝업의 버튼을 누르면 결재선 지정까지 채워요.
  4. 나이스 화면에서 확인하고 [상신]은 직접.
시간외근무는 수당과 직결돼요. 실제 근무와 다른 날짜·시각이 올라가지 않도록 꼭 확인하세요.

과세특 엑셀 입력

  1. 팝업 › 바로 열기 › [과세특 입력] — 업무포털 로그인 → 나이스 → 과세특 메뉴까지 알아서 열려요(된 단계는 건너뜀)
  2. 나이스에서 OTP 입력 → 쌤패스 과세특 탭으로 돌아와 엑셀 파일 불러오기
  3. "이렇게 이해했어요"에서 열이 맞는지 확인 (틀리면 바꾸기)
  4. 나이스에서 학기·과목·강의실을 고르고 [조회]
  5. 맞추기 표를 보고 [입력 시작] — 이미 내용이 있는 학생은 체크해야 바꿔요
  6. 나이스에서 확인 후 [저장] → 다음 강의실을 조회하면 이어서
엑셀은 화면 안에서만 읽고 저장·전송하지 않아요. 나이스 양식(엑셀내려받기)으로 쓴 파일도 그대로 넣을 수 있어요.

자동 상신 (선택)

  1. 기본은 꺼짐 — 결재선까지 넣고 멈춰요.
  2. 켜려면 수당·책임 안내를 읽고 동의해야 해요.
  3. 루틴에서는 이 설정과 상관없이 항상 [상신] 앞에서 멈춰요.

단축키

  1. Alt+Shift+N 팝업 열기
  2. Alt+Shift+L 업무포털 로그인
  3. Alt+Shift+1~2 복무 신청 1·2번 (오늘 날짜)
  4. [단축키 바꾸기]에서 3~6번 · K-에듀파인도 지정할 수 있어요.

화면 테마

  1. 설정 › 화면에서 6가지 색 중 하나를 골라요: 스카이(기본) · 베이지 · 라임 · 민트 · 라벤더 · 피치.
  2. 고르는 즉시 팝업 · 설정 · 과세특 화면에 함께 바뀌어요. 열려 있는 창도 바로 따라 바뀌어요.
  3. 고른 테마는 이 브라우저에만 저장돼요.

정보 · 업데이트

  1. 새 버전은 브라우저를 켤 때와 몇 시간마다 확인해요. [지금 확인]으로 바로 볼 수도 있어요.
  2. 새 버전이 있으면 툴바 아이콘에 NEW가 붙고, 팝업의 [받기]를 누르면 받는 곳이 열려요.
  3. 새 설치 파일을 실행하면 쌤패스가 1분 안에 스스로 새 버전으로 바뀌어요.
쌤패스는 브라우저 안에서만 돌아가요. 따로 실행되는 프로그램이 없어서 백신 확인 창도 뜨지 않아요.

04 · 안전

선생님 정보는
선생님 PC에만

PIN 암호화 금고인증서 비밀번호는 PIN으로 암호화(AES-256)해 이 브라우저 안에만 둬요. 5번 틀리면 잠겨요.
외부 전송 없음비밀번호 · 학생 정보를 어디에도 보내지 않아요. 인터넷은 새 버전 확인 때만.
마지막은 사람이[상신] · [저장]은 선생님이 확인하고 눌러요. OTP도 직접 입력해요.
브라우저 안에서만따로 실행되는 프로그램이 없어요. 백신 확인 창 없이 가볍게.
05 · 질문

자주 묻는 질문

교육청에서 만든 공식 프로그램인가요?
아니요. 현직 교사가 개인적으로 만든 비공식 도구예요. 나이스·업무포털 화면이 바뀌면 일부 기능이 잠시 동작하지 않을 수 있어요. 학교·교육청의 정보보안 지침을 먼저 확인하고 사용해 주세요.
인증서 비밀번호를 저장해도 안전한가요?
PIN으로 암호화(AES-256)해 이 브라우저 안에만 보관하고, 어디로도 보내지 않아요. PIN을 5번 틀리면 잠시 잠겨요. 여러 사람이 같이 쓰는 PC에서는 쓰지 마세요. 또 잠금이 풀린 채 자리를 비우면 다른 사람이 쓸 수 있으니, 자리를 비울 땐 Win+L로 PC를 잠가 주세요.
[상신]까지 자동으로 할 수는 없나요?
기본은 결재선 지정까지 하고 멈춰요. 시간외근무는 수당과 직결되기 때문이에요. 설정 › 자동 상신에서 안내에 동의하면 켤 수 있지만 책임은 사용자에게 있어요. 루틴은 이 설정과 상관없이 항상 [상신] 앞에서 멈춰요.
안랩 V3나 Windows에서 경고가 떠요.
설치 파일이 회사 인증서로 서명하지 않은 개인 제작 프로그램이라 처음 보는 파일로 보고 묻는 거예요. 이 페이지에서 받은 파일이라면 괜찮아요.
· Windows의 PC 보호: [추가 정보] → [실행]
· 안랩 V3 "프로그램 실행 알림": [한 번만 실행]을 고르고 [확인]
설치가 끝나면 쌤패스는 브라우저 안에서만 돌아가서 더는 묻지 않아요(0.15.0부터).
사진으로 보는 설치 가이드 →
확장 등록을 꼭 직접 해야 하나요?
네, 처음 한 번만요. 브라우저는 보안을 위해 웹스토어 밖 확장을 프로그램이 대신 등록하지 못하게 막아 두었어요. 등록한 뒤의 업데이트는 쌤패스가 자동으로 해요.
다른 시도교육청에서도 되나요?
업무포털 주소가 ○○.eduptl.kr 형태라면 설정 › 로그인에서 주소만 바꾸면 돼요. 처음 만든 곳은 경기도라, 다른 지역은 화면이 조금 달라 일부 기능이 다를 수 있어요.
엑셀 양식이 사람마다 다른데 괜찮나요?
머리글과 값 모양으로 학년·반·번호·이름·내용 열을 스스로 찾아요. 병합된 칸, 시트별 반, "2/17" 같은 반/번호, 학번, 이동반도 알아봐요. 틀리게 알아보면 확인 화면에서 고치면 되고, 고친 배치는 기억해요.
업데이트는 어떻게 하나요?
새 버전이 나오면 툴바의 쌤패스 아이콘에 NEW가 붙고 팝업에 [받기]가 떠요. 이 페이지에서 새 설치 파일을 받아 실행하면 쌤패스가 1분 안에 스스로 새 버전으로 바뀌어요. 확장을 다시 등록할 필요는 없어요.
맥(Mac)이나 휴대폰에서도 쓸 수 있나요?
지금은 Windows 10·11의 엣지·크롬만 지원해요. 인증서 프로그램과 비밀번호 금고가 Windows 기능을 쓰기 때문이에요.
지우고 싶어요.
Win+R(실행)에 %LOCALAPPDATA%\NeisHelper\NeisHelperSetup.exe /uninstall을 넣고 Enter → 브라우저 확장 관리 화면에서 쌤패스 [제거]. 확장을 제거하면 저장한 비밀번호도 함께 지워져요.
정말 무료인가요?
네, 완전 무료예요. 광고도, 회원 가입도 없어요.
