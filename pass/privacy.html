개인정보 처리방침

시행일 2026년 10월 16일 · 대상: 쌤패스 브라우저 확장(엣지 확장 스토어판·크롬 웹 스토어판과 직접 배포판)

쌤패스는 선생님의 정보를 어디로도 보내지 않아요. 모든 정보는 선생님 PC의 브라우저 안에만 있고, 만든 사람도 볼 수 없어요.

1. 무엇을, 어디에 보관하나요

인증서 비밀번호선생님이 정한 PIN으로 암호화(PBKDF2-SHA256 60만 회 → AES-256-GCM)해서 브라우저 확장 저장소(chrome.storage.local)에만 둬요. PIN 자체는 저장하지 않아요.
잠금을 푼 동안의 비밀번호브라우저 메모리(chrome.storage.session)에만 있고, 잠기거나 브라우저를 닫으면 지워져요. 확장 화면만 읽을 수 있어요.
설정잠금 시간, 업무포털 주소, 복무 신청 루틴 버튼(종류·시각·사유·출장지·결재선 이름), 단축키, 화면 테마, 인증서가 여러 개일 때 고른 인증서 이름. 모두 같은 확장 저장소에만 둬요.
엑셀 열 배치 기억과세특 엑셀의 머리글 줄을 줄여 만든 값(해시)과 열 역할만 기억해요. 학생 이름이나 내용은 저장하지 않아요.
과세특 엑셀 내용(학생 정보)선생님이 고른 파일을 브라우저 안에서만 읽고, 그 화면이 열려 있는 동안 메모리에만 있어요. 저장하지 않고 어디로도 보내지 않아요. 나이스 화면의 칸에 옮겨 적기만 해요.

2. 보내지 않는 것

  • 쌤패스는 서버가 없어요. 분석 도구, 광고, 사용 통계를 쓰지 않아요.
  • 비밀번호, 설정, 학생 정보를 만든 사람이나 다른 누구에게도 보내지 않고, 팔거나 넘기지 않아요.
  • 스토어판(엣지 확장 스토어·크롬 웹 스토어)은 바깥으로 나가는 요청이 하나도 없어요(확장 화면의 보안 정책 connect-src 'self'). 업데이트는 각 스토어가 맡아요.
  • 직접 배포판은 새 버전이 있는지 보려고 소개 페이지의 버전 파일(hirame-ki.github.io/pass/update/latest.json) 하나만 읽어요. 이때 쌤패스는 아무 정보도 보내지 않아요.

3. 어떤 사이트에서 동작하나요

업무포털(*.eduptl.kr)과 나이스(*.neis.go.kr)에서만, 선생님이 버튼·단축키를 누르거나 직접 켠 기능(업무포털을 열면 자동 로그인)일 때만 동작해요. 하는 일은 인증서 로그인 창에 비밀번호 넣기, 메뉴 열기, 복무 신청 칸 채우기, 과세특 칸에 엑셀 내용 옮겨 적기예요.

  • [상신]은 기본적으로 선생님이 직접 눌러요. 자동 상신은 동의한 뒤 직접 켠 경우에만 동작해요. [저장]은 쌤패스가 누르지 않아요.
  • OTP(2차 인증)는 입력하지 않아요.
  • 그 밖의 사이트에서는 아무것도 읽거나 바꾸지 않아요.

4. 지우는 방법

  • 설정 › 비밀번호·잠금에서 저장한 비밀번호를 지울 수 있어요.
  • 브라우저 확장 관리 화면에서 쌤패스를 [제거]하면 확장 저장소의 모든 정보(비밀번호, 설정)가 함께 지워져요.

5. 문의 · 바뀔 때

쌤패스는 개인(hirame.ki)이 만든 무료 도구이고, 나이스·업무포털을 운영하는 교육부·교육청과는 관계가 없어요. 문의는 인스타그램 @hirame.ki로 보내 주세요. 이 방침이 바뀌면 이 페이지에 시행일과 함께 알려요.

Summary in English

SsamPass is a browser extension that helps Korean teachers with repetitive tasks on the school work portal (*.eduptl.kr) and NEIS (*.neis.go.kr). It has no server and sends no data anywhere: no analytics, no ads, no tracking. The certificate password is encrypted with the user's PIN (PBKDF2-SHA256, 600,000 iterations, AES-256-GCM) and kept only in chrome.storage.local; the PIN is never stored. Settings stay in the same local storage. Student data from Excel files is read in the browser only, kept in memory while the page is open, and never stored or transmitted. The Edge Add-ons and Chrome Web Store versions make no network requests (connect-src 'self'). Removing the extension deletes all of its data. Contact: @hirame.ki on Instagram.
