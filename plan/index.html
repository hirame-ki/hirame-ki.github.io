📖 GAS 설정 방법

⚠️ 개인 Gmail 계정 사용 권장 (학교 계정은 관리자 설정에 따라 제한될 수 있습니다)

1. Google Sheets 새 파일 생성
2. 상단 메뉴 → 확장프로그램 → Apps Script
3. code.gs 내용 전체 붙여넣기
4. 저장 후 배포 → 새 배포 클릭
5. 유형: 웹 앱 선택
6. 실행 계정: 나(본인)
7. 액세스 권한: 모든 사용자(익명 포함)
8. 배포 → 생성된 URL 복사 → 여기에 붙여넣기
