📖 GAS 설정 방법

1. 배포 → 새 배포 클릭
2. 유형: 웹 앱 선택
3. 실행 계정: 나(본인)
4. 액세스 권한: 모든 사용자(익명 포함)
5. 배포 → 생성된 URL 복사 → 여기에 붙여넣기
