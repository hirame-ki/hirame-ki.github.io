🔑 Groq API 키 설정 (PDF 미션 자동 생성 기능 · 최초 1회)

PDF 수업 자료를 AI가 미션으로 자동 변환해주는 기능입니다. 무료 Groq 계정을 만들고 API 키를 아래에 한 번만 입력하면 이후 계속 사용할 수 있습니다.

  1. groq.com 접속 → 우측 상단 Sign Up
  2. Google 계정 또는 이메일로 가입 · 로그인
  3. 왼쪽 메뉴에서 API Keys 클릭
  4. + Create API Key 버튼 → 이름 입력(아무 이름) → Submit
  5. 생성된 키(gsk_로 시작)를 복사
  6. 아래 입력란에 붙여넣기 후 저장 클릭
✅ Groq API 키가 저장되었습니다. 교사 대시보드의 "📄 PDF로 미션 생성" 버튼을 바로 사용할 수 있습니다.
기본 사용법
1. 전체 흐름
  1. 교사가 교사용 대시보드에서 수업 코드를 만들고, 맵·구역별로 미션을 설정합니다.
  2. 대시보드의 "🔗 학생 초대 링크" 버튼으로 맵별 링크와 QR 코드를 학생에게 공유합니다.
  3. 학생은 링크 접속 또는 QR 스캔 → 캐릭터를 만들고 닉네임 입력 후 맵에 입장합니다.
  4. 캐릭터를 이동하다 구역(zone)에 진입하거나 특정 가구 위치를 밟으면 미션이 자동으로 열립니다.
  5. 미션을 완료할수록 우상단 진행률 배지(🎯 미션 진행률 N / 전체)가 올라갑니다.
  6. 필수 미션을 모두 마치면 출입구를 통해 다음 맵으로 자동 이동합니다.
2. 교사용 대시보드 사용법
  1. 접속 코드 입력 → "수업 선택" 화면. 이전 수업 목록(최대 10개)에서 "이 수업 계속하기"로 바로 이어서 관리. "+ 새 수업 만들기"로 새 수업 생성.
  2. 각 수업 항목에서 ✏️ 버튼으로 수업 이름(예: "3학년 2반") 추가 가능. ✕ 버튼은 목록에서만 제거(실제 미션 데이터는 유지).
  3. 상단 맵 탭(일반교실/도서관/운동장/체육관/현대도시/자연숲)으로 맵 전환.
  4. 각 맵의 구역(zone_A~H)별로 미션 추가·수정·삭제. 미션 타입은 8가지 중 선택 (아래 7번 항목 참고).
  5. 미션 등록 전에는 데모 미션이 학생에게 표시됩니다.
  6. 상단 도구 버튼: 🪑 맵 에디터 · 📄 PDF로 미션 생성 · 💬 채팅 설정 · 🚪 맵 이동 순서 · 🗺️ 실시간 맵 보기 · 🧑‍🏫 맵 참가하기 · 📊 진행현황 다운로드
3. 학생 초대 링크 & QR 코드 공유
  1. 대시보드 상단 "🔗 학생 초대 링크" 버튼 → 맵별 접속 링크 목록 표시.
  2. 각 링크 옆 "QR" 버튼 → 해당 링크의 QR 코드 생성.
  3. QR 창에서 "PNG 다운로드"로 이미지 저장. 화면에 띄우거나 인쇄해 학생이 스캔하면 바로 입장.
  4. "복사" 버튼으로 링크 텍스트를 채팅/학습 플랫폼에 붙여넣을 수 있습니다.
4. 학생 입장 방법
  • QR 스캔 또는 공유된 링크로 접속합니다.
  • 처음 접속한 학생은 자동으로 "캐릭터 만들기" 화면으로 이동. 교복/교사/판타지 탭에서 캐릭터를 꾸민 뒤 "이 캐릭터로 입장하기"를 누르면 맵으로 입장.
  • 한 번 만든 캐릭터는 같은 기기·브라우저에서는 다시 설정 없이 바로 입장.
  • PC/크롬북은 방향키, 모바일/태블릿은 화면 버튼 또는 스와이프로 이동.
  • 같은 수업 코드로 입장한 다른 학생 캐릭터가 실시간으로 함께 표시됩니다.
💡 캐릭터를 다시 꾸미고 싶으면 캐릭터 만들기 / 체험하기 페이지에서 새로 설정하면 그 기기의 캐릭터가 바뀝니다.
5. 미션 진행 방식

각 맵은 8개 구역(zone_A~H)으로 나뉩니다. 캐릭터가 구역에 진입하거나, 교사가 지정한 특정 타일을 밟으면 미션이 자동으로 열립니다.

  • 미완료 미션만 표시됩니다. 이미 완료한 구역은 다시 진입해도 열리지 않습니다.
  • 완료 시 우상단 진행률(🎯 N / 전체) 업데이트.
  • 필수 미션 전체 완료 시 색종이 효과 + 완료 팝업 표시.
💡 진행 상황은 학생 기기의 localStorage에 저장되므로 같은 기기·브라우저로 다시 접속하면 이어서 진행됩니다.
교사 도구
6. 🪑 맵 에디터 — 가구 배치 & 미션 발동 위치

대시보드 상단 "🪑 맵 에디터" 버튼을 누르면 맵별로 가구를 자유롭게 배치할 수 있는 에디터가 열립니다.

  • 상단 탭으로 맵 전환 (일반교실/도서관/운동장/체육관/현대도시/자연숲).
  • 맵마다 어울리는 가구 팔레트가 자동으로 바뀝니다:
맵배치 가능 가구
교실 / 도서관책상, 화분, 책장, 칸막이
운동장화분/나무, 벤치, 바위, 꽃밭
체육관책상, 칸막이, 운동매트, 운동기구
현대도시칸막이, 벤치, 가로수, 쓰레기통
자연숲화분, 나무, 바위, 꽃밭, 버섯
  • 배치: 팔레트에서 가구 선택 후 캔버스에서 좌클릭·드래그로 배치 (보행 가능 타일에만 허용).
  • 삭제: 지우개 선택 또는 우클릭으로 제거.
  • 배치된 가구는 학생이 지나갈 수 없는 장애물로 자동 처리됩니다.
  • 💾 저장 버튼 클릭 시 현재 수업에 저장. 학생 맵에 픽셀 아트 스타일로 표시됩니다.
📍 미션 발동 위치 지정: 미션 편집 모달 아래쪽 "미션 발동 위치" 섹션에서 "타일 직접 지정"을 선택하면 맵 미리보기가 열립니다. 학생이 밟으면 미션이 열릴 타일을 클릭으로 선택하세요. 배치한 가구 위치를 활용하면 "책상 앞에 서면 미션 열림" 같은 구성이 가능합니다.
7. 📋 미션 타입 8가지
타입설명완료 조건
유튜브 영상 YouTube URL 입력 → 영상 임베드 재생 "시청 완료" 버튼 클릭
객관식 퀴즈 질문 + 4지선다 + 정답 설정 정답 선택 시에만 완료
O/X 퀴즈 질문 + O 또는 X 중 정답 선택 (이미지 첨부 가능) 정답 선택 시에만 완료
이미지 퀴즈 이미지 URL + 질문 + 4지선다. 시각 자료 활용 퀴즈 정답 선택 시에만 완료
주관식 단답 질문 + 정답(텍스트). 대소문자 무시 비교 정답 텍스트 입력 시 완료
토론/의견 자유 서술 미션. 정답 없이 의견 작성 100자 이상 입력 시 완료
구글 설문 Google Forms URL → iframe 임베드 표시 "제출 완료" 버튼 클릭
외부 링크 URL → 새 탭으로 열기 (웹사이트·자료 방문) "완료" 버튼 클릭
💡 필수 여부: 미션 편집 시 "필수" 체크를 해제하면 학생이 "나중에" 버튼으로 건너뛸 수 있습니다. 비필수 미션은 맵 이동 조건(출입구 잠금)에 포함되지 않습니다.
8. 📄 PDF로 미션 자동 생성 (AI)

수업 자료 PDF를 업로드하면 AI(Groq · Qwen3-32B)가 자동으로 미션을 생성해줍니다.

  1. 대시보드 상단 "📄 PDF로 미션 생성" 버튼 클릭.
  2. PDF 파일 선택, 추출 페이지 범위와 생성할 미션 수(5~10개) 설정.
  3. 미션 타입(객관식 퀴즈 / 주관식 단답 / 토론 등)을 선택하고 "미션 생성" 클릭.
  4. AI가 수초~수십초 내에 미션 초안을 생성합니다. 내용을 검토한 뒤 "저장"을 누르면 현재 맵·구역에 등록됩니다.
⚠️ Groq API 키가 필요합니다. 이 페이지 상단 "🔑 Groq API 키 설정" 섹션에서 최초 1회만 입력하면 이후 자동으로 사용됩니다. Groq 무료 플랜은 분당 30회 요청, 월 1,000회 호출이 가능합니다.
9. 💬 채팅 설정 (전체 / 근접 / 금지)

대시보드 상단 채팅 모드 버튼을 클릭할 때마다 모드가 순환 전환되며, 변경 즉시 모든 학생에게 실시간 반영됩니다.

모드설명
💬 전체 공개같은 맵에 있는 모든 학생에게 채팅 메시지가 보입니다.
📍 근접만나와 5타일 이내에 있는 학생에게만 메시지가 보입니다. 소그룹 활동 시 유용합니다.
🚫 채팅 금지학생 채팅 입력창이 비활성화되고, 화면 하단에 금지 안내 배너가 표시됩니다.
💡 교사가 직접 맵에 참가한 경우에도 채팅 말풍선이 다른 학생에게 표시됩니다. "🗺️ 실시간 맵 보기" 창에서도 학생들의 말풍선을 확인할 수 있습니다.
10. 🚪 맵 이동 순서 & 출입구 자동 이동

대시보드 상단 "🚪 맵 이동 순서" 버튼 → 6개 맵의 진행 순서를 ▲▼로 정렬해 저장할 수 있습니다. 각 맵 옆에 "✅ 미션 있음 / ⚪ 미션 없음"이 표시됩니다.

  1. 학생이 현재 맵의 필수 미션을 모두 완료하고 출입구(문/게이트) 칸으로 이동하면 → 설정 순서상 다음 미션이 있는 맵으로 자동 이동합니다.
  2. 미션이 없는 맵(데모 미션만)은 자동 이동 대상에서 제외됩니다.
  3. 필수 미션이 남아있는 상태에서 출입구를 통과하려 하면 "🔒 미션을 모두 완료해야 출입구를 통과할 수 있어요!" 안내가 표시됩니다.
🎉 맵의 필수 미션을 모두 완료하면 색종이(컨페티) 효과와 함께 완료 팝업이 표시됩니다. 마지막 맵이면 "수고했어요" 메시지가 나옵니다.
모니터링
11. 🗺️ 실시간 맵 보기 (학생 이동 모니터링)

대시보드 상단 "🗺️ 실시간 맵 보기" 버튼 → 선택한 맵 전체를 한 화면에서 볼 수 있는 관전 창이 열립니다.

  • 상단 탭으로 보고 싶은 맵 전환.
  • 입장한 학생들의 캐릭터가 실시간으로 이동하는 모습이 표시됩니다. (직접 조작 불가, 관전 전용)
  • 우상단에 현재 맵 접속 인원("접속 인원: N명") 표시.
  • 학생들의 말풍선 채팅도 이 창에서 실시간으로 확인할 수 있습니다.
12. 🧑‍🏫 교사가 맵에 직접 참가하기

대시보드 상단 "🧑‍🏫 맵 참가하기" 버튼 → 맵 선택 → 새 탭에서 해당 맵 열림.

  • 처음 입장 시 캐릭터 선택 화면에서 "교사" 탭으로 교사용 캐릭터 선택.
  • 학생들과 동일하게 이동·채팅하며 함께 활동 가능.
  • "🗺️ 실시간 맵 보기"(관전)와 달리 직접 조작 가능한 참가자 모드입니다.
13. 📊 학생 미션 진행현황 다운로드

대시보드 상단 "📊 진행현황 다운로드" 버튼 → 학생별·미션별 완료 여부를 정리한 엑셀 파일(.xlsx)이 다운로드됩니다.

  • 맵별 색구분 헤더, 미션별 완료(✅) 표시, 학생별 완료 수·진행률 컬럼 포함.
  • MS Excel / 한컴 한셀 모두 지원.
  • 완료한 학생이 없거나 미션이 없으면 다운로드 대신 안내 메시지 표시.
