쌤버스 사용설명서

Groq API 키 설정 (PDF 미션 자동 생성 · 최초 1회)

PDF 수업 자료를 AI가 미션으로 자동 변환해주는 기능입니다. 무료 Groq 계정을 만들고 API 키를 아래에 한 번만 입력하면 이후 계속 사용할 수 있습니다.

  1. groq.com 접속 → 우측 상단 Sign Up
  2. Google 계정 또는 이메일로 가입 · 로그인
  3. 왼쪽 메뉴에서 API Keys 클릭
  4. + Create API Key 버튼 → 이름 입력(아무 이름) → Submit
  5. 생성된 키(gsk_로 시작)를 복사
  6. 아래 입력란에 붙여넣기 후 저장 클릭
Groq API 키가 저장되었습니다. 교사 대시보드의 "AI 자동문제 생성" 버튼을 바로 사용할 수 있습니다.
기본 사용법
1. 전체 흐름
  1. 교사가 교사용 대시보드에서 수업 코드를 만들고, 맵·구역별로 미션을 설정합니다.
  2. 대시보드의 "학생 초대 링크" 버튼으로 맵별 링크와 QR 코드를 학생에게 공유합니다.
  3. 학생은 링크 접속 또는 QR 스캔 → 캐릭터를 만들고 닉네임 입력 후 맵에 입장합니다.
  4. 캐릭터를 이동하다 구역(zone)에 진입하거나 특정 가구 위치를 밟으면 미션이 자동으로 열립니다.
  5. 미션을 완료할수록 우상단 진행률 배지(미션 진행률 N / 전체)가 올라갑니다.
  6. 필수 미션을 모두 마치면 출입구를 통해 다음 맵으로 자동 이동합니다.
2. 교사용 대시보드 사용법
  1. 접속 코드 입력 → "수업 선택" 화면. 이전 수업 목록(최대 10개)에서 "이 수업 계속하기"로 바로 이어서 관리. "+ 새 수업 만들기"로 새 수업 생성.
  2. 각 수업 항목에서 ✏️ 버튼으로 수업 이름(예: "3학년 2반") 추가 가능.
  3. 상단 맵 탭(일반교실·도서관·운동장·체육관·현대도시·자연숲·음악실·미술실·컴퓨터실·과학실·급식실·보건실·미로·경주 트랙)으로 맵 전환.
  4. 각 맵의 구역(zone_A~H)별로 미션 추가·수정·삭제. 미션 타입은 8가지 중 선택.
  5. 미션 등록 전에는 데모 미션이 학생에게 표시됩니다.
  6. 상단 도구 버튼: 맵 에디터 · AI 자동문제 생성 · 학생 초대 링크 · 채팅 모드 · 완료 순위 · 진행현황 다운로드 · 맵 이동 순서 · 실시간 맵 보기 · 맵 참가하기
3. 학생 초대 링크 & QR 코드 공유
  1. 대시보드 상단 "학생 초대 링크" 버튼 → 팝업이 열리면서 시작 맵의 QR 코드가 즉시 표시됩니다.
  2. "전체화면으로 보기" 버튼으로 빔프로젝터·모니터에 QR을 크게 띄울 수 있습니다. ESC 키로 닫기.
  3. "PNG 다운로드"로 QR 이미지 저장 → 원격 수업 시 학습 플랫폼에 첨부 가능.
  4. 상단 헤더의 수업코드 옆 "복사" 버튼으로 수업코드를 클립보드에 복사할 수 있습니다.
학생은 QR 스캔 또는 공유된 링크로 바로 입장합니다. 코드 입력 방식은 지원하지 않습니다.
4. 학생 입장 방법
  • QR 스캔 또는 공유된 링크로 접속합니다.
  • 처음 접속한 학생은 자동으로 "캐릭터 만들기" 화면으로 이동. 교복/교사/판타지 탭에서 캐릭터를 꾸민 뒤 "이 캐릭터로 입장하기"를 누르면 맵으로 입장.
  • 한 번 만든 캐릭터는 같은 기기·브라우저에서는 다시 설정 없이 바로 입장.
  • PC/크롬북은 방향키, 모바일/태블릿은 화면 버튼 또는 스와이프로 이동.
  • 같은 수업 코드로 입장한 다른 학생 캐릭터가 실시간으로 함께 표시됩니다.
캐릭터를 다시 꾸미고 싶으면 캐릭터 만들기 / 체험하기 페이지에서 새로 설정하면 그 기기의 캐릭터가 바뀝니다.
5. 미션 진행 방식

각 맵은 8개 구역(zone_A~H)으로 나뉩니다. 캐릭터가 구역에 진입하거나, 교사가 지정한 특정 타일을 밟으면 미션이 자동으로 열립니다.

  • 미완료 미션만 표시됩니다. 이미 완료한 구역은 다시 진입해도 열리지 않습니다.
  • 완료 시 우상단 진행률(N / 전체) 업데이트.
  • 맵의 필수 미션 전체 완료 → 색종이 효과 + 완료 팝업. 마지막 맵이면 소감 입력란도 함께 표시됩니다.
  • 필수 미션을 모두 마쳐야 출입구를 통해 다음 맵으로 이동할 수 있습니다.
진행 상황은 학생 기기의 localStorage에 저장되므로 같은 기기·브라우저로 다시 접속하면 이어서 진행됩니다.
교사 도구
6. 맵 에디터 — 가구 배치 & 미션 발동 위치

대시보드 상단 "맵 에디터" 버튼을 누르면 맵별로 가구를 자유롭게 배치할 수 있는 에디터가 열립니다.

  • 상단 탭으로 맵 전환 (일반교실·도서관·운동장·체육관·현대도시·자연숲·음악실·미술실·컴퓨터실·과학실·급식실·보건실·미로·경주 트랙).
  • 배치: 팔레트에서 가구 선택 후 캔버스에서 좌클릭·드래그로 배치 (보행 가능 타일에만 허용).
  • 삭제: 지우개 선택 또는 우클릭으로 제거.
  • 배치된 가구는 학생이 지나갈 수 없는 장애물로 자동 처리됩니다.
  • 저장 버튼 클릭 시 현재 수업에 저장됩니다.
  • 이전 수업 불러오기: 이전에 만든 다른 수업의 가구 배치를 그대로 가져올 수 있습니다.
미션 발동 위치 지정: 미션 편집 모달 아래쪽 "미션 발동 위치" 섹션에서 "타일 직접 지정"을 선택하면 맵 미리보기가 열립니다. 학생이 밟으면 미션이 열릴 타일을 클릭으로 선택하세요.
구역(zone) vs 타일 직접 지정 — 발동 조건 차이
  • 구역(zone_A~H): 해당 구역 범위 안으로 들어오면 미션이 열립니다.
  • 타일 직접 지정: 지정한 타일 칸을 정확히 밟아야만 미션이 열립니다. 구역은 완전히 무시됩니다.

8. PDF로 미션 자동 생성 (AI)

수업 자료 PDF를 업로드하면 AI(Groq · Qwen3-32B)가 자동으로 미션을 생성해줍니다.

  1. 대시보드 상단 "AI 자동문제 생성" 버튼 클릭.
  2. PDF 파일 선택, 추출 페이지 범위와 생성할 미션 수(5~10개) 설정.
  3. 미션 타입을 선택하고 "미션 생성" 클릭.
  4. AI가 수초~수십초 내에 미션 초안을 카드 형태로 표시합니다.
  5. 남은 카드를 검토한 뒤 구역을 선택하고 "저장"을 누르면 현재 맵·구역에 등록됩니다.
Groq API 키가 필요합니다. 이 페이지 상단 "Groq API 키 설정" 섹션에서 최초 1회만 입력하면 이후 자동으로 사용됩니다. Groq 무료 플랜은 분당 30회 요청, 월 1,000회 호출이 가능합니다.
9. 채팅 설정 (전체 / 근접 / 금지)

대시보드 상단 채팅 모드 버튼을 클릭할 때마다 모드가 순환 전환되며, 변경 즉시 모든 학생에게 실시간 반영됩니다.

모드설명
전체 공개같은 맵에 있는 모든 학생에게 채팅 메시지가 보입니다.
근접만나와 5타일 이내에 있는 학생에게만 메시지가 보입니다. 소그룹 활동 시 유용합니다.
채팅 금지학생 채팅 입력창이 비활성화되고, 화면 하단에 금지 안내 배너가 표시됩니다.
10. 맵 이동 순서 & 출입구 자동 이동

대시보드 상단 "맵 이동 순서" 버튼 → 맵 진행 순서를 ▲▼로 정렬해 저장할 수 있습니다.

  1. 학생이 현재 맵의 필수 미션을 모두 완료하고 출입구 칸으로 이동하면 → 다음 미션이 있는 맵으로 자동 이동합니다.
  2. 미션이 없는 맵(데모 미션만)은 자동 이동 대상에서 제외됩니다.
  3. 필수 미션이 남아있는 상태에서 출입구를 통과하려 하면 잠금 안내가 표시됩니다.
맵의 필수 미션을 모두 완료하면 색종이(컨페티) 효과와 함께 완료 팝업이 표시됩니다. 마지막 맵 완료 시에는 수업 소감 입력란이 나타납니다.
모니터링
11. 실시간 맵 보기 (학생 이동 모니터링)

대시보드 상단 "실시간 맵 보기" 버튼 → 선택한 맵 전체를 한 화면에서 볼 수 있는 관전 창이 열립니다.

  • 입장한 학생들의 캐릭터가 실시간으로 이동하는 모습이 표시됩니다. (직접 조작 불가)
  • 우상단에 현재 맵 접속 인원 표시.
  • 학생들의 말풍선 채팅도 이 창에서 실시간으로 확인할 수 있습니다.
12. 교사가 맵에 직접 참가하기

대시보드 상단 "맵 참가하기" 버튼 → 맵 선택 → 새 탭에서 해당 맵 열림.

  • 처음 입장 시 캐릭터 선택 화면에서 "교사" 탭으로 교사용 캐릭터 선택.
  • 학생들과 동일하게 이동·채팅하며 함께 활동 가능.
13. 학생 미션 진행현황 다운로드

대시보드 상단 "진행현황 다운로드" 버튼 → 학생별·미션별 완료 여부를 정리한 엑셀 파일(.xlsx)이 다운로드됩니다.

14. 캐릭터 커스터마이징
종류옵션

교사피부색 8종, 머리 스타일 10종, 머리색 12종, 의상 6종, 의상 색상 12종, 액세서리 12종 중복 선택

15. 캐릭터 이동 조작법
  • PC / 크롬북: 키보드 방향키(↑↓←→)
  • 모바일 / 태블릿: 화면 하단 방향 버튼 또는 화면 스와이프(상/하/좌/우)
  • 캐릭터는 한 타일씩 부드럽게 슬라이드로 이동합니다. (맵 카메라도 함께 따라옴)
  • 다른 학생이 점유한 타일로는 이동할 수 없습니다. (충돌 방지)
  • 가구가 배치된 타일도 이동 불가 장애물로 처리됩니다.
같은 맵에 있는 다른 학생 캐릭터는 실시간으로 부드럽게 이동하는 모습이 표시됩니다. 채팅 말풍선도 캐릭터 위에 4초간 표시됩니다.
특수 맵
16. 미로 맵 — 탐험형 퀴즈 미션

Z자형 통로와 막다른 골목이 있는 미로를 탐험하며 8개 구역의 미션을 수행하는 맵입니다.

  • 통로 폭이 좁고 교차로가 많아 실제 미로 탐험 느낌을 줍니다.
  • 미션 구역에 진입하면 일반 맵과 동일하게 미션 팝업이 열립니다.
  • 타일 겹침이 허용되어 같은 타일에 여러 학생이 동시 위치할 수 있습니다.
  • 모든 구역을 방문하려면 미로 전체를 탐색해야 하므로, 팀·모둠 활동에 적합합니다.
17. 경주 트랙 맵 — 게이트 퀴즈 & 실시간 순위

S자형 코스를 따라 이동하며 8개 게이트를 통과하는 경쟁형 맵입니다. 일반 구역 미션과 달리 게이트를 만나면 즉시 퀴즈가 발동되고, 정답을 맞혀야만 통과할 수 있습니다.

  • 게이트 퀴즈: 각 게이트(1~8번)는 통로를 완전히 막습니다. 퀴즈에 정답 시 영구 개방되어 재통과 가능.
  • 실시간 순위판: 화면 우측에 학생별 통과 게이트 수 기준의 순위가 실시간으로 표시됩니다. 완주 시 🏁 완주! 배지 부여.
  • 장애물: 직선 구간마다 지그재그 배리어가 배치되어 좌우로 회피하며 이동해야 합니다.
  • 장애물 설정: 교사 대시보드 → 경주 트랙 탭 상단 "🚧 장애물 설정" 패널에서 활성화·비활성화 후 저장.
  • 퀴즈 미설정 시 스포츠 관련 기본 데모 문제가 적용됩니다. 대시보드에서 게이트별 퀴즈를 직접 설정하거나 AI 자동 생성이 가능합니다.
경주 트랙은 구역 진입 방식이 아닌 게이트 충돌 방식이므로, 대시보드에서 구역(zone_A~H)에 각 게이트별 퀴즈를 1개씩 등록하면 됩니다.
