Groq AI란?

Groq는 구글 TPU 개발자 출신들이 창업한 AI 추론 칩 전문 스타트업으로, 세계 최고 수준의 속도를 자랑하는 LPU(Language Processing Unit)를 개발했습니다.

엔비디아(NVIDIA)가 약 200억 달러(약 29조 원)에 우회 인수 (2025.12)
반독점 규제를 피하기 위해 그로크 법인은 독립을 유지하되, 핵심 기술·IP·인재를 엔비디아가 흡수하는 방식입니다. 엔비디아 역대 최대 규모 빅딜입니다.
무료로 사용 가능!
단, 분당 처리 가능한 토큰(token) 수에 제한이 있어 대용량 PDF나 긴 문서는 한 번에 처리하기 어렵습니다.
PDF는 4페이지 이내로 나누어 업로드하는 것을 권장합니다.
🔑 API 키 발급 방법
  1. console.groq.com/keys 접속 후 회원가입 / 로그인
  2. Create API Key 버튼 클릭 → 이름 입력 후 생성
  3. gsk_... 로 시작하는 키를 복사
  4. AI 문제 생성 팝업의 Groq API 키 입력란에 붙여넣기
