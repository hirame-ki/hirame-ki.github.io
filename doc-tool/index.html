1. 항목 번호 체계 (규칙 제2조제1항, 편람 51~52쪽)
1단계 1., 2. → 2단계 가., 나. → 3단계 1), 2) → 4단계 가), 나)
5단계 (1) → 6단계 (가) → 7단계 ① → 8단계 ㉮
• 항목 하나뿐이면 기호 부여 안 함 / 기호와 내용 사이 1타
• 둘째 항목부터 오른쪽으로 2타씩 이동
2. 날짜·시간 표기 (영 제7조제5항, 편람 49쪽)
• 2026. 5. 30. (○) / 2026.5.30. (×) — 숫자·마침표 사이 1타

• 요일 병기: 2026. 5. 30.(금). / 시간: 15:20, 07:09
★ 3. 연도 자동 수정

5. 어문 규범 교정 (편람 41~44쪽)
• 두음법칙: 년간→연간, 시설 년도→시설 연도
• 사이시옷: 하교길→하굣길, 최소값→최솟값
• 외래어: 컨퍼런스→콘퍼런스, 워크샵→워크숍
• 괄호 뒤 조사: 인공지능(AI)를→인공지능(AI)을 (괄호 앞 글자 기준)
6. 띄어쓰기·문장 부호 (편람 43~44쪽)
• 10만톤→10만 톤 / 홍길동씨→홍길동 씨
• 쌍점: 원장 : 김갑동→원장: 김갑동
• 물결표: 4. 23. ~ 6. 15.→4. 23.~6. 15.
7. 어휘 순화 · 고압적 표현
• 금번→이번, 상기→위, 차년도→다음 해
• 매뉴얼→지침, 인프라→기반시설
• '작성할 것'→'작성해 주십시오'
8. 붙임·끝 표시 (편람 59~61쪽)
• '첨부'→'붙임'
• 붙임 없음: ~바랍니다.  끝.
• 붙임 1개: 붙임  ○○○ 1부.  끝.
• 붙임 2개↑: 붙임  1. ○○ 1부.
                 2. ○○ 1부.  끝.
