4. 어문 규범 (편람 41~44쪽)

· 사이시옷: 하교길→하굣길, 최소값→최솟값, 갯수→개수 (예외: 곳간·셋방·숫자·찻간·툇간·횟수)
· 가운뎃점: 국내·외→국내외, 민·관→민관, 초·중·고→초중고 (사전 등재 단어)

6. 어휘 순화

· 매뉴얼→지침, 가이드라인→방침, 인프라→기반시설, 모니터링→점검
· 거버넌스→민관협력, 리스크→위험, 태스크포스(TF)→전담팀
