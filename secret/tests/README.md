# 테스트

빌드 도구도 의존성도 없습니다. node 만 있으면 됩니다.

```bash
node tests/matching.test.js
```

```bash
node tests/files.test.js
```

```bash
node tests/forms.test.js
```

## 이 테스트가 지키는 것

`자율 · 진로 기록 모으기`에서 **업로드한 파일을 읽어 학생을 우리 반 명단과 맞추는 부분**입니다.
교사가 받는 전교생 취합 파일은 서식이 제각각인데, 열 하나가 달라지면 기록이 통째로 빠지면서
화면에는 `가져올 새 기록이 없습니다` 만 뜹니다. 그래서 실제로 실패했던 서식을 사례로 남겨 둡니다.

| 파일 | 지키는 것 |
|---|---|
| `tests/files.test.js` | 파일 읽기. `.xlsx` · `.xlsm` · `.xlsb` · `.xls` · `.cell` · `.nxl` · `.ods` · `.csv` · HTML 형 `.xls`, 암호 · 표지 안내 |
| `tests/forms.test.js` | 표 모양. 머리글 · 학년반 표기 · 여러 사람 칸 · 영역 · 제목 줄 · 탭 이름 |
| `tests/matching.test.js` | 학생 맞추기와 담을 줄 고르기. 동명이인 · 번호 어긋남 · 고친 역할 유지 |

## 사례를 더하는 법

**먼저 재현되는 서식을 사례로 적고, 시험이 실패하는 것을 본 뒤** `index.html` 을 고치세요.

- 새 표 모양은 `tests/forms.test.js` 의 `GROUPS` 에 한 줄만 더하면 됩니다.

  ```js
  ["학생회 칸 뒤에 내용 · 성명", [["번호", "학생회", "기록", "성명"], [1, "회장", T, "강도윤"]], "a", { unmatched: 0 }],
  ```

  순서대로 이름, 표, 담겨야 할 사람(명단 열쇠 `a b c ...`, 진로는 뒤에 `진`), 옵션입니다.
- 새 파일 형식은 `tests/files.test.js` 에 넣습니다. 한셀이 만들 수 없는 변형은 그 파일의 도우미(`rec` · `makeCfb` · `miniXlsx`)로 바이트를 직접 짭니다.
- 실제 학생 파일은 저장소에 넣지 않습니다. 이름과 내용을 지어낸 값으로 바꿔 서식만 옮겨 적으세요.

## 시험 파일 (`tests/fixtures`)

한셀(Hancom Office 2022)로 같은 가상 자료를 형식만 바꿔 저장한 파일입니다. 형식마다 같은 표가 나와야 합니다.
학생 이름과 내용은 모두 지어낸 값이고, 저장할 때 들어간 내 컴퓨터의 폴더 경로는 지웠습니다. 파일을 새로 저장했다면 `xl/workbook.xml` · `xl/workbook.bin` 의 경로를 지운 뒤 올리세요.
`hancell-password.*` 는 암호를 걸어 저장한 파일로, 안내 문구만 확인합니다.

한셀의 옛 `.cell`(판 번호 `0x1001`)은 지금 한셀이 더 이상 저장하지 못해서, `tests/files.test.js` 에서 바이트로 짭니다.
이 형식은 엑셀 97 과 비슷하지만 줄 번호가 4바이트이고 글자가 늘 2바이트입니다.

## 어떻게 돌아가는지

앱은 파일 하나(`index.html`)로 굴러가야 하므로 코드를 모듈로 쪼개지 않았습니다.
대신 `index.html` 안에서 **브라우저 API 를 쓰지 않는 순수 함수 구간**을 표시로 감싸 두고,
`tests/harness.js` 가 그 구간만 떼어내 node 에서 돌립니다.

```js
/* ===== @import-core:start ===== */
   ... 여기에는 document · window · state 를 쓰지 않는다 ...
/* ===== @import-core:end ===== */
```

구간에 브라우저 API 가 들어오면 테스트가 먼저 깨지므로, 순수하게 유지됩니다.
새 함수를 테스트하려면 그 구간 안에 두고 `tests/harness.js` 의 `CORE_NAMES` 에 이름을 더하세요.
