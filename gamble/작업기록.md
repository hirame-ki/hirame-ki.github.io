# 도박예방교육 체험 시뮬레이션 — 작업 기록

> 최종 갱신: 2026-07-14
> 대상: 청소년 도박예방 교육용. 실제 금전·실제 사이트 아님(상단 경고 배너 상시 노출).
> 백엔드·서버 없이 브라우저에서 단독 실행되는 웹 시뮬레이션. 오프라인 작동.

**⚠ index.html 파일 형식 주의**
초기에는 순수 단일 HTML 파일이었으나, 이후 **Claude 디자인으로 손본 뒤 아티팩트에서 export한 번들 파일**로 교체됨(약 1MB, 폰트 내장, **전체 HTML이 JS 문자열로 이스케이프**되어 저장 — `/`→`/`, `"`→`\"`). 따라서 손편집이 위험하며, 편집 시 이스케이프를 맞춰 Python 스크립트로 교체해야 함(§5 참고). **원본 소스의 진짜 출처는 claude.ai 아티팩트**이고, 아티팩트를 다시 export하면 로컬 수정이 덮어써짐.

## 1. 앱 개요

화려한 배너 → 가입 → 카지노 게임 → 초반 연승 → 잔액 소진 → 단계별 대출 →
사채 독촉·가족 붕괴 → 파산 → **각본이었음을 밝히는 각성(reveal) 화면**으로 이어지는
"불법 도박 피해 각본"을 1인칭으로 체험시키는 웹 시뮬레이션.

**전체 화면 흐름**: 인트로 → 배너 그리드 → 회원가입 → 카지노 → 파산 → 각성

## 2. 이번 세션에서 추가/변경한 내용

### ① 메신저 대화량 확대 + 연속 수신(몇 초 텀)
- 환영 메시지 3→**5개**, 각 대출 대화 **4개+**, 붕괴 시퀀스 9→**16개**로 확장
- 각 메시지에 `1.2~2.6초` 간격을 둬 순차 도착 → 알림이 쉴 새 없이 울리는 압박감
- 대출 직후 게임 중에도 다른 사람이 계속 압박 메시지를 보내는 **nudge** 추가
  (`scheduleNudge()` — 해당 라운드가 유지될 때만 발송)

### ② 등장인물(가족) 확대
- 기존 엄마·아빠 + **여동생·할머니·이모·담임선생님** 추가
- 붕괴 시퀀스에서 **사채 협박 ↔ 가족의 눈물**이 교차하도록 배치
- 말풍선 색상 구분: `friend`(파랑) `broker`(보라) `shark`(빨강/threat) `family`(초록) `teacher`(주황)

### ③ 친구에게 직접 돈 빌리는 단계 신규 추가
대출이 **눈덩이처럼 커지는** 다단계 구조로 재설계:
1. 내 돈 35만(30만+보너스 5만) 소진
2. **절친 민준** — 자기 돈 15만 직접 대출 (담주 20만 상환) ← **신규**
3. **같은반 승우** — "아는 형" 소개, 20만 대출 (담주 30만 상환)
4. **사이트 실장** — 50만 대출 + **신분증·부모님 연락처** 요구 (75만 상환)
5. 사채 독촉 → 붕괴

### ④ 사다리 애니메이션 + 게임 종류 추가 (총 4종)
- **사다리**: 결과만 나오던 것을 → 무작위 발판을 따라 **구슬이 실제로 내려가는 SVG 애니메이션**으로 교체.
  도착 칸에 당첨/꽝 표시. 패배 시 **옆 칸을 '당첨'으로** 둬 "아깝게 빗나간" 연출.
- **홀짝**: 기존 유지(주사위 굴림 애니메이션)
- **룰렛(빨강/검정)**: 숫자가 빠르게 돌다가 정해진 색에 착지 ← **신규**
- **슬롯(3릴)**: 릴이 순차 정지, 당첨 시 3개 일치 강조 ← **신규**

### ⑤ 연승 후 연패 중에도 1~2판 이기는 "유혹" 구조
- 라운드별 승패를 미리 정한 패턴 배열(`patterns`)로 제어. **간헐적 승리**를 심음:
  - `firstRun`: 6연승 후 지는 중에도 8·11·14번째 판을 이기게 함
  - 이후 대출 라운드도 초반 잠깐 승리 → 결국 전패
  - 배열 길이를 넘으면 무조건 패배 → 결국 잔액 0
- **슬롯 니어미스**(두 개만 일치 → "하나만 더 맞으면 대박") 토스트
- 연패 중 승리 시 **"거봐, 한 방이면 오르잖아"** 토스트로 재유입 유도

### ⑥ 출금 잠수/차단 시뮬레이션 (신규 요청)
- 상단바 **💵 출금** 버튼 추가
- 신청 시 "검토중" → **롤링 300% 미달·본인인증·계정점검** 등 사기 상투 사유로 항상 보류
  (달성률 표시가 **절대 100%에 도달하지 않음**)
- "관리자에게 문의" → 실장에게 메시지 → **타이핑 점만 뜨다가 무응답 → 잠수 → 연락 두절 → 계정 차단**
- 차단 후 출금 버튼은 **"⛔ 접속 차단 · 따놓은 돈이 사이트에 갇힘"** 표시
  → **돈을 따도 뽑을 수 없다**는 핵심 메시지 전달
- 각성(reveal) 화면 해설에도 반영

### ⑦ 각성(reveal) 화면 해설 갱신
간헐 보상·니어미스·다단계 대출(절친→형→실장)·출금 불가·가족 전체 협박 구조를 반영하도록 문구 수정.

## 3. 주요 기술 메모 (유지보수용)

- **상태 흐름(stage)**: `start → firstRun → loanCloseWait → secondRun → loanBrokerWait → thirdRun → loanSharkWait → fourthRun → collapse`
- **승패 각본**: `scripted()`가 `patterns[stage][stageBet]`를 반환. `stageBet`은 각 라운드 진입 시 0으로 리셋(가입 시, 각 대출 실행 함수 내부).
- **게임 공통**: 모든 게임이 같은 `scripted()` 결과 → `settle()`로 정산. 애니메이션만 게임별로 다름.
- **베팅 금액**: `#betRow` 하나를 4게임이 공유(`selBet` 전역).
- **휴대폰 메신저**: `pushChat(type)`가 시나리오별 대화 실행. `addBubble()`은 Promise 기반으로 지연·순차 도착 처리. `addTyping()/removeTyping()`으로 잠수 연출.
- **출금**: `openWithdraw()` / `renderWithdraw(state)` — 상태 `form / processing / reject / blocked`. `wdBlocked`, `wdAttempts` 전역으로 관리.

## 4. 향후 앱(구글 플레이) 전환 시 참고 — *웹 배포 반응 보고 결정 예정*

- **권장 방식**: **Capacitor**(HTML/JS를 앱에 내장, 서버 불필요, 오프라인 작동, iOS 확장 가능).
  대안: PWA→TWA(Bubblewrap/PWABuilder)는 호스팅이 필요해 이 앱엔 과함.
- **⚠ 최대 리스크 — 구글 플레이 도박 정책**: 교육용이라도 화면이 카지노/베팅이라
  "도박 흉내 앱"으로 오인·반려될 수 있음. 대비:
  - 교육용 배너 유지 + 스토어 제목·설명에 **"도박예방 교육"** 명시
  - 콘텐츠 등급 설문에서 "시뮬레이션 도박(실제 금전 없음)" 정직하게 선택
  - 학교/기관 배포면 **내부 테스트·조직 전용 배포**가 심사 부담이 훨씬 적음
- **필요 준비물**: 구글 플레이 개발자 계정($25 1회), 서명 키(keystore), 릴리스 AAB,
  아이콘·스플래시·스크린샷, 개인정보처리방침(수집 데이터 없으면 "수집 안 함" 명시).
- Capacitor 대략 순서:
  ```
  npm install @capacitor/core @capacitor/cli @capacitor/android
  npx cap init "도박예방체험" "kr.goedu.gamble.prevent"
  # index.html을 www/ 에 배치, webDir=www 설정
  npx cap add android && npx cap copy && npx cap open android
  ```

## 5. 각성 페이지 상담/신고 전화 확대 (추가 세션)

> 주의: 이 시점의 `index.html`은 Claude 아티팩트에서 export된 **번들 파일**(전체 HTML이 JS 문자열로 이스케이프됨, `/`->`\u002F`, `"`->`\\"`). 손편집이 위험해 Python 스크립트로 정확히 교체함.

파산 후 하얀 각성 페이지의 도움 안내(teal 박스)를 1336 단독 안내에서 **상담·신고 기관 목록 + 설명**으로 확장:

- **1336** 한국도박문제예방치유원 — 도박문제 24시간 무료·익명 상담, 회복 프로그램·가족 상담
- **1388** 청소년 상담전화 — 청소년 고민 24시간 상담(문자/카톡 가능)
- **1332** 금융감독원 불법사금융 신고 — 불법 사채·고금리·협박 추심·보이스피싱 피해
- **117** 학교폭력 신고센터 — 협박·금품 갈취·학교폭력 24시간 신고
- **112** 경찰 긴급신고 — 신변 위험·불법 도박/추심 신고(강조 박스)

**중요**: 이 index.html은 생성된 번들이라, 아티팩트를 다시 export하면 덮어써짐. 영구 반영하려면 원본 아티팩트 소스도 같이 수정 필요.
